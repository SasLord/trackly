# Trackly

Trackly — приложение для учёта и отслеживания техники, принтеров и картриджей
в организации с несколькими локациями и складами. Десктоп-приложение с встроенным
серверным режимом: сотрудники могут подключаться через браузер из локальной сети
для подачи заявок и работы с системой.

---

## Установка и запуск

### Windows 10 x64

**Вариант 1 — NSIS-инсталлятор (рекомендуется):**

1. Скачайте файл `Trackly_N.N.N_x64-setup.exe` из раздела Assets релиза.
2. Запустите установщик и следуйте инструкциям мастера установки.
3. После установки запустите Trackly через меню Пуск или ярлык на рабочем столе.

**Вариант 2 — Portable ZIP:**

1. Скачайте `trackly-vN.N.N-windows-x64-portable.zip` из раздела Assets релиза.
2. Распакуйте архив в любую папку (например, `D:\trackly\`).
3. Запустите `trackly.exe` из папки с распакованным архивом.

Подробнее о portable-режиме — см. раздел «Portable-режим» ниже.

### macOS aarch64 (Apple Silicon)

1. Скачайте файл `Trackly_N.N.N_aarch64.dmg` из раздела Assets релиза.
2. Смонтируйте образ двойным кликом.
3. Перетащите значок Trackly в папку «Программы» (Applications).
4. При первом запуске может потребоваться подтвердить открытие — см. раздел
   «Предупреждения безопасности» ниже.

### Linux x86_64

**AppImage (универсальный, без установки):**

```bash
chmod +x trackly_N.N.N_amd64.AppImage
./trackly_N.N.N_amd64.AppImage
```

**DEB-пакет (Debian / Ubuntu / Mint):**

```bash
sudo dpkg -i trackly_N.N.N_amd64.deb
```

После установки запустите Trackly из меню приложений или командой `trackly`.

## Portable-режим (Windows)

Portable ZIP содержит `trackly.exe` вместе с пустым файлом `portable.txt`.
Наличие `portable.txt` рядом с исполняемым файлом активирует portable-режим:
все данные (база `trackly.db`, логи, сертификаты) сохраняются в ту же папку,
где находится `trackly.exe`. Ничего не записывается в `%APPDATA%` или реестр.

**Не удаляйте `portable.txt`** — без него приложение перейдёт в режим
с системными путями.

Для указания другого пути к базе данных:

1. Переименуйте `trackly.config.toml.example` в `trackly.config.toml`.
2. Откройте файл в текстовом редакторе и раскомментируйте строку `db_path`.

## Серверный режим

Серверный режим позволяет сотрудникам подключаться к Trackly через браузер
из локальной сети (без установки приложения).

**Включение:**

1. Откройте Настройки → Сеть (или «Сервер»).
2. Включите серверный режим и нажмите «Применить».
3. Приложение привяжется к порту **8443** (HTTPS).

**TLS-сертификат:**

При первом включении Trackly автоматически генерирует самоподписанный сертификат
(self-signed). Браузеры покажут предупреждение о ненадёжном сертификате — это
ожидаемо. Как добавить доверие к сертификату:

- **Chrome / Edge:** нажмите «Дополнительно» → «Перейти на сайт (небезопасно)».
- **Firefox:** нажмите «Дополнительно» → «Принять риск и продолжить».

Для производственного использования можно настроить собственный сертификат:
укажите пути к `.pem`-файлам в `trackly.config.toml` (раздел `[server]`).

## Предупреждения безопасности (SmartScreen / Gatekeeper)

Артефакты Trackly не подписаны коммерческим сертификатом (только ad-hoc подпись).
Операционные системы могут показывать предупреждения при первом запуске.

### Windows — SmartScreen

При запуске установщика или portable `trackly.exe` Windows SmartScreen может
показать экран «Защита компьютера».

**Способ 1 (NSIS-инсталлятор):**
Нажмите «Подробнее» → «Выполнить в любом случае».

**Способ 2 (portable EXE через Свойства файла):**
Правая кнопка мыши на `trackly.exe` → «Свойства» → вкладка «Общие» →
поставьте галочку «Разблокировать» → нажмите «OK».

### macOS — Gatekeeper

При открытии `.dmg` или приложения macOS Gatekeeper может заблокировать запуск.

**Способ 1:**
Удерживайте Ctrl и кликните по приложению → выберите «Открыть» → подтвердите
в диалоге.

**Способ 2:**
Системные настройки → «Конфиденциальность и безопасность» → найдите строку
«Trackly заблокировано» → нажмите «Всё равно открыть».

## Проверка контрольных сумм

К каждому релизу прилагается файл `SHA256SUMS` со значениями SHA256 для всех
артефактов. Рекомендуется проверять контрольные суммы перед установкой.

**Linux / macOS:**

```bash
sha256sum -c SHA256SUMS
```

**Windows (PowerShell):**

```powershell
Get-FileHash trackly_N.N.N_x64-setup.exe -Algorithm SHA256
```

Сравните вывод со значением из файла `SHA256SUMS` для вашего артефакта.
