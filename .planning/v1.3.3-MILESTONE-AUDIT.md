### ✅ INT-01 (был blocker, закрыт 2026-08-18) — CI не исполнял собственные гейты

`cargo fmt --all -- --check` падает на HEAD в **11 местах**, в файлах, которые трогали именно
фазы 34–36:

```
crates/trackly-app/src/pdf/html_templates.rs:37
crates/trackly-app/src/pdf/minijinja_env.rs:254, 321, 388
crates/trackly-app/tests/html_act_render.rs:396, 776

crates/trackly-app/tests/org_settings.rs:66
crates/trackly-app/tests/pdf_render_act.rs:457
```

В `ci-fast.yml` job `fast` шаги идут последовательно, без `continue-on-error`, и
`cargo fmt --check` стоит перед `cargo clippy`, `cargo test`, `pnpm svelte-check`, `pnpm lint`.
Фактический результат последнего прогона (на `eca26d24`):

```
success  Privacy gate
success  Build Svelte SPA (ui/dist)
failure  cargo fmt --check
skipped  cargo clippy
skipped  cargo test
skipped  pnpm svelte-check
skipped  pnpm lint
```

CI красный на **каждом** прогоне минимум с 2026-08-11 — то есть почти всю веху. Практическое
следствие: единственное автоматическое свидетельство по DOC-04..DOC-11 (Rust-тесты рендера,
структурные CSS-гейты, `check-print-isolation.mjs`, `check-pagedjs-csp-hash.mjs`) не
исполнялось ни разу. Гейты написаны, подключены и корректны — но не работают как гейты.

Privacy-гейт (PRIV-02) — единственный, кто реально отрабатывает, потому что стоит первым шагом.

Тот же дрейф был замечен ретроаудитом Фазы 32 (`32-VALIDATION.md`) 2026-08-18 и явно вынесен
за границы той фазы. Никто его после этого не закрыл.

**Фикс — потребовалось два шага, а не один.**

1. `cargo fmt --all` — 6 файлов, 28 вставок, только переформатирование, токены идентичны
   (`b26f6173`).
2. За fmt пряталась вторая поломка того же происхождения: `cargo clippy -D warnings` падал на
   `crates/trackly-app/src/services/act_service.rs:3318` — тестовый конструктор `item()` из
   плана 36-06 (D-17, `group_items_for_print`), 9 аргументов при лимите 7, таргет lib test.
   Добавлен `#[allow(clippy::too_many_arguments)]` по уже принятому в репозитории образцу
   (`report_service.rs:606`, `requests_sqlite.rs:137`, `cartridges_sqlite.rs:171/232`)
   — `b4a7dc52`.

**Результат:** прогон `ci-fast` на `b4a7dc52` зелёный целиком — Privacy gate, build SPA,
`cargo fmt --check`, `cargo clippy`, **`cargo test --workspace`**, `pnpm svelte-check`,
`pnpm lint` — все `success`. Первый зелёный CI с 2026-08-08.

Практическое следствие для вехи: автоматическое свидетельство по DOC-04..DOC-11 (тесты рендера,
структурные CSS-гейты, `check-print-isolation.mjs`, `check-pagedjs-csp-hash.mjs`) впервые за
две недели реально исполнено и зелёное — на Linux-раннере, включая полный
`cargo test --workspace`, который локально на macOS не гоняется из-за известного хэнга
`login_remember_persistent_cookie`.

**Урок для процесса:** тот факт, что за fmt-дрейфом пряталась вторая поломка, — прямой
аргумент против закрытия вехи с красным CI. Красный шаг маскирует всё, что стоит за ним,
и цена ошибки растёт молча.
