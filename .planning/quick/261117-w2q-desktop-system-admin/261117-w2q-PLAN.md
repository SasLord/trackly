<objective>
Системный пользователь «Администратор» для десктопа + честные ошибки ремонтного create.

Проблема: десктоп несёт Identity::trusted_admin() (user_id None), create заявок подставляет `unwrap_or(1)` — на свежей БД FK падает, а ремонтный create маскирует любой ConstraintViolation под «повторите попытку».

Выбранный дизайн (planner discretion):
1. Маркер: колонка `users.is_system INTEGER NOT NULL DEFAULT 0` + частичный `UNIQUE INDEX ... ON users(is_system) WHERE is_system = 1` (V053, только схема, БЕЗ INSERT). Создание — идемпотентный `AuthService::ensure_system_admin()` в `AppCtx::build` сразу после миграций. Причина отказа от INSERT в миграции: десятки существующих тестов гонят `migrations::run` и ждут пустую users (`needs_bootstrap`); миграционный INSERT их ломает. Ensure при старте покрывает и свежую, и старую БД одним путём.
2. Логин: `admin`, если свободен (включая soft-deleted строки — login UNIQUE безусловен); иначе `admin-system`, затем `admin-system-2…`. Существующего пользователя молча не присваиваем. Если системная строка уже есть, но soft-deleted/деактивирована/не admin (правка БД руками) — ensure её чинит UPDATE'ом, не плодит вторую.
3. Identity: `resolve_tauri_identity`: unlocked → `Identity{Some(system_id), Admin}`; locked → прежняя D-Desktop-02 (ровно один активный НЕ-системный admin → он), иначе системный (вместо trusted_admin/None). Системный исключается из подсчёта admin'ов в desktop_identity, needs_bootstrap/bootstrap_first_admin (count_active_admins) и в guard «последний администратор» — иначе первичная настройка и D-Desktop-02 сломаются. trusted_admin() в тестах/HTTP/внутренних сервисах не трогаем.
4. Побочный эффект (принять и отметить в SUMMARY): десктопные действия теперь имеют user_id → попадают в audit_log с актором (раньше без записи). Старые десктопные заявки, приписанные users.id=1, НЕ переписываются (неотличимы).
5. Повтор D-19: `Conflict` повторяется только если reason содержит "UNIQUE constraint failed" (или имя индекса uq_requests_open_repair_device); остальное возвращается как есть.
</objective>
