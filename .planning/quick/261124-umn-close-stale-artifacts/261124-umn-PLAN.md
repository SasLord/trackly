# Закрыть исторические «открытые» артефакты перед закрытием v1.4

Сканер `gsd-sdk query audit-open` перед `/gsd-complete-milestone v1.4` показал 121 открытый
артефакт. Решение пользователя: разобрать до закрытия, а не принимать скопом. Только документы
`.planning/`, код не трогать, cargo/pnpm не запускать.

## Задача 1. Quick-задачи (74: 72 «missing», 2 «unknown»)
Причина: старые SUMMARY без поля `status` во frontmatter (формат до сентября).
- Для каждой папки `.planning/quick/*` из списка сканера: если SUMMARY есть и описывает
  выполненную работу (коммиты есть в `git log`), добавить во frontmatter `status: complete`.
- Если SUMMARY говорит о незавершённом/заблокированном — `status: incomplete` + строка-причина;
  такие пункты перечислить в SUMMARY этой задачи.
- Папка без SUMMARY (`260827-wsu-...`): проверить по `git log --grep 260827-wsu` и строке в
  STATE.md; если работа сделана — написать короткий SUMMARY со ссылкой на коммиты
  (`status: complete`), иначе — `status: abandoned` с объяснением.

## Задача 2. Debug-сессии (8, `.planning/debug/`)
Для каждой: найти исправление (`git log --grep <slug>` / упоминания в SUMMARY/STATE). Если
исправление в main — перевести в `status: resolved` со ссылкой на коммит и переместить в
`.planning/debug/resolved/` (если такая папка используется), иначе оставить и перечислить.
`knowledge-base` — не сессия, проверить, как сканер её видит; если это служебный файл —
отразить в SUMMARY как ложное срабатывание.

## Задача 3. UAT- и VERIFICATION-пробелы (30 + 8)
- Фазы прошлых вех (03–38, архивы закрыты): статусы привести к факту — `resolved`, если пробел
  закрыт позже (найти коммит), иначе `accepted` с пометкой «веха vX закрыта YYYY-MM-DD,
  принято при закрытии» и ссылкой на `milestones/vX-MILESTONE-AUDIT.md`, где есть.
- Фазы v1.4 (40, 41.2 и др.): сверить с П7 (`261124-u2k`) и `v1.4-CLOSE-UAT.md`; закрыть или
  перенести в `.planning/v1.5-DISCUSSION-SEEDS.md`.
- 24-VERIFICATION `gaps_found` — выяснить и проставить по факту.

## Проверка
`gsd-sdk query audit-open` после правок: открытыми остаются только сознательно отложенные
(todo wr02 → v1.5 и то, что не удалось подтвердить). Числа «до/после» — в SUMMARY.
Приватность: репозиторий публичный; правки — только статусы и ссылки, без цитирования реальных
данных; pre-commit check-privacy зелёный. Коммиты `docs(quick-261124-umn): …`.
