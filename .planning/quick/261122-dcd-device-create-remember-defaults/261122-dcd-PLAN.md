# Быстрая задача: форма создания устройства помнит «Место» и «Статус»

При следующем создании устройства подставлять последние выбранные место и статус.
Правка не затрагивается; значение остаётся редактируемым; удалённое место/статус
не подставляется, без ошибки. Оба режима (десктоп и LAN-браузер).

## Задача 1
- `ui/src/features/devices/createDefaults.ts` — load/save в localStorage (try/catch,
  ключ по id пользователя, валидация значения).
- `DeviceFormBody.svelte` — create-режим без пресета вызывающего: статус после загрузки
  справочника (если существует и пользователь ещё не выбрал), место после успешного
  `places_get`; сохранение после успешного одиночного и пакетного создания (кроме
  создания из записи разбора).
- Гейты: `pnpm --dir ui lint`, `pnpm --dir ui svelte-check`, `pnpm --dir ui build`.
