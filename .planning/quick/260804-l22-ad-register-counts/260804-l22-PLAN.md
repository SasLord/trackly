<objective>
Close a REQ-06 visibility leak: `list()` already hides `ad_register` (auto-generated AD registration/restore) requests from non-admin callers, but `counts()` does not — so an Employee's own invisible `ad_register` request inflates their "Мои заявки" badge/switch-bar count (e.g. shows "1" with an empty list). Mirror the exact `exclude_ad_register` mechanism already proven in `list()` into `counts()` at both the repo (SQL) and service (role→bool) layers, across ALL count buckets, and add a regression test.

Purpose: Employee-visible request counts must match what `list()` actually shows them — no phantom counts from system-generated rows they can never see or act on.
Output: `RequestRepository::counts` gains an `exclude_ad_register: bool` parameter (trait + sole impl + sole caller updated in lockstep), all 6 SQL count queries in `SqliteRequestRepository::counts` filter it, `RequestService::counts` computes it identically to `RequestService::list`, and a new regression test locks the behavior in.
</objective>
