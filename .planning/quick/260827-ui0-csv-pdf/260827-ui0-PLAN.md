<objective>
Починить «Экспорт CSV» в «Отчётах»: сегодня клик ничего не делает — файл не сохраняется, диалог
сохранения не появляется. Причина (подтверждена чтением кода, не гипотеза) — `exportCsv` в
`ReportsPage.svelte` доставляет байты через detached `<a>`-якорь с гонкой `URL.revokeObjectURL`
сразу после `click()`, и этот путь вообще не работает в Tauri-вебвью (нужен нативный
save-диалог + `writeFile`, а не blob-скачивание).

Используется уже существующий в проекте паттерн (`StorageSettings.svelte`, `OrgSettings.svelte`):
`isTauri` guard + динамический `import('@tauri-apps/plugin-dialog')`/`import('@tauri-apps/plugin-fs')`.
Оба плагина уже объявлены в `Cargo.toml`/`package.json` — новых зависимостей не требуется.

**Решение по выносу общего хелпера (взвешено в brief):** выносим `saveFile(bytes, suggestedName,
mimeType)` в `ui/src/lib/utils/saveFile.ts`. Это второе место в приложении, которому нужно «отдать
пользователю файл» (после DB-move в StorageSettings, который сам не пишет байты, а просит бэкенд).
Без общего хелпера следующий caller рискует повторить те же три бага. Хелпер маленький
(~30-40 строк), явно не scope creep.

**Решение по имени файла:** сохраняем кириллический префикс «отчёт» (существующая конвенция,
кириллица в именах файлов штатно работает и на Windows, и на macOS), но добавляем машинный ключ
типа отчёта (`reportTypeKey()`, например `device_acts`) и ISO-дату — иначе повторные экспорты
схлопываются в «отчёт.csv» / «отчёт (1).csv». Итоговый пример: `отчёт-device_acts-2026-08-27.csv`.

**Решение по обработке ошибок:** отмена диалога сохранения (Tauri `save()` вернул `null`) —
штатное действие, НЕ ошибка → без тоста. Реальный сбой записи (диск, права, network при
`apiCall`) — как и раньше, error-тост.

**Вне scope:** PDF-путь (`exportPdf`/`PdfPreviewModal`/`reports_export_pdf`) не трогаем — он уже
работает через preview+print модалку (Plan 17-03), blob/save-dialog там убран ранее. Не трогаем
формат сокращения place-path (отдельная очередь) и `sibling_cmp`-правку.

Purpose: живой UAT показал, что бэкенд корректно отдаёт байты CSV, но доставка до диска никогда не
была реально проверена — синтетические гейты (svelte-check/lint/build) прошли на полностью
нерабочем в рантайме коде.

Output: рабочий CSV-экспорт в обоих вебвью (десктоп Tauri + LAN-браузер), общий переиспользуемый
`saveFile` хелпер, расширенный Tauri ACL-скоуп для `.csv`.
</objective>

```
function exportCsv() {
  csvExporting = true;
  apiCall<number[]>('reports_export_csv', {
    reportType: reportTypeKey(),
    filter,
    period: isSnapshot() ? undefined : period,
  })
    .then((bytes) => {
      const blob = new Blob([new Uint8Array(bytes)], { type: 'text/csv;charset=utf-8' });
      const url = URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url;
      a.download = 'отчёт.csv';
      a.click();
      URL.revokeObjectURL(url);
    })
    .catch(() => { pushToast('error', 'Ошибка при экспорте CSV. Попробуйте ещё раз.'); })
    .finally(() => { csvExporting = false; });
}
```
