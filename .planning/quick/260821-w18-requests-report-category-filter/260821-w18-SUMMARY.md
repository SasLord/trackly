# Quick Task 260821-w18: Фильтр категорий заявок в отчёте «Заявки» Summary

**Funnel-фильтр (кнопка-воронка + попап из 8 чекбоксов) для отчёта «Заявки»: allow-list по request_type/category_id, идентично применяется к экрану, счётчикам вкладок, CSV и печати/PDF на обоих транспортах, без ослабления RBAC-исключения ad_register.**

## Accomplishments
- `ReportFilter.request_category_filter: Option<Vec<String>>` — новое поле фильтра, автоматически течёт через оба транспорта (Tauri invoke + HTTP `/api/v1/reports_*`) без правок в `tauri_cmds/reports.rs`/`http/reports.rs`/`specta_export.rs`
- `category_filter_clause()` — allow-list WHERE-builder: `None`→нет ограничения, `Some([])`→0 строк, известные ключи → `r.request_type = '...'` или подзапрос `SELECT id FROM request_categories WHERE name = ?N` с точными RU-именами из V024, неизвестные ключи молча пропускаются (нет паники/ошибки)
- `query_requests_inner`/`count_requests_inner` получили 6-й параметр `category_filter`; 4 `list_requests_*` метода и `get_report_counts(domain="requests")` прокидывают `filter.request_category_filter.as_deref()`

## Decisions Made
- «Все» implemented as `None` (absence of WHERE clause), not an OR of all currently-known keys — this means future request types/categories added later remain visible while «Все» is selected, per the plan's explicit CATF-02 truth
- Explicit empty checkbox selection (`Some(vec![])`) yields `1 = 0` (0 rows) rather than falling back to «Все» — UI does not "fix" a fully-unchecked state on the user's behalf
- Category-key clause is combined with `exclude_ad_register`'s clause via `AND` in the same WHERE — the funnel filter can only narrow the RBAC-permitted result, verified by a dedicated test (`report_requests_category_filter_ad_register_key_still_excluded_for_manager`)
- Introduced a `.controls-left` wrapper div (not in the plan's literal snippet, but implied by CATF-01's "сразу после PeriodSelector" truth) so the new button stays visually adjacent to `PeriodSelector` regardless of `.controls-row`'s `justify-content: space-between` — otherwise a bare 3-child flex row would separate the button from PeriodSelector
