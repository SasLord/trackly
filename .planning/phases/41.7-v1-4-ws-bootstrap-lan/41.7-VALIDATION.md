## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust: встроенный `cargo test` (`#[tokio::test(flavor = "multi_thread")]`, `tower::ServiceExt::oneshot`, `tokio-tungstenite` в dev-deps `crates/trackly-app/Cargo.toml:106`). UI: юнит-раннера НЕТ (`ui/package.json` без `test`) — только `svelte-check`, `eslint`, `node scripts/check-*.mjs` |
| **Config file** | отсутствует (cargo-таргеты `crates/*/tests/*.rs`); UI-гейты подключены в `ui/package.json:16` (`pnpm lint`) |
| **Quick run command** | `cargo test -p trackly-app --test <имя>` (таблица целей ниже) |
| **Full suite command** | `cargo test -p trackly-app -- --skip login_remember_persistent_cookie > <файл-лога> 2>&1` — В ФОНЕ, один раз на границе фазы |
| **Estimated runtime** | скоупленный таргет ≈1–3 мин после первой сборки; полный пакет ≈80 мин даже на тёплом `target/` |

**Известные ограничения среды:**
- `login_remember_persistent_cookie` ВИСИТ (и при `-p trackly-app`) — всегда `--skip`.
- Один `cargo test` одновременно; параллельные прогоны запрещены.
- Утилиты `timeout` на macOS нет — лимит задаёт оркестратор (`run_in_background` + timeout до 2 ч).
- Вывод полного прогона — СЫРЫМ в файл: `grep` в конвейере съедает буфер при убийстве по таймауту.
- При `exit 69` на линковке — префикс `DEVELOPER_DIR=/Library/Developer/CommandLineTools`.
- `cargo fmt --all -- --check` имеет ДОКУМЕНТИРОВАННЫЙ дрейф ДО фазы — сверять только свои файлы.

## Sampling Rate

- **After every task commit:** скоупленный таргет(ы) своей области из карты ниже (≈1–3 мин).
- **After every plan wave:** все таргеты волны + `cargo clippy -p trackly-app -p trackly-infra -p trackly-core --all-targets -- -D warnings` + `cargo fmt` по своим файлам.
- **Phase gate (один раз):** `pnpm --dir ui build` (тянет `prebuild` = `export_bindings`), затем ОДИН полный прогон пакета в фоне.
- **Before human-verify:** `pnpm --dir ui build` ОБЯЗАТЕЛЕН — иначе LAN-браузер получит устаревший `ui/dist`.
- **Max feedback latency:** ≈180 с на задачу; ≈80 мин на границе фазы.
