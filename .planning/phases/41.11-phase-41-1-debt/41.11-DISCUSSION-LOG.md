## CR-02: строка ребёнка в свёртке

### На какой `refresh()` сбрасывать кеш детей

| Option | Description | Selected |
|--------|-------------|----------|
| На любой успешный | Как уже делает `reloadExpandedAnchors`; одно правило на два кеша. Цена — `listByIds` на каждую раскрытую свёртку на каждый refresh | ✓ |
| Только после мутаций | Меньше запросов, но второй вид refresh и вопрос «а WS — это мутация?»; расхождение с якорями в том же файле | |

**User's choice:** На любой успешный

### Что видно, пока перечитывание в полёте

| Option | Description | Selected |
|--------|-------------|----------|
| Старые строки | Без мигания, ушедший ребёнок отсекается `visibleChildren` сразу; правленое поле обновится с задержкой запроса | ✓ |
| «Загрузка…» | Честнее, но мигание на каждом срабатывании WS — тот самый шум, который комментарий в коде специально исключает | |

**User's choice:** Старые строки

## CR-01: контраст на композите

**Поправки к формулировке ROADMAP, предъявленные до вопроса:** (1) «существующего альфа-бленда» в проекте нет — `check-contrast.mjs` единственный парсит `rgba()` и прямо декларирует композитинг «вне периметра»; (2) после честного фикса правило станет красным, так как на композите порядок muted/active инвертируется, а окно светлой warning-пары ≈0.21 не даёт поднять `MIN_CONTRAST_GAP` без правки токенов.

### Что менять, если на композите приглушённый НЕ тише активного

| Option | Description | Selected |
|--------|-------------|----------|
| Нецветовой признак | R1 сводится к «не ниже 4.5 на композите», требование порядка снимается; различие пары несёт не цвет; самостоятельный выигрыш по WCAG 1.4.1 | ✓ |
| Править токены | Правило остаётся как задумано, но меняется вид в двух темах, нужна повторная живая проверка G10–G12, окно может оказаться пустым | |
| Сначала измерить, потом решить | Бленд и фактические числа по 8 комбинациям, решение по цифрам; добавляет человеческий чекпоинт внутрь фазы | |

**User's choice:** Нецветовой признак

### Какой именно нецветовой признак

| Option | Description | Selected |
|--------|-------------|----------|
| Обводка у приглушённых | Подложка и токены `*-muted-*` из 41.1 остаются, добавляется 1px рамка только у muted; нужен новый класс в `Badge` и токен рамки в двух темах | ✓ |
| Точка вместо подложки | Готовый `appearance: 'dot'`, одна строка на статус в `TONES`; побочно растворяет CR-01, но осиротит токены 41.1, R1/R2 переписываются с нуля, вид шести чипов меняется заметно | |
| Решить по цифрам | Оба варианта в исследование, решение — чекпоинт пользователя | |

**User's choice:** Обводка у приглушённых

## Процессные пункты: AR-23 и AR-25

**Поправки к фактам, предъявленные до вопроса:** (1) AR-25 выполним — `login_remember_persistent_cookie` обёрнут в `tokio::time::timeout(30s)` и гоняется в `ci-full` без `--skip`; эталонная команда `cargo test --workspace --no-fail-fast -- --test-threads=1`, `timeout-minutes: 75`. (2) AR-23 в десктопе кодом не воспроизводится: Tauri `invoke` ходит в процессе, оба вызова идут подряд в одном обработчике.

### AR-23: как воспроизвести сбой живьём

| Option | Description | Selected |
|--------|-------------|----------|
