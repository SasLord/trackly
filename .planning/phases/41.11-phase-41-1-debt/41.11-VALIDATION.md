## Test Infrastructure

Фаза трогает три независимых слоя, у каждого своя цепочка. Единой «одной команды» нет.

| Property | Value |
|----------|-------|
| **Frameworks** | `cargo test` (Rust, встроенный); самописные Node-гейты `ui/scripts/check-*.mjs` с режимом `--selftest`; `svelte-check`, `eslint`, `prettier` |
| **Config files** | `Cargo.toml` (воркспейс), `ui/package.json` (строка `lint`), `.github/workflows/ci-fast.yml`, `.github/workflows/ci-full.yml` |
| **Quick run — Rust** | `DEVELOPER_DIR=/Library/Developer/CommandLineTools TRACKLY_AD_MOCK=1 TRACKLY_SNMP_MOCK=1 cargo test -p trackly-infra --test devices_list_all` (и целевой тест реестра, когда он появится) |
| **Quick run — гейт** | `node ui/scripts/<gate>.mjs --selftest && node ui/scripts/<gate>.mjs` |
| **Quick run — UI-типы** | `pnpm --dir ui svelte-check` (НЕ входит в `pnpm lint`) |
| **Full suite command** | цепочка `ci-full` целиком, см. «Sampling Rate» ниже |
| **Estimated runtime** | быстрые прогоны — секунды/десятки секунд; полная цепочка — **≈80 минут** |

## Sampling Rate

- **После каждого коммита задачи:** соответствующий слою quick-run из таблицы выше.
  Для правки гейта quick-run обязан включать **оба** шага: `--selftest` и обычный прогон по
  боевому исходнику (зелёный selftest при красном боевом файле — известный класс ошибки).
- **После каждой волны:** все затронутые волной гейты + `pnpm --dir ui lint` +
  `pnpm --dir ui svelte-check` + `cargo clippy --workspace -- -D warnings`.
- **На границе последней волны (AR-25, решение D-28/D-28a):** один непрерывный прогон,
  повторяющий `ci-full` командой в команду:

  ```
  pnpm --dir ui build
  cargo fmt --check
  cargo clippy --workspace -- -D warnings
  cargo test --workspace --no-fail-fast -- --test-threads=1
  ```

  с `DEVELOPER_DIR=/Library/Developer/CommandLineTools`, `TRACKLY_AD_MOCK=1`,
  `TRACKLY_SNMP_MOCK=1`, в фоне, под собственным watchdog'ом на 2 ч (`timeout`/`gtimeout` на
  машине нет), сырой вывод целиком — в каталог scratchpad сессии, **не** в репозиторий.
- **Перед закрытием фазы:** полная цепочка зелёная, сырой вывод сохранён, плюс живая
  проверка из «Manual-Only».
- **Max feedback latency:** quick-run — < 60 с; полная цепочка — один раз за фазу.
