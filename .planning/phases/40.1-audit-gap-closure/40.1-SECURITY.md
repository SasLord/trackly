### Audit Notes (non-blocking)

- **T-40.1-01 residual (pre-existing, out of plan scope, low severity):** `subtree_stats_impl` counts only live rows (`deleted_at_utc IS NULL`) for devices, cartridges, acts and child places. Soft-delete paths (`devices_sqlite.rs:534`, `acts_sqlite.rs:342`, `cartridge_service.rs:311`) do NOT clear `place_id`, and the V037/V038 FKs are `ON DELETE RESTRICT` regardless of soft-delete. A place referenced only by soft-deleted rows therefore passes the pre-check, the `DELETE` fails on the FK, and `map_rusqlite` (`crates/trackly-infra/src/error_conversions.rs:38`) passes SQLite's raw text (`FOREIGN KEY constraint failed`) through as `AppError::Conflict.reason`. The leaked string contains no table/column names and the path is Admin-only. It predates phase 40.1 (same shape as phase-39 CR-01). This was found by reading the code; no test reproduces it. Recommended follow-up: either count soft-deleted referrers in the pre-check, or map `ConstraintViolation`/FK failures in `places_sqlite::delete_hard` to a controlled Russian message.
- **T-40.1-07 note:** The header row is not passed through `csv_safe`. That is safe today because the labels are `'static` constants. If `column_labels` ever becomes data-driven (user-editable labels), apply `csv_safe` to the header as well.
- `csv_safe` checks only the prefixes `= + - @`. OWASP also lists leading TAB and CR. This gap predates this phase (T-07-03-05) and is outside the phase-40.1 register.
