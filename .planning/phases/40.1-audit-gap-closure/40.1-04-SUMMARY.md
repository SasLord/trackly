# Phase 40.1 Plan 04: Русские заголовки CSV-экспорта отчётов Summary

**`ReportService::export_csv` теперь пишет заголовок CSV из `column_labels_for(&report_type)` (та же русская подпись, что уже используется в `export_pdf`), а не из сырых ключей колонок — закрывает WARNING-4 аудита вехи v1.4.**

## Performance

- **Duration:** ~15 min
- **Tasks:** 3 completed
- **Files modified:** 4

## Accomplishments
- `export_csv(rows, columns, column_labels)` пишет заголовок CSV из `column_labels`, значения строк по-прежнему читаются по `columns` через `row_field` — сигнатура зеркалит уже существующий `export_pdf`.
- `build_reports_export_csv` передаёт `column_labels_for(&report_type)` тем же способом, что и `build_reports_export_pdf`; HTTP-транспорт (`http/reports.rs`) не тронут и получает фикс автоматически через общую точку.
- Тест `report_movements.rs`, который раньше фиксировал сырые английские ключи в заголовке CSV как ожидаемое поведение, переписан: теперь он доказывает, что заголовок — семь русских подписей `column_labels_for("movements")`.
- Индексная согласованность `columns_for`/`column_labels_for` защищена одним существующим тестом (`column_labels_for_is_index_aligned_with_columns_for`), расширенным doc-комментарием на упоминание CSV — новый дублирующий тест не заведён (D-20).

## Files Created/Modified
- `crates/trackly-app/src/services/report_service.rs` - `export_csv` получил параметр `column_labels: &[&str]`, заголовок пишется из него; doc-комментарий объясняет разделение источников заголовка/значений (D-19/D-20).
- `crates/trackly-app/src/tauri_cmds/reports.rs` - `build_reports_export_csv` собирает `labels = column_labels_for(&report_type)` (буквально та же строка, что в `build_reports_export_pdf`) и передаёт третьим аргументом; doc-комментарий индексного теста расширен.
- `crates/trackly-app/tests/report_csv_export.rs` - оба прямых вызова `svc.export_csv` обновлены на три аргумента; первый тест теперь проверяет русскую подпись «Номер» в заголовке вместо сырого ключа `number`.
- `crates/trackly-app/tests/report_movements.rs` - CSV-тест заголовков переименован и переписан на русские подписи; комментарий, документировавший старое (регрессивное) поведение, инвертирован.

## Decisions Made
- Плановый `#[allow(clippy::too_many_arguments)]` для `export_csv` не добавлен — функция имеет 4 аргумента (включая `self`), ниже дефолтного порога clippy (7); добавление неиспользуемого allow было бы избыточным подавлением линта.
- Второй тест в `report_csv_export.rs` (`csv_export_guards_formula_injection`) получил `column_labels = columns` (те же значения) с явным комментарием, почему подписи здесь функционально не важны — тест проверяет экранирование значений ячеек, не заголовок.

## Deviations from Plan

None - план выполнен как написан. Отредактированы оба файла заранее, но закоммичены раздельно и последовательно, строго по файловому списку каждой задачи плана (Task 1: `report_service.rs` + `report_csv_export.rs`; Task 2: `tauri_cmds/reports.rs`), с проверкой полной компиляции крейта перед каждым коммитом.
