<objective>
Close GAP-3 (28-VERIFICATION.md): the Отчёты report table lost its rounded/card styling and does
not fill height to the bottom of the window with padding, unlike Акты. Root-cause analysis found
two distinct defects, both CSS-only:

1. **Missing card framing.** `ReportTable.svelte` passes `framed={false}` to the shared `Table`
   component — correct ONLY when a surrounding bordered panel already paints the border/radius/
   shadow (as in Акты/Заявки, whose `.master`/`.detail` wrapper divs are `--tr-surface-raised` +
   border + `box-shadow: var(--tr-elev-1)`). Отчёты has NO such wrapping panel — `ReportTable` sits
   directly in the page's flex column — so with `framed={false}` there is currently no border/
   radius/shadow ANYWHERE around the report table. `Users.svelte` (a standalone-Table consumer with
   no master/detail wrapper, like Отчёты) uses `Table`'s default `framed={true}` for exactly this
   reason.
2. **Missing page-level flex context**, the same class of bug as GAP-2: `ReportsPage.svelte`'s
   `.reports-content` IS already a flex column (`display: flex; flex-direction: column; flex: 1;`)
   but is missing `min-height: 0` and uses `overflow: auto` (both axes) instead of `overflow-x:
   auto; overflow-y: hidden` — so `ReportTable.svelte`'s own `.report-table-wrap { flex: 1;
   min-height: 200px; }` wrapper has no bounded parent height to fill against, and the whole
   `.reports-content` area grows to natural content size and scrolls as one block instead of the
   table filling to the bottom with its own internal scroll.

This plan depends on 28-15 (GAP-4) because both touch the Отчёты report-loading surface
(`ReportsPage.svelte`) — sequencing avoids any risk of the two plans landing conflicting edits to
the same file in the same wave.

Purpose: restore the card look consistent with every other window's tables, and make the table
area truly fill to the bottom like Акты.
Output: ReportTable.svelte framed (rounded/bordered), ReportsPage.svelte's .reports-content
matches the proven ActsPage.svelte flex pattern; verified in a human checkpoint (both themes).
</objective>
