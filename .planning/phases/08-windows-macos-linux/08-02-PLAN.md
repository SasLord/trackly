    Имя: "release"

    Триггеры (per D-11, D-12):
    - on.push.tags: ['v*.*.*']
    - on.workflow_dispatch.inputs.version: {description: "Version to build (e.g. 1.2.3)", required: true}

    --- JOB: create-release ---

    runs-on: ubuntu-latest
    outputs: release_id: ${{ steps.create-release.outputs.result }}

    steps:
    1. actions/checkout@v4
    2. name "Create draft release", id: create-release
       uses: actions/github-script@v7
       with.script:
         Извлекать тег условно в зависимости от события:
           const tag = context.eventName === 'workflow_dispatch'
             ? 'v' + context.payload.inputs.version
             : context.ref.replace('refs/tags/', '');
         version = tag.replace(/^v/, '');
         Вызвать github.rest.repos.createRelease с owner/repo из context.repo,
         tag_name: tag, name: `Trackly ${version}`, draft: true, generate_release_notes: true (per D-15).
         Вернуть data.id через return (не core.setOutput — github-script@v7 возвращает через return).

         На workflow_dispatch draft Release создаётся против ещё не существующего тега —
         это допустимо: gh release upload позже ссылается на тот же тег, а при dry-run
         пользователь может удалить draft вручную после проверки.

    --- JOB: build ---

    needs: create-release
    strategy.fail-fast: false
    strategy.matrix.include:
      - platform: windows-latest
        args: '--bundles nsis'
      - platform: macos-latest
        args: '--target aarch64-apple-darwin --bundles dmg'
      - platform: ubuntu-22.04
        args: '--bundles appimage,deb'

    runs-on: ${{ matrix.platform }}
    timeout-minutes: 60

    steps (в этом порядке):

    1. actions/checkout@v4

    2. dtolnay/rust-toolchain@stable  with.toolchain: '1.92'
       (НЕ '1.88' — MSRV проекта 1.92 из Cargo.toml rust-version)

    3. Swatinem/rust-cache@v2

    4. Install Tauri 2 Linux system dependencies
       if: runner.os == 'Linux'
       run: sudo apt-get update && sudo apt-get install -y libwebkit2gtk-4.1-dev libgtk-3-dev
       libayatana-appindicator3-dev librsvg2-dev libxdo-dev build-essential curl wget file libssl-dev

    5. pnpm/action-setup@v4  with.version: 10

    6. actions/setup-node@v4  with.node-version: '20', cache: 'pnpm',
       cache-dependency-path: ui/pnpm-lock.yaml

    7. pnpm install (frozen lockfile)
       working-directory: ui
       run: pnpm install --frozen-lockfile

    8. name "Extract version and inject into Cargo.toml + tauri.conf.json"
       shell: bash
       run:
         Определить VERSION в зависимости от события:
           if [[ "$GITHUB_EVENT_NAME" == "workflow_dispatch" ]]; then
             VERSION="${{ github.event.inputs.version }}"
           else
             VERSION="${GITHUB_REF_NAME#v}"
           fi

         Обновить workspace version в Cargo.toml (только первое вхождение [workspace.package]).
         Использовать perl вместо sed -i — sed -i без аргумента суффикса не работает на BSD sed
         (macOS runner); perl -0pi -e переносим на Linux, macOS и Windows-bash одинаково:
           perl -0pi -e 's/^(version = ")[0-9]+\.[0-9]+\.[0-9]+(")/${1}'"${VERSION}"'${2}/m' Cargo.toml

         Обновить version в tauri.conf.json через jq (jq переносим, менять не нужно):
           jq --arg v "$VERSION" '.version = $v' crates/trackly-app/tauri.conf.json > /tmp/_tauri.conf.json
           mv /tmp/_tauri.conf.json crates/trackly-app/tauri.conf.json

         Экспортировать VERSION в окружение и верифицировать подстановку:
           echo "VERSION=${VERSION}" >> "$GITHUB_ENV"
           grep -E '^version = "[0-9]+\.[0-9]+\.[0-9]+"' Cargo.toml
           jq .version crates/trackly-app/tauri.conf.json

         grep должен вернуть строку вида version = "1.2.3" (с сохранёнными кавычками и префиксом), завершиться с кодом 0 — это доказывает, что perl-замена сохранила структуру `version = "..."`. jq должен вернуть VERSION (не "0.1.0"). Иначе следующий шаг
         tauri-action соберёт артефакты со старой версией.

    9. tauri-apps/tauri-action@v0
       env:
         GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
         APPLE_SIGNING_IDENTITY: '-'    (ad-hoc per D-04; применяется только на macOS)
       with:
         releaseId: ${{ needs.create-release.outputs.release_id }}
         releaseDraft: true             (safety net per D-12)
         uploadUpdaterJson: false       (per D-09: no updater)
         retryAttempts: 1              (per Pitfall 4: macOS DMG intermittent failure)
         projectPath: crates/trackly-app
         args: ${{ matrix.args }}

    10. name "Assemble portable ZIP"
        if: matrix.platform == 'windows-latest'
        shell: pwsh
        run:
          $STAGE = "portable-stage"
          New-Item -ItemType Directory -Force -Path $STAGE
          Copy-Item "target\release\trackly.exe" "$STAGE\trackly.exe"
          New-Item -ItemType File -Path "$STAGE\portable.txt" -Force
          Copy-Item "README-portable.md" "$STAGE\README.md"
          Copy-Item "trackly.config.toml.example" "$STAGE\trackly.config.toml.example"
          $ZIP_NAME = "trackly-v${env:VERSION}-windows-x64-portable.zip"
          Compress-Archive -Path "$STAGE\*" -DestinationPath $ZIP_NAME -Force
          echo "PORTABLE_ZIP=$ZIP_NAME" | Out-File -FilePath $env:GITHUB_ENV -Append

    11. name "Upload portable ZIP to release"
        if: matrix.platform == 'windows-latest'
        shell: bash
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run:
          Разрешить тег с учётом события — на workflow_dispatch GITHUB_REF_NAME равен имени ветки
          (например "main"), поэтому нужен явный fallback:

              TAG="v${{ github.event.inputs.version }}"
            else
              TAG="$GITHUB_REF_NAME"
            fi
            gh release upload "$TAG" "$PORTABLE_ZIP" --repo "${{ github.repository }}"

    12. name "Upload artifacts for checksums job"
        uses: actions/upload-artifact@v4
        with:
          name: release-artifacts-${{ matrix.platform }}
          path: |
            target/release/bundle/nsis/*.exe
            target/release/bundle/dmg/*.dmg
            target/release/bundle/appimage/*.AppImage
            target/release/bundle/deb/*.deb
            *-portable.zip
          if-no-files-found: warn
          retention-days: 1

    ВАЖНО: НЕ добавлять webviewInstallMode — Tauri 2 использует Evergreen по умолчанию (D-07).
    НЕ добавлять i686-pc-windows-msvc — только Win10 x64 (D-01).
    НЕ включать tauri-plugin-updater нигде в workflow (D-09).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| git tag → workflow trigger | Тег v*.*.* запускает pipeline; имя тега используется как версия |
| GitHub Actions runner → GitHub Release | GITHUB_TOKEN с contents: write загружает артефакты и создаёт Release |
| portable ZIP → пользователь Win10 | ZIP содержит исполняемый файл; portable.txt определяет режим записи данных |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
