Текущий (дефектный) `update_body` (`crates/trackly-app/src/services/template_service.rs:220-255`):

pub async fn update_body(
    &self,
    caller: &Identity,
    kind: &str,
    body: String,
) -> Result<(), AppError> {
    authorize(caller, &Action::ManageSettings)?;

    {
        let mut env = minijinja::Environment::new();  // ← ЛЕНИЕНТНОЕ окружение, БЕЗ autoescape,
        env.add_template_owned("_validate", body.clone())  //   БЕЗ UndefinedBehavior::Strict —
            .map_err(|e| AppError::Validation { ... })?;    //   ловит только синтаксис, не undefined vars
    }

    let filename = format!("{kind}.html");
    if !crate::pdf::html_templates::DEFAULT_HTML_TEMPLATES.iter().any(|(f, _)| *f == filename) {
        return Err(AppError::NotFound { entity: "document_template", id: 0 });
    }

    let templates_dir = self.templates_dir()?;
    tokio::fs::write(templates_dir.join(&filename), body).await
        .map_err(|e| AppError::Internal { source_chain: format!("write {filename}: {e}") })
}

Существующий `validate_preview` (уже строгий, `crates/trackly-app/src/services/template_service.rs:328-337`)

pub async fn validate_preview(&self, kind: &str, body: &str) -> Result<String, AppError> {
    let demo_ctx = demo_context_for_kind(kind);
    crate::pdf::minijinja_env::render_with_timeout(
        &crate::pdf::minijinja_env::build_safe_html_env(),
        "_preview",
        body,
        demo_ctx,
    )
    .await
}

`render_with_timeout` (`crates/trackly-app/src/pdf/minijinja_env.rs:68-107`) на ошибке парсинга/рендера
возвращает `AppError::Validation { field: "template".into(), message: ... }` — обратите внимание,
field = "template", а не "body"; существующий тест
`update_body_rejects_invalid_minijinja_syntax` (tests/template_edit.rs) ожидает
`AppError::Validation { field: "body", .. }` — сохранить этот контракт нужно явным ремаппингом
поля при переиспользовании validate_preview внутри update_body.

Текущие preview-iframe:

Ни один из компонентов не обращается к `contentWindow`/DOM внутри iframe (проверено — вся print-

экспорт, не через iframe), поэтому bare `sandbox` (deny-all: no-scripts, no-same-origin,
no-forms, no-popups, no-top-navigation) безопасен и не ломает никакую существующую
функциональность — iframe используется исключительно для статичного визуального превью.
