## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust: cargo test, suite-бинарники (`autotests = false`, `docs/TESTING.md`); UI: Node-гейты `ui/scripts/check-*.mjs`, `svelte-check`, `eslint`, `prettier` |
| **Config file** | `crates/trackly-app/Cargo.toml` `[[test]]`, `crates/trackly-app/tests/suites/*.rs`, `ui/package.json` (`lint`) |
| **Quick run command** | `DEVELOPER_DIR=/Library/Developer/CommandLineTools TRACKLY_AD_MOCK=1 TRACKLY_SNMP_MOCK=1 cargo test -p trackly-app --test app_groups groups_membership::` |
| **Full suite command** | `cargo test --workspace --no-fail-fast -- --test-threads=1` (в фоне, один процесс cargo) + `pnpm --dir ui lint` + `pnpm --dir ui svelte-check` + `cargo clippy --workspace -- -D warnings` + `cargo fmt --check` |
| **Estimated runtime** | точечная цель ~60–180 с; сплошной прогон — часы, только на границе фазы |

---

## Sampling Rate

- **After every task commit:** точечная цель (`--test app_groups groups_membership::<имя>`, `node ui/scripts/check-device-row-menu.mjs` и т.п.)
- **After every plan wave:** `cargo test -p trackly-app --test app_groups`, `--test app_gates`, `--test app_auth role_endpoint_matrix::`, `--test app_devices devices_crud::`, `pnpm --dir ui lint`, `pnpm --dir ui svelte-check`, clippy, fmt
- **Before `/gsd-verify-work`:** сплошной прогон зелёный + живая UAT (UI-SPEC §14.4)
- **Max feedback latency:** ~180 с на точечную цель
