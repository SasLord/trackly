# Phase 41.8 Plan 11: Дерево групп — двойники, правый клик, меню узла Summary

Вложенная группа видна по месту вложения и корнем своего типа с подписью «в {родитель}»; у узла работает правый клик и полное меню (Вывести из группы / Переместить в группу / Списать), перенос и списание подключены к странице.

## Задачи
1. Двойники в GroupTree: коммит 5a934275. Ключи group-{id}, in-type-{id}, in-type-{корень}-group-{id}; itemByKey/parentOf знают все; глубокая ссылка и «Открыть группу» по-прежнему ведут на основной узел; счётчик типа не пересчитывается.
2. GroupTreeNode: коммит f339baca. oncontextmenu + ContextMenu/Shift+F10 через ActionMenu.openAt (узел не выбирается); «Вывести из состава» заменено на «Вывести из группы»; «Переместить в группу» не рендерится у teardown (D-09); «Списать» только при anchor_status_code = на_списание; разделители hr role=separator, border-top у .menu-danger снят.
3. GroupsPage / GroupDeleteModal: коммит eb515d50. Тост «Группа «…» выведена из «…»», сетевая ошибка по плану; при отказе удаления группы футер — только «Закрыть».

## Отклонения
Нет. Замечания:
- У двойника и основного узла общий `group.id`, поэтому `onSelect` передаёт странице тот же узел; выбранным в дереве остаётся именно нажатый ключ.
- `hr role="separator"` даёт 3 предупреждения svelte-check «Redundant role» (хотели по критерию плана; гейты их не краснят).
