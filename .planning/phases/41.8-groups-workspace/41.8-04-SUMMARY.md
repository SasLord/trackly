# Phase 41.8 Plan 04: призраки, правила вложения, защита удаления разбора

Сервер отдаёт призраков разбора и поля для UI, отказывает во вложении «Разбора» и в тихом перехвате вложенной группы, а удаление разбора блокируется, пока с ним связаны детали или призраки.

## Задачи

1. DTO и чтение, коммит 3892f448 (вместе с задачей 2, правки одного файла сервиса): GroupGhostDeviceDto, ghosts в composition (один вызов ghost_devices, только teardown), anchor_status_code, type_behavior в поиске, replace_parent с `serde(default)`.
2. set_parent и delete_group, тот же коммит. Tauri-адаптер передаёт replace_parent; HTTP идёт через тот же build_groups_set_parent.
3. Тесты, коммит 4ff5bdbc. Починены вызовы set_parent в 5 файлах (false; true там, где перевешивание намеренное: `membership_place_invariant_walk`). Новые тесты: призраки (выведенная, списанная, удалённая, чужой origin, живой член; счётчики не меняются; current_group; у не-teardown пусто), отказ удаления с удалённой деталью и текст, пустой разбор удаляется, D-09 (в т.ч. replace не снимает запрет), D-16 (AlreadyInGroup, с флагом успех), инфра-страж: set_parent_in_tx по-прежнему вкладывает teardown.
