## Границы доверия

| Граница | Описание | Что пересекает |
|---------|----------|----------------|
| LAN-браузер → axum `/api/v1/groups_*`, `/api/v1/devices_update` | Сессия tower-sessions, роль из сессии; те же `build_*`, что у Tauri | id групп/устройств, version, флаги `release_from_group`, `replace_parent`, `change_status`, `group_write_off` |
| Tauri webview → invoke | Десктоп-идентичность через `resolve_tauri_identity` | то же |
| Клиент → `devices.create(origin_group_id)` | Клиент сам называет группу происхождения детали | id группы разбора |
| Сервис → SQLite / audit_log | Параметры запросов из id, заданных клиентом; payload аудита с id устройств и групп | id, снимки DeviceDto |
| Сервер → клиент | Отказ `ALREADY_IN_GROUP` (имена групп), состав с призраками, предпросмотр смены статуса | имена групп, число устройств |
| UI → API | Скрытие пунктов меню и модалки — только UX; граница — сервер | — |
| Код → CI-гейты | Гейт, зелёный при снятой защите, равен отсутствию защиты | — |
| dev-БД → репозиторий (публичный) | Данные живой приёмки не должны попасть в коммиты | обезличенные описания UAT |
