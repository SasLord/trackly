# Phase 41.8 Plan 34: чекбокс смены статуса в попапе переноса группы (D-34) Summary

В GroupMoveModal добавлен чекбокс «Поменять статус на «...»» по серверному предпросмотру `groups.moveStatusPreview`; выбор уходит в `groups.move` как `change_status`, структура закреплена гейтом `check-group-move-status` в lint.

## Сделано

1. **Task 1** (57a8414d): `GroupMoveModal.svelte`. `$effect` по выбранному месту вызывает предпросмотр внутри `untrack`, ответ записывается только при совпадении локального номера с `previewSeq` (плюс флаг `stale` в cleanup); при смене места `changeStatus` возвращается в true. Чекбокс показывается при `transition != null` и непустом `target_status_name`, подпись и число с сервера, склонение «у N устройств» через `pluralizeRu`. При N = 0 чекбокс отключён и снят, подсказка «Подходящих устройств нет: статусы не изменятся». `change_status = preview?.transition != null && devices_affected > 0 && changeStatus`. Сбой предпросмотра - без тоста, чекбокса нет; VALIDATION выводится в `placeError`. `notifyPlaceContentChanged` остался в `confirmMove` рядом с `groups.move(`.
2. **Task 2** (77af78cb): `check-group-move-status.mjs`, правила [M1]-[M6], selftest на 6 мутантов (каждый с уникальным якорем краснит своё правило), подключён в `lint` перед `check-lint-selftest-wiring`. Мутация реального исходника (снято сравнение с `previewSeq`): красный [M2]; восстановление из копии в scratchpad, `cmp` чистый.
3. **Task 3** (c9ca7ee7): UI-SPEC §12.7 «Смена статуса при переносе группы (D-34)» и строка гейта в §17.
