## What Was Built

### Task 1 — DEF-2B: condition в GROUP BY (fccd04b)

**SQL изменение** в `list_grouped`:
- `GROUP BY d.type_id, d.name` → `GROUP BY d.type_id, d.name, d.condition`
- `d.condition` теперь прямая проекция вместо `MAX(d.condition)` — repr.state точно соответствует condition группы
- LEFT JOIN subquery расширен: добавлено `AND d2.condition IS d.condition` — IS (не =) для корректной работы с NULL (SQLite: NULL IS NULL = TRUE, NULL = NULL = NULL)
- Без этого расширения subquery получил бы location из устройства с другим condition (cross-contamination repr)

**UI**: добавлен `{#if g.repr.state}<span class="opt-state">{g.repr.state}</span>{/if}` после блока SN/инв./×count в dropdown `ActFormItemsTable.svelte`; `.opt-state` стиль аналогичен `.opt-model`.

**Тесты**:
- `condition_key_splits_groups`: 2 устройства с разным condition → 2 группы; repr.state не cross-contaminated
- `condition_key_same_condition_collapses`: 2 устройства с одинаковым condition → 1 группа count=2
- `grouping_groups_devices_with_same_name_and_different_condition`: обновлён под новую семантику (ожидает 2 группы вместо 1)

### Task 2 — DEF-3: resolved_location_id в handover-UPDATE (237fa82)

**Однострочный fix** в `act_service.rs` ~424:
```
- payload.location_id,
+ resolved_location_id,
```
`resolved_location_id` вычисляется выше (~строка 258) из `payload.location_name` через `resolve_location_id_in_tx`. До фикса акты через location_name давали `payload.location_id=None` → `devices.location_id` не обновлялся.

**do_return**: логика `effective_location` не изменена; добавлен комментарий документирующий контракт (если `effective_location=None`, caller должен передать `bulk_location_name` или `location_name_override`).

**Integration test** `handover_via_location_name_sets_device_location_id`:
1. Создаёт handover via `location_name: Some("Отдел кадров")`, `location_id: None`
2. Проверяет `devices.location_id == resolved_handover_loc_id` (core DEF-3 assertion)
3. Вызывает `do_return` с `bulk_location_name: Some("Склад-ОК")`
4. Проверяет `devices.location_id == return_loc_id`
