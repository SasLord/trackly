## What Was Built

### Task 1 — PersonAutocomplete handleFocus (3377478)

Добавлена функция `handleFocus` в `PersonAutocomplete.svelte`:
- Сбрасывает `suppressDropdown = false` и `lastSelected = null`
- Вызывает `acts.suggestPerson(field, value)` через `setTimeout(0)` напрямую, обходя `$effect` (который блокируется guard `v.length < 1`)
- Добавлен `onfocus={handleFocus}` на `<input>`
- Убран guard `value.length > 0` в `handleKeydown` ArrowDown-ветке — ArrowDown при пустом поле тоже открывает дропдаун
- `onMount`-seed (edit-mode pre-fill: `suppressDropdown=true`) не изменён — пользовательский фокус явно сбрасывает suppression

### Task 2 — DeviceAutocompleteField handleFocus (8ef17cb)

Аналогичный паттерн в `DeviceAutocompleteField.svelte`:
- `handleFocus` сбрасывает suppression, вызывает `devices.autocomplete(field, value, contextName, contextStatusId, statusIn)` с `delay=0`
- `onfocus={handleFocus}` добавлен на ОБА элемента: `<textarea>` (multiline) и `<input>`
- Убран guard `value.length > 0` в ArrowDown-ветке `handleKeydown`

### Task 3 — ActFormItemsTable getSelectedIds (f6eacbc)

Добавлена функция `getSelectedIds(excludeIdx: number): Set<number>` в `ActFormItemsTable.svelte`:
- Собирает все `group_ids` из `picked=true` строк, исключая строку с `excludeIdx`
- В `handleQueryInput`: результаты `devices.listGrouped` фильтруются через `getSelectedIds(idx)` до записи в `suggestionsByRow[idx]`
- В дропдаун-рендере: inline-фильтр `filter((g) => !g.ids.some((id) => getSelectedIds(idx).has(id)))` — fallback для стале-загруженных suggestions
