<objective>
Close two of the three confirmed BLOCKER gaps from 24-VERIFICATION.md: (1) CMP-02's `bind:value` is currently
one-way in Input/Select/Textarea because all three destructure props with `const` and hand the native element
a one-way `{value}` attribute instead of `bind:value` — parent state silently never updates; (2) D-09's
theme-switch transition suppression rule in `global.scss` is wrapped in `:global(...)`, a Svelte-scoped-style
selector that is meaningless in a plain `.scss` file processed by sass/Vite — it survives verbatim into the
compiled CSS as an invalid selector the browser ignores, so `theme-switching` class toggling has zero effect.

Purpose: Input/Select/Textarea are the form primitives every phase 25-30 screen will build on — a silently
broken two-way bind would ship stale data to the backend from every future form. The D-09 fix is a one-line
syntax correction that unblocks the already-correct transition-suppression logic in `theme.svelte.ts`.
Output: Working two-way `bind:value` on all three text-entry primitives; a functioning `.theme-switching`
transition-suppression rule in the compiled CSS.
</objective>
