    `aria-controls` target from Plan 26-01 Task 2).

    Introduce a small reactive `isDesktop` boolean via `window.matchMedia('(min-width: 1024px)')`
    with a change listener (set up in an `$effect`, cleaned up on teardown) — this is the ONE
    intentional exception to "no matchMedia" because `inert` is a DOM attribute, not stylable via
    pure CSS. **Correctness-critical pitfall to avoid:** do NOT gate the aside's `inert` purely on
    `!sidebarNav.open` — `sidebarNav.open` defaults to `false`, and applying `inert` whenever it is
    `false` would make the desktop (`>=1024px`) sidebar permanently non-interactive. `inert` must be
    `!isDesktop && !sidebarNav.open`. When the matchMedia listener detects a transition to desktop
    while the drawer is open, call `closeNav()` so state does not desync across a resize.

    `.sidebar-container` responsive behavior: `>= 1024px` (i.e. `isDesktop`) — unchanged
    (`position:sticky; top:0; height:100vh; overflow:hidden`). `< 1024px` — via a `@media (max-width: bp.$bp-lg - 1px)`
    block (`@use '../../styles/_breakpoints' as bp;`): `position:fixed; inset-block:0; left:0;
    width:236px; z-index:60; transform:translateX(-100%); transition:transform .18s ease;
    box-shadow:var(--tr-elev-3);`, and `&.open { transform: translateX(0); }` bound via `class:open={sidebarNav.open}`
    on the `<aside>`. Wrap the transition in `@media (prefers-reduced-motion: reduce) { transition: none; }`.

    Backdrop: render `{#if sidebarNav.open && !isDesktop}<div class="nav-backdrop" ...>` reusing
    Modal's `mousedown`/`mouseup`-on-target-only dismiss pattern (not bare `onclick`, to avoid the
    text-selection-drag-closes-modal bug the codebase already fixed once for Modal). Style:
    `position:fixed; inset:0; background:var(--tr-overlay); z-index:55`.

    Escape-to-close: `<svelte:window onkeydown={sidebarNav.open ? handleKeydown : undefined} />`
    where `handleKeydown` calls `closeNav()` on `e.key === 'Escape'`.

    Auto-close on route change: `import { router } from 'svelte-spa-router';` then an `$effect(() => { void router.location; closeNav(); })` — this single mechanism covers BOTH "click any nav link" and "route changes" from UI-SPEC §6.3 (a nav-link click always triggers a route change via `use:link`), so `Sidebar.svelte` (owned by the parallel Plan 26-02) needs NO changes to close the drawer.

    Focus management — mirror `Modal.svelte` lines 67-86 exactly: an `$effect` keyed on `sidebarNav.open`

    pattern from `Modal.svelte` (lines 159-167), guarded on `sidebarNav.open && !isDesktop`.
