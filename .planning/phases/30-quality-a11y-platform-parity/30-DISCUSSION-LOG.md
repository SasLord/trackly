| Option | Description | Selected |

| Скрипт по токен-парам | check-contrast.mjs считает WCAG по парам hex из _tokens.scss (обе темы), падает при <AA; durable-гейт как check-tokens.mjs; починка правкой центрального токена, крупный текст 3:1 — документированное исключение | ✓ |

## Кольцо фокуса: охват аудита

| Option | Description | Selected |
|--------|-------------|----------|
| Baseline + тип-аудит + фикс клипов | Сохранить глобальный *:focus-visible; аудит по типам интерактива на голый outline:none и клип box-shadow-кольца overflow:hidden; точечная починка (inset-ring где клип) | ✓ |

## Форма сдачи: durable-гейт vs ручной чек-лист

| Option | Description | Selected |
|--------|-------------|----------|
| Гибрид: автогейт + ручной UAT | Скрипт контраста в lint/CI + лёгкий линт на голый outline:none + финальный both-theme ручной UAT на клипы/паритет | ✓ |
| Только ручной UAT | Без новых скриптов — только both-theme визуальный чекпоинт (прецедент Ф.26–29) | |
| Только автоскрипты | Скрипты контраста/фокуса без финального ручного UAT — но клипы/паритет машина не видит | |

**User's choice:** Гибрид: автогейт + ручной UAT (Rec)
**Notes:** Контраст и голый outline:none машина ловит надёжно (регресс-защита); клипы/наложения/паритет требуют глаз. UAT-чекпоинт делать блокирующим (урок Фазы 24: авто-одобрение маскировало непроверенное).
