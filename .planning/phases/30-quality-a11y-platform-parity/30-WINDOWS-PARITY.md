## Как запускать

1. На Windows-машине собрать фронтенд: `pnpm --dir ui build`.
2. Сравнить `cargo tauri dev` (десктоп, WebView2) против серверного/LAN-режима, отдающего
   тот же `ui/dist`, открытого в Edge/Chrome на той же Windows-машине — по колонкам
   таблицы выше (обе темы через `ThemeSwitcher`).

Результат прогона — **не блокер** закрытия фазы 30 / milestone v1.2 (D-03,
`30-CONTEXT.md`); фиксируется здесь исключительно для трекинга технического долга по
Windows/WebView2-паритету.
