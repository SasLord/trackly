<objective>
Закрыть Gap 1 (обрезанное кольцо на переключателе периода Дашборда) и Gap 2 (весь app-shell
скроллится вместе с контентом Дашборда вместо изолированного скролла контентной области) — два

Purpose: QA-02 (ROADMAP SC #2 — видимое, не обрезаемое кольцо) и QA-03 (ROADMAP SC #3 —
desktop↔LAN визуальный/layout паритет; фиксированный shell — часть паритетного контракта, т.к.
и WKWebView, и LAN Chrome должны вести себя идентично относительно того, ЧТО именно скроллится).

Gap 1 root cause (диагностировано на этапе планирования, не гипотеза): `.period-toggle { display:
flex; gap: 2px; overflow-x: auto; }` (PeriodToggle.svelte) — установка ТОЛЬКО `overflow-x` без
явного `overflow-y` заставляет браузер вычислить `overflow-y` как `auto` (CSS 2.1 §11.1.1: если
`overflow-x` не `visible`, а `overflow-y` остаётся `visible` — используемое значение `overflow-y`
принудительно меняется на `auto`). Это создаёт СКРЫТЫЙ клип-контейнер по вертикали, обрезающий
outward-кольцо `.toggle-btn:focus-visible`'s `box-shadow: 0 0 0 3px var(--tr-focus-ring)` — тот же
класс дефекта, что чинили в 30-02 (kebab/chevron), просто с менее очевидным источником клипа (не
явный `overflow: hidden` на видимом контейнере, а неявный побочный эффект `overflow-x`).

Gap 2 root cause (диагностировано, не гипотеза): `DashboardPage.svelte`'s `.dashboard-grid { flex:
1; overflow: auto; ...padding: 24px; }` НЕ имеет `min-height: 0`. Flex-элементы по умолчанию имеют
`min-height: auto` (= "automatic minimum size", содержимое-based) — без явного `min-height: 0`
элемент отказывается сжиматься меньше высоты своего содержимого (widgets + ChartWidget), даже с
`flex: 1` и `overflow: auto` на себе. Это ИДЕНТИЧНЫЙ класс бага, который уже был исправлен для
`ActsPage.svelte`'s `.page-content` (комментарий «FIX B1» в файле) и для `EmployeeLayout.svelte`'s
`.employee-content` (Phase 29 commit `61feaa7`) — `DashboardPage.svelte` единственная из основных
страниц, где этот фикс ещё не применён. Родительский shell (`Layout.svelte`'s `.content`) УЖЕ
корректен (`overflow: auto; min-height: 0;`, `ui/src/features/layout/Layout.svelte:169-173`) — не
трогается в этом плане, только сам `DashboardPage.svelte`.

Output: `PeriodToggle.svelte` с inset-кольцом; `DashboardPage.svelte` с `min-height: 0` на
`.dashboard-grid`.
