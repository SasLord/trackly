## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust `cargo test` (suite-бинарники `app_repairs`, `app_gates`, `app_server`; infra `repairs_repo`); UI: eslint + prettier + `svelte-check` + `ui/scripts/check-*.mjs` |
| **Config file** | `crates/trackly-app/Cargo.toml` `[[test]]` + `crates/trackly-app/tests/suites/*.rs`; `ui/package.json` (`lint` НЕ включает svelte-check/clippy/fmt) |
| **Quick run command** | `cargo test -p trackly-app --test app_repairs employee_devices` ; `pnpm --dir ui lint` ; `pnpm --dir ui svelte-check` |
| **Full suite command** | `ci-full` (сплошной прогон, один `cargo test` за раз, в фоне) + `cargo clippy --workspace -- -D warnings` + `cargo fmt --check` + `pnpm --dir ui build` |
| **Estimated runtime** | quick ~60–180 s; full — часы (см. память проекта), только на границе фазы |

---

## Sampling Rate

- **After every task commit:** целевой cargo-тест задачи + `pnpm --dir ui lint`, если затронуты UI/скрипты
- **After every plan wave:** `pnpm --dir ui svelte-check`, `cargo clippy`, `cargo fmt --check`, `pnpm --dir ui build`, затронутые suite-бинарники
- **Before `/gsd-verify-work`:** сплошной прогон зелёный
- **Max feedback latency:** ~180 s (точечные цели)
