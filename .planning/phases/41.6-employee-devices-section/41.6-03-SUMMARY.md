# Phase 41.6 Plan 03: кирпичи UI для раздела сотрудника

Аддитивные основы: признак принтера в `PrinterMark`, общая `tonerFillColor`, чистая карта тонов статуса, компонент `TonerMini` (минимум среди известных уровней, три состояния, aria-label/title с датой опроса).

## Что сделано

- `PrinterMark`: необязательные `typeId` и `isPrinter`; при переданном `isPrinter` он решает показ, существующие вызовы не менялись.
- `tonerFill.ts` без импортов; `TonerGauge` использует её, литералов порогов в компоненте не осталось.
- `deviceStatusTone.ts` без runtime-импортов: карта `TONES` и `statusTone`; `deviceStatuses.svelte.ts` импортирует и реэкспортирует (типы тоже), сигнатура прежняя.
- `TonerMini.svelte`: трек 32x8, токены `--tr-*`, API не вызывает.
