## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Клиент → `employee_devices_list` (axum `/api/v1/employee_devices_list`, Tauri-команда) | Параметров нет; идентичность только из сессии (HTTP) или системного администратора (десктоп) | ничего от клиента; в ответе — DTO устройств области |
| Сервис → репозиторий | `user_id` из сессии уходит в SQL только параметром `?1` | id пользователя |
| Репозиторий → DTO | origins содержат имена групп; в DTO уходят только имена привязанных групп самого сотрудника | имена АРМ, описание устройств, уровень тонера |
| Сервер → WS-клиент | Событие доставляется по `is_visible_to` роли сессии | сигнал `employee_scope_changed` без данных |
| Форма заявки ← prefill | deviceId из prefill — подсказка UI; границу держит сервер при создании | id устройства |
| Шапка / маршрутизатор сотрудника → маршруты | Только разрешённые сотруднику hash-маршруты | — |
| UI-компоненты сотрудника → API | Чистые компоненты API не вызывают; страница вызывает одну read-команду | — |
| Репозиторий (публичный) / стенд UAT | Всё закоммиченное остаётся в истории git | тестовые данные, описания UAT |
