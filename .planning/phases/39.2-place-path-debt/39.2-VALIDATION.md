  за раз) + `cd ui && pnpm lint` + `pnpm svelte-check`
- **Max feedback latency:** ~15 s (quick) / ~360 s (full wave gate)

## Ограничение фазы: обратная совместимость поведения

Фаза рефакторит владельца дефолтов и робастность, **не меняя ни одного результата,
видимого пользователю на исправной БД**. Это проверяемо, и проверка обязана стоять
на каждой волне:

```
cargo test -p trackly-core shorten_place_path_matches_golden_fixture -- --test-threads=1
cd ui && node scripts/check-placepath-parity.mjs
cd ui && node scripts/check-place-path-short.mjs
```

Оба гейта паритета (`scripts/fixtures/place-path/shorten-cases.json`, 23 кейса)
добавлены аудитом 2026-09-01 и обязаны остаться зелёными **без правки фикстуры**.
Красная фикстура в этой фазе означает не «надо обновить ожидания», а «рефакторинг
изменил наблюдаемое поведение» — то есть выход за границы фазы.
