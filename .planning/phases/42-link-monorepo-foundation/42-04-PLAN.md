Собирает: версию/сборку/разрядность ОС (`[Environment]::Is64BitOperatingSystem`, `Win32_OperatingSystem` Caption/BuildNumber/ProductType, ProductType 3 = сервер); версию WebView2 Runtime (значение `pv` в `HKLM:\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}` и `HKCU:\Software\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}`, «установлен» = любое значение больше `0.0.0.0`); наличие `trackly-link.exe` в ДВУХ путях (`$env:LOCALAPPDATA\Programs\Trackly Link\` и `$env:LOCALAPPDATA\Trackly Link\`), запись `HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\Trackly Link` (DisplayVersion, InstallLocation), разрядность exe чтением PE-заголовка (Machine 0x8664 = x64); `Get-AuthenticodeSignature` — в файл итога только Status и «подписан/не подписан», Subject — только на экран с пометкой «не пересылать»; события AppLocker из журналов `Microsoft-Windows-AppLocker/EXE and DLL` и `.../MSI and Script` с фильтром по `*trackly-link*` (ID 8002 разрешено, 8003 audit, 8004 заблокировано, 8005-8007) и режим EnforcementMode эффективной политики числом правил по коллекциям, без путей; SRP — события провайдера `Microsoft-Windows-SoftwareRestrictionPolicies` и ключ `HKLM:\SOFTWARE\Policies\Microsoft\Windows\Safer\CodeIdentifiers` (DefaultLevel, PolicyScope); сеанс: `$env:SESSIONNAME` (RDP-Tcp или Console), роли/ProductType, только ЧИСЛО активных сеансов; пробный запуск exe (`Start-Process -PassThru`, ожидание 5 с, `HasExited`/`ExitCode`, затем события AppLocker за последнюю минуту). Итог — JSON-файл в `$env:TEMP`, содержащий ТОЛЬКО обезличиваемые поля. Имя компьютера, имя пользователя, IP, домен и Subject в файл итога не попадают никогда; в шапке объяснить это словами без перечисления самих переменных окружения в исполняемых строках.

`install-silent.ps1` — имитация вызова из скрипта входа GPO: параметр `-Installer <путь>`; выполняет `Start-Process -FilePath $Installer -ArgumentList '/S',"/D=$env:LOCALAPPDATA\Programs\Trackly Link" -Wait -PassThru` (`/D=` обязан идти последним и без кавычек); проверяет ExitCode 0, наличие `trackly-link.exe` в целевом каталоге, запись HKCU Uninstall, ярлык в меню «Пуск»; идемпотентен (повторный запуск при установленной версии не ломается); режим `-Uninstall` вызывает `uninstall.exe /S` из InstallLocation и проверяет исчезновение каталога, ярлыка и записи реестра. Имя установщика — параметр, не хардкод. Тестовый CN в любых примерах — «Link Pilot Test».

Если `pwsh` доступен — проверить синтаксис `[System.Management.Automation.Language.Parser]::ParseFile`; если нет — зафиксировать «синтаксис не проверен: pwsh отсутствует» в SUMMARY.
