## Secret-Leak Guard: End-to-End Path

`logging::tests::secret_through_tracing_writes_redacted_marker_to_file`:

1. `Secret::new(String::from("hunter2"))` — wraps the secret.
2. Builds a scoped subscriber (`tracing_subscriber::Registry + fmt::layer().with_writer(non_blocking).with_ansi(false)`) — scoped so it doesn't fight the global subscriber from concurrent tests.
3. `tracing::subscriber::with_default(subscriber, || { tracing::info!(secret = ?secret, "log line with secret"); });` — emits the event through the `?`-formatter (Debug).
4. `drop(guard)` — non-blocking appender flushes.
5. Reads `<tempdir>/logs/trackly.log.<today>` → asserts `contents.contains("***")` AND `!contents.contains("hunter2")`.

This is the runtime mirror of the Plan 04 compile-gate (`static_assertions::assert_not_impl_all!(Secret<String>: serde::Serialize)`).
