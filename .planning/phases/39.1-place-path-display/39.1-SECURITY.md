## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Tauri invoke / axum HTTP → `settings_set_place_path_defaults` | Мутирующая точка входа настроек организации; требует `Action::ManageSettings` | `variant`, `sep_ends`, `sep_last_two` — произвольные пользовательские строки |
| Tauri invoke / axum HTTP → `places_set_path_variant` | Мутирующая точка входа на конкретном месте; требует `Action::MutatePlaces` (D-12) | `path_variant_override` (токен варианта), `version` (CAS) |
| SQL-вью `place_effective_variant` → `app_settings` | Read-only разрешение эффективного варианта восходящим обходом дерева | `path_variant_override` мест + организационный дефолт |
| `shorten_place_path` (trackly-core) ← вызывающие слои | Чистая функция без I/O, вызывается из devices/cartridges/reports/acts read-path | Уже провалидированные строки пути |
| `act_service::render_pdf` → `place_effective_variant` / `app_settings` | Только чтение при печати акта; `place_id` провалидирован при создании акта | Замороженный снимок `place_path_snapshot` (D-16) + текущий вариант (D-20) |
| minijinja-шаблоны актов | Рендерят готовые Rust-строки; форматирующей логики не содержат (Pitfall 3) | `act.place_path_short` |
| `export_csv` → третьи лица | CSV покидает приложение без hover-подсказок — полный путь обязателен (D-18) | Полный `place_path` |
| Фронтенд-формы (`OrgSettings.svelte`, `PlaceFormModal.svelte`) → бэкенд | Фронт не источник истины по валидации — гейт на сервере | Те же поля, что выше |
