# Phase 39.1 Plan 08: Формат пути — подраздел в OrgSettings Summary

**Новый подраздел «Формат отображения пути места» под логотипом организации: радио-группа варианта, два независимых поля разделителей со значимыми пробелами (mono-шрифт + readout-в-точках), живой предпросмотр 3×2, отдельная кнопка сохранения поверх backend'а из плана 02.**

## Performance

- **Duration:** ~35 мин
- **Completed:** 2026-08-28
- **Tasks:** 2/2
- **Files modified:** 3

## Accomplishments

- `Input.svelte` расширен необязательным `mono?: boolean` пропом (дефолт `false`, полная обратная совместимость с ~30 существующими вызовами) — `.input.mono { font-family: var(--tr-font-mono) }`.
- `placePath.ts` получил `previewShortenPath(fullPath, variant, sepEnds, sepLastTwo)` — параметризованное зеркало Rust `shorten_place_path` (D-13..D-16: разделитель ставится только когда реально что-то выброшено; путь из ≤2 сегментов всегда полный через штатный ` / `) — и `monoReadout(v)` (заменяет только U+0020 на «·» для `.field-hint`). Старые `shortenPlacePath`/`normalizePlacePathDisplay`/`PlacePathDisplay` не тронуты (их удалит план 10).
- `OrgSettings.svelte`: подраздел `.path-section` сразу после `.logo-section`, буквально по DOM-контракту UI-SPEC.md «Поверхность 1» — `role="radiogroup"` с тремя `<Radio bind:group={pathVariant}>`, `.form-grid.path-sep-fields` с двумя `mono`-полями (каждое с `.field-hint.tr-mono` readout и D-10 empty-value `.field-error`, **независимо** видимыми и активными вне зависимости от выбранного радио), `<table class="path-preview">` 3×2 с шестью `$derived`-ячейками, пересчитывающимися на каждый keystroke, и кнопка «Сохранить формат пути».
- `loadPathDefaults()`/`savePathDefaults()` вызывают `settings_get_/set_place_path_defaults` (план 02) тем же try/catch + `pushToast` паттерном, что `loadOrg()`/`saveOrg()`; `loadPathDefaults()` добавлен в существующий `onMount` рядом с `loadOrg()`.

## Decisions Made

- `OrgPathDisplayDto` объявлен локально в `OrgSettings.svelte` (не импортирован из `ui/src/bindings.ts`), как и остальные DTO этого файла — сохраняет однородность файла и не создаёт зависимости от generated/gitignored файла в исходниках компонента (сам `apiCall` всё равно типобезопасен через дженерик).
- Radio/Input подраздела получили `disabled={savingPath}` — явное требование states matrix UI-SPEC.md («Disabled (во время сохранения)»), не продиктованное дословно в `<action>` плана, но необходимое для соответствия UI-SPEC контракту (Rule 2).
- `.sr-only`/`.field-hint`/`.field-error` продублированы локально в стилевом блоке `OrgSettings.svelte` — Svelte scoped styles не позволяют шарить CSS-классы между файлами без общего глобального стиля; скопированы буквально из существующих прецедентов (`ChartWidget.svelte::.sr-only`, `PlaceFormModal.svelte::.field-hint/.field-error`).
