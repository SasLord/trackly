# Phase 39.1 Plan 05: place_path_short во всех 5 доменах отчётов + CSV/PDF асимметрия Summary

**All 5 report-domain SQL builders now LEFT JOIN `place_effective_variant` and populate `ReportRow.place_path_short`, and `row_field` gained an explicit `shorten: bool` fourth parameter so CSV (`export_csv`, always `false`, D-18) and PDF/print (`export_pdf`, always `true`, D-17) can never drift back into lockstep on the same column.**

## Performance

- **Duration:** ~25 min
- **Completed:** 2026-08-28
- **Tasks:** 2
- **Files modified:** 6 (1 created, 5 modified)

## Accomplishments

- `ReportRow.place_path_short: Option<String>` added to `crates/trackly-app/src/dto/reports.rs`, right after `place_path` (mirrors `DeviceRow`'s Plan 03 precedent).
- Two shared helpers added to `report_service.rs`: `read_path_display_separators(conn)` (reads `place_path_sep_ends`/`place_path_sep_last_two` from `app_settings`, falling back to the V039-seeded defaults) and `compute_place_path_short(full_path, effective_variant, sep_ends, sep_last_two)` (chains `PathDisplayVariant::from_str` + `shorten_place_path`, `None` on any missing input).
- All 5 domain query functions (`query_acts_inner`, `query_device_snapshot`, `query_cartridge_audit`, `query_cartridge_snapshot`, `query_requests_inner`) gained a second `LEFT JOIN place_effective_variant pev ON pev.place_id = <same fk as the existing place_full_paths join>`, an extra `pev.effective_variant AS place_variant` SELECT column, one `read_path_display_separators(conn)` call per query (not per row), and a `compute_place_path_short(...)` call inside each row-mapping closure.
- `row_field` signature changed to `fn row_field(row: &ReportRow, col: &str, tz: UtcOffset, shorten: bool) -> String`. The `"place_path"` arm switches between `row.place_path_short`/`row.place_path` on `shorten`; the `"printer_place"` arm narrows only the place-path argument passed into `combine_printer_and_place`, leaving the printer-name argument (and `combine_printer_and_place`'s own signature) completely untouched. `export_csv`'s call site now passes a literal `false`; `export_pdf`'s call site now passes a literal `true`.
- 6 new integration tests in `crates/trackly-app/tests/report_place_path_short.rs` prove, via the real public `ReportService` API (`list_device_acts`, `list_device_in_stock`, `list_cartridge_consumption`, `list_cartridge_in_stock`, `list_requests_all`) against a real 3-segment place tree, that all 5 domains carry the D-16 «Ends»-shortened path (`"Здание А // Кабинет 214"` from `"Здание А / 2 этаж / Кабинет 214"`, fresh-DB org default), and that a placeless device row yields `place_path_short: None`.
- 4 new unit tests in `report_service.rs`'s existing test module lock down `row_field`'s asymmetry: `shorten=false`/`shorten=true` divergence on `"place_path"`, printer-name identity across both modes on `"printer_place"`, and `csv_pdf_asymmetry_same_report_response_differs_on_place_path` — the exact same `ReportRow` read twice (once as CSV, once as PDF) produces two different strings for the same logical cell, CSV always the longer one.
