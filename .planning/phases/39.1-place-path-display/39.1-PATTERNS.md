### `migrations/V039__place_path_display.sql` (migration)

**Аналог 1 — таблица + seed:** `migrations/V016__cartridges_kind_color_settings.sql:37-44`
```sql
CREATE TABLE app_settings (
  key            TEXT    NOT NULL PRIMARY KEY,
  value          TEXT    NOT NULL,
  created_at_utc INTEGER NOT NULL,
  updated_at_utc INTEGER NOT NULL
);
INSERT INTO app_settings (key, value, created_at_utc, updated_at_utc)
  VALUES ('low_stock_threshold', '2', unixepoch(), unixepoch());
```
`app_settings` уже существует (создана в V016) — V039 только `INSERT ... ON CONFLICT DO NOTHING`
или прямой `INSERT` трёх новых ключей (`place_path_variant`='ends', `place_path_sep_ends`=' // ',
`place_path_sep_last_two`=' / '), таблицу заново не создаёт.

**Аналог 2 — рекурсивный CTE-вью:** `migrations/V037__places.sql:24-40`
```sql
CREATE VIEW place_full_paths AS
WITH RECURSIVE path_cte(id, path, parent_id) AS (
  SELECT id, name, parent_id FROM places WHERE deleted_at_utc IS NULL
  UNION ALL
  SELECT pc.id, p.name || ' / ' || pc.path, p.parent_id
  FROM path_cte pc
  JOIN places p ON p.id = pc.parent_id
  WHERE p.deleted_at_utc IS NULL
)
SELECT id AS place_id, path AS full_path
FROM path_cte
WHERE parent_id IS NULL;
```
Новый `place_effective_variant` — тот же скелет (`WITH RECURSIVE ... WHERE parent_id IS NULL`),
но восходящий обход (к `parent_id`, не к детям) с ранней остановкой на первом непустом
`path_variant_override` + `COALESCE` на `app_settings.place_path_variant` в терминальном SELECT
(готовый черновик — RESEARCH.md § Pattern 2, не буквальная реализация).

**Новая колонка:** добавить `places.path_variant_override TEXT NULL` через `ALTER TABLE places ADD
COLUMN` — миграция V038, ближайший прецедент `ALTER TABLE`-миграции на `places`-соседей
(`acts.place_id`), посмотреть форму `ALTER TABLE ... ADD COLUMN` там же.

**Следующий свободный номер:** `V039` (последняя существующая — `V038__places_migrate_devices_acts_cartridges.sql`, `ls migrations/` подтверждён).

### `crates/trackly-app/src/tauri_cmds/settings_org.rs` (controller, request-response)

**Аналог:** `build_settings_get_low_stock_basis` / `build_settings_set_low_stock_basis`
(строки 241-296 того же файла) — буквальный образец для копирования:
```rust
pub async fn build_settings_get_low_stock_basis(ctx: &AppCtx) -> Result<String, AppError> {
    let readers = ctx.readers.clone();
    tokio::task::spawn_blocking(move || -> Result<String, AppError> {
        let conn = readers.acquire();
        let result: rusqlite::Result<Option<String>> = conn.query_row(
            "SELECT value FROM app_settings WHERE key = 'low_stock_basis'",
            [], |r| r.get(0),
        );
        let basis = match result {
            Ok(Some(s)) => LowStockBasis::parse(s.trim()).unwrap_or(LowStockBasis::DEFAULT),
            Ok(None) => LowStockBasis::DEFAULT,
            Err(rusqlite::Error::QueryReturnedNoRows) => LowStockBasis::DEFAULT,
            Err(e) => return Err(map_rusqlite(e)),
        };
        Ok(basis.as_str().to_string())
    }).await.map_err(|e| AppError::Internal { source_chain: format!("spawn_blocking: {e}") })?
}

pub async fn build_settings_set_low_stock_basis(
    ctx: &AppCtx, caller_identity: &Identity, basis: String,
) -> Result<(), AppError> {
    authorize(caller_identity, &Action::ManageSettings)?;
    let parsed = LowStockBasis::parse(&basis).ok_or_else(|| AppError::Validation {
        field: "basis".to_string(),
        message: format!("Недопустимое значение базы подсчёта: {basis}"),
    })?;
    let now = ctx.clock.unix_seconds();
    let value = parsed.as_str().to_string();
    ctx.writer.execute(move |conn| {
        conn.execute(
            "INSERT INTO app_settings (key, value, created_at_utc, updated_at_utc) \
             VALUES (?1, ?2, ?3, ?3) \
             ON CONFLICT(key) DO UPDATE SET value = ?2, updated_at_utc = ?3",
            rusqlite::params!["low_stock_basis", value, now],
        ).map(|_| ()).map_err(map_rusqlite)
    }).await
}
```
Рекомендация RESEARCH.md (Pattern 1, assumption A2): объединить 3 новых значения в один
patch-эндпоинт `settings_get/set_place_path_defaults(OrgPathDisplayDto)`, мирроринг `OrgPatch` /
`build_settings_save_org_fields` (тот же файл, строка ~33) — одна кнопка «Сохранить формат пути»
на фронте (D-07/D-11) сохраняет все 3 значения одним round-trip.

**Wrapper (`#[tauri::command]`)** — строки 535-550, паттерн:
```rust

pub async fn settings_set_low_stock_basis(
    state: tauri::State<'_, AppCtx>,
```

**Валидация непустого разделителя (D-10):** мирроринг `LowStockBasis::parse().ok_or_else()` —

```rust
fn rename(&self, conn: &mut Self::Conn, id: i64, name: &str, version: i64, now_utc: i64)
```

### `ui/src/lib/utils/placePath.ts` (utility, transform) — источник переносимой формулы + live-preview

**Текущий полный файл** (переносится в Rust дословно, D-01; остаётся урезанная копия для
превью, D-11):
```ts
export type PlacePathDisplay = 'ends' | 'last_two' | 'full';

export function normalizePlacePathDisplay(raw: string | null | undefined): PlacePathDisplay {
  return raw === 'ends' || raw === 'last_two' || raw === 'full' ? raw : 'ends';
}

export function shortenPlacePath(fullPath: string, variant: PlacePathDisplay): string {
  if (!fullPath) return fullPath;
  const segments = fullPath.split(' / ');
  if (variant === 'full' || segments.length <= 2) return fullPath;
  if (variant === 'last_two') return segments.slice(-2).join(' / ');
  return `${segments[0]} // ${segments[segments.length - 1]}`;
}
```
**Anti-pattern явно предупреждён в RESEARCH.md:** старая ветка `variant === 'full' => return
fullPath` семантически ПРОТИВОПОЛОЖНА новому третьему варианту `'last'` («только последний
сегмент») — не копировать её как есть. Новая версия для превью Настроек принимает `sepEnds`/
`sepLastTwo` параметрами (а не хардкодит `' // '`/`' / '`), т.к. D-08/D-09 делают их
настраиваемыми полями.
