## Разделитель и формула вариантов

### К каким вариантам применяется разделитель?

| Option | Description | Selected |
|--------|-------------|----------|
| Ко всем — соединяет показанные сегменты | Одно правило, «, » даёт перечисление везде | ✓ |

**User's choice:** Ко всем, **плюс поправка**: в Настройках заводится отдельное поле разделителя
на каждый тип — «Крайние» и «Два последних» → D-08

### Умолчания двух полей разделителей

| Option | Description | Selected |
|--------|-------------|----------|

| Оба « / » | Сокращение неотличимо от полного пути | |

**User's choice:** « // » и « / » → D-09

### Путь из 2 сегментов при варианте «Крайние»

## Охват «везде, где сокращается»

### CSV и PDF экспорт отчётов

| Option | Description | Selected |
|--------|-------------|----------|
| Экспорт всегда полный путь | Файл уходит третьим лицам, подсказки нет | |
| Экспорт повторяет то, что на экране | Расширяет фазу на бэкенд-рендер экспорта | |
| CSV — полный, печать/PDF — сокращённый | CSV = данные, PDF = документ для чтения | ✓ |

**User's choice:** CSV — полный, печать/PDF — сокращённый → D-17, D-18

**Notes:** Проверено в коде — и `reports_export_csv`, и `reports_export_pdf` (HTML для
`PdfPreviewModal`) генерируются на бэкенде, то есть оба попадают ровно туда, где по D-01
считается короткая строка. Асимметрия реализуема без отдельного клиентского пути.

### Детальные экраны, PlacePicker, поиск в дереве

| Option | Description | Selected |
|--------|-------------|----------|
| Остаются полными | Сокращение — лекарство от узкой колонки в списке | ✓ |
| Тоже сокращать — единообразно везде | Мешает отличить два одноимённых кабинета | |

**User's choice:** Остаются полными → D-19

### Акты приёма-передачи

| Option | Description | Selected |
|--------|-------------|----------|
| Акты — всегда полный путь | Подписываемый документ, снимок заморожен ради точности | |
| Акты тоже сокращать | Единый формат печатных форм; правки в minijinja + сид шаблонов в БД | ✓ |

**User's choice:** Акты тоже сокращать → D-17, D-20

**Notes:** Claude озвучил возражение — в PDF нет подсказки при наведении, сокращение в
подписываемом документе теряет информацию безвозвратно; владелец подтвердил решение. Зафиксировано
как есть, возражение отражено в CONTEXT.md рядом с D-20.

### По какому варианту сокращать снимок пути в акте?

| Option | Description | Selected |
|--------|-------------|----------|
| По текущему варианту места, фолбэк — организация | `acts.place_id` → вариант, применяется к замороженной строке | ✓ |
| Всегда по умолчанию организации | Переопределение места в акт не попадает | |
| Заморозить сокращённый вид при создании акта | Новая колонка + миграция старых записей | |

**User's choice:** По текущему варианту места, фолбэк — организация → D-20
