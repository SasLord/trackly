'—'}` (у `PlaceContentDto.place_path_short` — не-опциональное поле, прямое чтение без `??`); `title`-атрибуты не тронуты — по-прежнему читают `full_path` (D-21).
- `ReportTable.svelte`: `formatCellDisplay`'s вызов `formatPlaceCell(row, col, (p) => shortenPlacePath(p, authStore.placePathDisplay))` заменён на `formatPlaceCell(row, col, () => row.place_path_short ?? - Все 4 файла лишились импортов `shortenPlacePath`/`authStore` (`placePathDisplay`) — подтверждено grep'ом, ноль совпадений.
- `crates/trackly-infra/src/config.rs`: `OrganizationConfig.place_path_display` поле, `enum PlacePathDisplay`, `fn deserialize_place_path_display` удалены целиком; `OrganizationConfig` теперь содержит только `timezone`.
- `crates/trackly-infra/tests/config_test.rs`: тесты 7–11 (место_path_display missing/partial/last_two/full/bogus-degradation) удалены вместе с преамбулой-комментарием про «quick 260827-ui3»; остались ровно тесты 1–6, все зелёные.
- `trackly.config.toml.example`: блок документации `place_path_display` заменён коротким указателем на «Настройки → Организация» (Phase 39.1, PLC-07/PLC-08) — источник истины теперь БД (`app_settings`/`places`), не TOML.
- `crates/trackly-app/src/dto/auth.rs`: `AuthStatusDto.place_path_display: String` удалено; тестовый конструктор и `assert!(json.contains(...))` заменены на явный `assert!(!json.contains("place_path_display"))`, фиксирующий контракт удаления.
- `crates/trackly-app/src/http/auth.rs` и `crates/trackly-app/src/tauri_cmds/auth.rs`: чтение `ctx.config.organization.place_path_display` убрано из обоих `build_auth_status*` конструкторов `AuthStatusDto`.
- `ui/src/App.svelte`: импорт `normalizePlacePathDisplay` и строка `authStore.placePathDisplay = normalizePlacePathDisplay(status.place_path_display)` удалены из `loadAuthStatus()`; остальная bootstrap-логика не тронута.
- `ui/src/lib/stores/auth.svelte.ts`: импорт типа `PlacePathDisplay` и поле `placePathDisplay` в `authStore` удалены.
- `ui/src/lib/utils/placePath.ts`: старый `export type PlacePathDisplay`, `normalizePlacePathDisplay`, старый `shortenPlacePath` удалены вместе с устаревшим файловым докстрингом (ссылался на `AuthStatusDto.place_path_display`/`authStore.placePathDisplay`, оба больше не существуют); `previewShortenPath`/`monoReadout` (план 08) не тронуты.
