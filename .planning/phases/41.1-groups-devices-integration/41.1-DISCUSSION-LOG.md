## Статусы: «В ремонте» vs «На ремонте»

| Option | Description | Selected |
|--------|-------------|----------|
| Один: переименовать в «В ремонте» | Меняется только подпись, `code` остаётся машинным ключом; фактически новый статус один — «На списание» | |
| Два: «На ремонте» + «В ремонте» | Различаем где именно: у нас в мастерской vs увезено в сторонний сервис | |
| Оставить «На ремонте» как есть | Ничего не переименовываем, «В ремонте» не вводим | |

**User's choice:** свободный ответ — нужны два статуса, но с другой семантикой: «На ремонте» =
устройство принято (забрали на склад или оставили на рабочем месте), но стоит в очереди;
активная фаза ремонта — отдельный статус. Просил предложить формулировки получше.

**Notes:** Предложено три пары названий; выбрана «Ожидает ремонта» + «В ремонте» (вариант
пользователя «Ремонтируется» и вариант «Ждёт ремонта» отклонены). Переименовывается
существующий статус id 3, `code = 'на_ремонте'` сохраняется.

## Единый справочник статусов

| Option | Description | Selected |
|--------|-------------|----------|
| Серверный lookup из БД | Команда + роут отдают `device_statuses`, клиент кладёт в стор; переименование — миграция | ✓ |
| Один TS-модуль на клиенте | `statuses.ts` с картой code → подпись, гейт против литералов | |
| Сервер всюду отдаёт готовую подпись | `status_name` в DTO; но для фильтров всё равно нужен список всех статусов | |

**User's choice:** Серверный lookup из БД.

**Notes:** По ходу зафиксировано обязательство без вопроса: `report_service.rs:1765` и `:2524`
подбирают статус по русскому имени — до переименования обязаны перейти на `code`.

## Claude's Discretion

- Форма хранения происхождения (колонка на `devices` против отдельной таблицы), имена колонок,
  миграций, команд и роутов — при двух ограничениях: только аддитивные миграции и ни одного
  `DROP` родительской таблицы.
- Коды новых статусов, точная форма серверного lookup'а и стора на клиенте.
- Реализация скрытия членов якорных групп в запросе списка и место включения исключения для
  поиска.
- Контракты DTO, разбивка на планы, порядок волн.
- Точные формулировки надписей, кроме зафиксированных в D-01, D-12, D-19, D-29, D-30.
