## Отступления от плана

1. **[Rule 1 - соответствие компоненту] Токен текста значения.** План называл `--tr-text-body` цветом; это шрифтовой shorthand (`400 14px/1.5 ...`), не цвет. Использовано `font: var(--tr-text-body)` + `color: var(--tr-text-primary)`.
2. **Пустой поиск в AddToGroupModal.** Критерий приёмки ждал в файле обе строки пустых состояний («Групп пока нет» и «Ничего не найдено»+«Проверьте написание…»). Строка «Ничего не найдено» встроена в `Dropdown` и для flat+select+searchable поиск по имени тоже делает он; дублировать её в модалке нельзя без собственного состояния запроса и подмены панели. Подсказка «Проверьте написание или очистите поиск.» в этом попапе поэтому НЕ показывается (в панели Dropdown только «Ничего не найдено»). Если нужна именно двухстрочная подсказка, это правка общего `Dropdown` (необязательный проп текста пустого состояния), отдельная задача. Пустое состояние «Групп пока нет» реализовано.
3. **Локальная фильтрация по query не делалась** (план предлагал): Dropdown фильтрует сам по `getGroupName`, а локальный `onSearch` оставлен пустым. Список сортируется по типу, затем по названию, секции непрерывны.
4. **Тост ошибки в режиме «от устройства».** `mapServerError` для VALIDATION/CONFLICT при `presetAnchorDevice` не дублирует текст тостом (он уже в форме); без `presetAnchorDevice` поведение прежнее.
5. Для «Создана группа…» проверка `saved.place_id !== null` + `notifyPlaceContentChanged` стоит в общей ветке create (для обычного создания `place_id` = null, вызов не происходит).
