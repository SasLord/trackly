# Phase 41.1 Plan 26: охрана click строки принтера Summary

Клик из модалок меню строки принтера больше не доходит до `onclick()` строки; гейт check-device-row-menu получил порядко-чувствительное правило [F4], проверенное мутацией-перестановкой на реальном исходнике.

## Задачи

1. **Охрана click в PrinterListRow.svelte** — коммит `a0d3886b`. Фрагмент:
   ```
   function handleClick(e: MouseEvent) {
     if (isRowOverlayEvent(e.target)) return;
     onclick();
   }
   ```
   `grep -c "onclick={handleClick}"` = 3 (td.cell-name, cell-status, cell-toner).
2. **Правило [F4] в гейте** — коммит `2e42ba4a`. `extractTdClickBindings` + `findTagEnd` (учёт `{...}`/кавычек), `GUARD_BY_ATTR.onclick`, токен `\bonclick\s*\(` в FORBIDDEN_BEFORE_GUARD, `REQUIRED_TD_CLICK_ROWS`, коды: F4 (охрана нет/полярность/не первым/не разрешилось), F3 (действие до охраны), F0 (снята привязка у обязательного файла).
