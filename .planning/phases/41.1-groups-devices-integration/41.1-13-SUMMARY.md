## Гейт: освобождение по правилу

`RULE_EXEMPT` содержит одну запись: `places/PlaceContents.svelte`, правило [B]. Механика: в участках кода файла ищутся объявления `const CARTRIDGE_<имя> ... = { ... }` (тело ищется балансом фигурных скобок). Совпадение [B] пропускается, только если оно лежит внутри такого объявления или является ссылкой на его имя. Объявление, в теле которого есть слово устройственного статуса, в расчёт не берётся. Если допустимого объявления в файле нет, гейт краснеет правилом [E] (освобождение устарело).

Новые фикстуры self-test (M15-M23): устройственная карта `STATUS_VARIANT_BY_NAME` рядом с картриджной; устройственная карта под нейтральным именем `TONE`; `CARTRIDGE_`-карта с ключом «Ожидает ремонта»; то же с прежним «На ремонте»; картриджная карта без префикса; карта `id -> подпись` в этом же файле (остаётся [A]); `status_id === 1` в этом же файле (остаётся [C]); устаревшее освобождение; объявление карты ниже ссылки на неё. Ожидание сверяется точным множеством кодов.

## Отступления от плана

1. **[Rule 2 - строже плана] Критерий освобождения картриджной карты шире трёх слов.** План называл «Ожидает ремонта», «В ремонте», «На списание». Добавлено «На ремонте»: это прежнее имя устройственного статуса, его нет в `cartridge_statuses` (V001: «На складе», «В работе», «На заправке», «Списано»), и оставленное в картриджной карте оно скрыло бы устройственный ключ.
2. **[Rule 2 - самопроверка освобождения] Освобождение по правилу проверяется на устаревание ([E]).** Без этого запись в `RULE_EXEMPT` пережила бы удаление картриджной карты и тихо освобождала бы файл, в котором нечего освобождать.
3. **PlaceContents без `ensureLoaded`.** План требовал `ensureLoaded` только для групповых экранов и актов; в «Местах» справочник не нужен (тон по статической таблице, подпись с сервера), поэтому лишний запрос не добавлен.
4. Из картриджной карты убран ключ `'На ремонте': 'warning'`: он был устройственным и для картриджей недостижим.
