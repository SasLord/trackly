# Phase 40.5 Plan 01: Убрать зависимость суффикса возврата от соседей и строкового поиска «в» Summary

## Decisions Made
- **D-08 (Claude's Discretion, зафиксировано планом):** выбрана простейшая корректная реализация — `compute_return_suffix(is_return: bool, sub_number: Option<i64>) -> String`, возвращающая `""` для handover и `format!("в{}", sub_number.unwrap_or(1))` для return. Параметры `display`/`number_raw` убраны из сигнатуры целиком (не просто заменена внутренняя логика) — функция физически не может обратиться к display-строке.

- Unit-тесты `compute_return_suffix` размещены в новом `#[cfg(test)] mod compute_return_suffix_tests` внутри `act_service.rs` (в файле не было существующего `mod tests`, план разрешал оба варианта).
