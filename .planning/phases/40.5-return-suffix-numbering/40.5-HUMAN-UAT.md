# Phase 40.5 — Human UAT: плотные суффиксы возвратов «в1..вN»

> Этот чеклист проходит ЧЕЛОВЕК (пользователь проекта), а не исполнитель-агент. Согласно
> `40.5-VALIDATION.md` и памяти проекта `auto_advance_auto_approves_human_verify` — исполнители
> имеют привычку закрывать human-verify чекпоинты без запуска приложения. Пункты ниже
> автоматизированный тест физически не видит (печать — HTML, материализуется браузером; конечный
> пользовательский сценарий — сквозной путь через реальный UI).
>
> Отметьте `[x]` только после реальной проверки в запущенном приложении.

**Подготовка:**
- Десктоп: `cargo tauri dev` (из main после мержа веток фазы 40.5).
- LAN-браузер: `pnpm --dir ui build`, затем открыть `https://<host>:<port>` с другого устройства
  или локально в браузере (не в Tauri webview) — см. память `dev_browser_testing_needs_ui_build`.

## Чеклист

- [ ] **1. Печать акта с ОДНИМ возвратом («…в1»).** Открыть предпросмотр печати акта возврата,
  у которого ровно один живой возврат — заголовок/подзаголовок должен показывать «…в1», не
  «…в» без цифры. Проверить визуально в `.subtitle` и `.appendix-mark` — нет переноса строки
  или наложения текста, которых не было раньше. Проверить И на десктопе, И в LAN-браузере.

- [ ] **2. Печать акта с НЕСКОЛЬКИМИ возвратами, самый длинный реалистичный суффикс** (например
  «в12» при двузначном номере родителя). Убедиться в отсутствии переполнения строки/наложения в
  тех же двух местах шаблона (`.subtitle`, `.appendix-mark`). И на десктопе, и в LAN-браузере.

- [ ] **3. Пользовательский сценарий приёмки (буквально по CONTEXT.md).** Создать акт передачи,
  оформить 2 возврата (получатся «в1», «в2») → удалить возврат «в1» → создать НОВЫЙ возврат →
  убедиться, что он получил «в1» (НЕ «в3») → убедиться, что исходный «в2» в списке актов НЕ
  изменился (номер, дата, состояние).

- [ ] **4. Попап «Номер занят» называет правильную запись.** Попытаться вручную создать или
  переименовать акт в номер, совпадающий с отображением живого возврата (например, «42в1», если
  у акта «42» есть живой возврат с этим отображением) — убедиться, что попап корректно называет
  конфликтующую запись именно как «42в1» (не «42в» — такого отображения больше не существует).

- [ ] **5. Превью шаблона номера.** Настройки → Шаблоны номеров → тип «Акты» — список «занятых»
  номеров/подсказка автоподбора должен показывать «…в1», «…в2» и т. п. для существующих
  возвратов, не «…в» без цифры.
