<objective>
Заменить выделение `sub_number` возврата с `MAX(sub_number)+1` на «наименьший свободный
положительный номер среди неудалённых возвратов родителя» — решение D-04 из
`40.5-CONTEXT.md`. Освободившаяся после удаления возврата позиция («дырка») достаётся следующему
СОЗДАННОМУ возврату (D-05), при нескольких дырках — меньшей (D-06 подтверждает: переиспользование
номера принято осознанно). Параллелизм не требует новых механизмов (D-07) — единственный писатель
+ `BEGIN IMMEDIATE` + существующий `idx_acts_number_sub_unique` уже покрывают гонку.

Этот план НЕ трогает `format_act_number`, `ActRow`, `SELECT_ACTS` — та часть отдельно закрывается
планами `40.5-01` (формула отображения) и `40.5-03` (D-16, позиционные индексы). Изменения этого
плана изолированы в одной функции одного файла и параллельны плану `40.5-01` (нет пересечения
файлов).

Purpose: убрать корень дефекта B (дыры в нумерации не переиспользуются).
Output: `next_sub_number_for_parent` с новым SQL/алгоритмом + инлайн unit-тесты алгоритма без БД.
