<interfaces>
Контракты репозитория (создаёт этот план; план 05/06 использует дословно). Все методы принимают `&rusqlite::Connection` (Transaction разыменовывается) и возвращают `Result<_, AppError>`:

- `struct ChatMessageNew<'a> { request_id: i64, author_user_id: Option<i64>, body: &'a str, created_at_utc: i64, moved_from_request_id: Option<i64> }`
- `struct ChatMessageRow { id, request_id, author_user_id: Option<i64>, author_name: Option<String>, author_role: Option<String> /* users.role */, body: String, created_at_utc: i64, moved_from_request_id: Option<i64> }`
- `struct ChatEventRow { id, action: String, user_id: Option<i64>, user_name: Option<String>, payload_json: Option<String>, created_at_utc: i64 }`
- `struct ReadMark { last_message_id: i64, last_audit_id: i64 }`
- `insert_message_on(&self, conn, &ChatMessageNew) -> i64`
- `get_message_on(&self, conn, id) -> Option<ChatMessageRow>`
- `list_messages_on(&self, conn, request_id) -> Vec<ChatMessageRow>` (по id возр.)
- `list_events_on(&self, conn, request_id) -> Vec<ChatEventRow>` (по created_at_utc, id возр.; исключает list/get, `custom:attachment_%` и строки с маркером message_id; но ВКЛЮЧАЕТ все остальные action)
- `message_attachment_ids_on(&self, conn, request_id) -> HashSet<i64>` (id вложений заявки с message_id IS NOT NULL, включая мягко удалённые)
- `baseline_audit_id_on(&self, conn) -> i64` (app_settings `chat_unread_baseline_audit_id`, нет строки = 0)
- `get_read_on(&self, conn, user_id, request_id) -> Option<ReadMark>`; `effective_read_on(...) -> ReadMark` (нет строки: 0 и baseline)
- `max_ids_on(&self, conn, request_id) -> (i64, i64)` (MAX(chat_messages.id), MAX(audit_log.id) по заявке, 0 если пусто)
- `upsert_read_on(&self, conn, user_id, request_id, mark: ReadMark, now) -> ()`
- `unread_summary_on(&self, conn, user_id: i64, staff: bool) -> Vec<(i64 /*request_id*/, i64 /*count*/)>` (только count > 0)
- `list_drafts_on(&self, conn, request_id, user_id) -> Vec<AttachmentRow>`
- `promote_drafts_on(&self, conn, request_id, user_id, draft_ids: &[i64], message_id) -> Result<Vec<AttachmentRow>, AppError>` — Forbidden, если хоть один id не удовлетворяет условию черновика
- `delete_draft_rows_on(&self, conn, ids: &[i64]) -> ()`
- в `SqliteAttachmentRepository` (attachments_sqlite.rs): `list_message_attachments_on(&self, conn, request_id) -> Vec<AttachmentRow>` (parent_kind='request', parent_id, message_id NOT NULL, включая удалённые; по id)
</interfaces>
