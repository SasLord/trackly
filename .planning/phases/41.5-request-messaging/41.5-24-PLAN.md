<objective>
Платформенный слой системных уведомлений (UAT 41.5, тест 3; D-G1): десктопные уведомления через официальный tauri-plugin-notification и единая обёртка `systemNotify.ts` для десктопа и браузера.

Оценка вариантов (записать в SUMMARY):
- Web Notification API в десктопном webview: в WKWebView (macOS) не поддерживается в Tauri, в WebView2 зависит от обработчика разрешений хоста — ненадёжно; именно поэтому у Специалиста/Админа (десктоп) уведомлений не было.
- tauri-plugin-notification (Tauri v2, официальный): `isPermissionGranted`, `requestPermission`, `sendNotification`; Windows — toast через WinRT (Windows 10+; на Windows 7 вызов завершится ошибкой — обёртка её проглатывает), macOS — нативный центр уведомлений, Linux — D-Bus. Данных в %APPDATA% не пишет. Клик по уведомлению на десктопе плагином не отдаётся (обработчик действий — только мобильные платформы): навигацию по клику обеспечивает внутренний тост «Открыть чат» (D-G1 оставляет оба канала). Известное ограничение: в portable-сборке без установки Windows может показывать в заголовке уведомления имя-заместитель вместо «Trackly»; проверяется живой UAT на Windows (план 27).
- Свой код на Rust (notify-rust напрямую): повторяет плагин без выигрыша, требует собственных разрешений — отвергнут.
Для LAN-браузера остаётся web Notification (нужен безопасный контекст: https или localhost — как уже сделано в EmployeeLayout).

    Создать ui/src/lib/platform/systemNotify.ts с экспортами (все без исключений наружу):
    - `appHasFocus(): boolean` — `typeof document !== 'undefined' && document.hasFocus()`; в комментарии пометить: document.hidden НЕ использовать (false при переключении между приложениями).
    - `ensureNotifyPermission(): Promise<boolean>` — Tauri: динамический import `@tauri-apps/plugin-notification`, `isPermissionGranted()`, при false — `requestPermission()` и сравнение с 'granted'; браузер: `'Notification' in window && window.isSecureContext`, при `Notification.permission === 'default'` — `Notification.requestPermission()`; результат `granted`. Любое исключение → false.
    - `armPermissionPrompt(): () => void` — для браузера при `permission === 'default'` вешает одноразовый слушатель `pointerdown` (capture, once) на document, который вызывает ensureNotifyPermission (жест пользователя); для Tauri вызывает ensureNotifyPermission сразу один раз; возвращает функцию снятия слушателя. Повторные вызовы не плодят слушателей (флаг модуля).
    - `showSystemNotification(title: string, body: string): Promise<boolean>` — проверяет разрешение БЕЗ запроса (`isPermissionGranted()` / `Notification.permission === 'granted'`); Tauri → `sendNotification({ title, body })`; браузер → `new Notification(title, { body })`; false при отсутствии разрешения или любой ошибке (в т.ч. Windows 7).
