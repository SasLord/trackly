- Документация крейта: «`Toast::POWERSHELL_APP_ID` — if you do not have an AppUserModelID / if the program was not installed»; пример `unpackaged_app.rs` показывает, что собственный AUMID не-упакованного приложения надо регистрировать в HKCU (нам запрещено), иначе «the notification won't appear». Для AUMID, неизвестного оболочке, `Show()` проходит без ошибки, а тост не появляется.
- NSIS-шаблон Tauri: `WriteUninstaller "$INSTDIR\uninstall.exe"` и `!insertmacro SetLnkAppUserModelId "$SMPROGRAMS\…\${PRODUCTNAME}.lnk"` — установленная сборка регистрирует AUMID = identifier ярлыком; portable ZIP (trackly.exe + portable.txt + README + пример конфига) — нет. Значит, в portable identifier неизвестен, и тост молча отбрасывается и у нашей команды, и у плагина (плагин тоже берёт identifier вне target/debug|release). «Запасной путь через плагин» в portable поэтому не помогает. Раунд 2, где уведомления плагина были видны, вероятно, проверялся на NSIS (вариант сборки не записан).
- Совместимый с portable путь с кликом: `POWERSHELL_APP_ID` (известен оболочке; пример `simple.rs` получает on_activated без регистрации). Цена: подпись «Windows PowerShell» и её значок; клик из Центра уведомлений после исчезновения баннера может не дойти до приложения — проверяется в UAT. Решение D-R3-1 о подписи запрашивает у пользователя оркестратор; реализация держит выбор в одной ветке (`PORTABLE_AUMID`), чтобы ответ переключал только её.
- Отключённые уведомления: `ToastNotifier::Setting()` для известного AUMID отдаёт `DisabledForApplication` / `DisabledForUser` / `DisabledByGroupPolicy` / `DisabledByManifest`, если показ запрещён пользователем или политикой AD. В этом случае обходить запрет подменой AUMID или путём плагина нельзя: ничего не показываем и сообщаем фронтенду «suppressed». Откат на POWERSHELL_APP_ID — только при ошибке пробы (AUMID неизвестен оболочке).
- Признак «установлено»: `uninstall.exe` рядом с exe. `Paths::is_portable()` не годится: он истинен и при наличии `trackly.config.toml`, который может лежать рядом с установленным exe.
