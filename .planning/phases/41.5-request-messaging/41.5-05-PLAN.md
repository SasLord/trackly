Контракт сервиса (этот план создаёт, планы 06/07 расширяют/используют):

```
pub struct ChatService { writer: Arc<WriterHandle>, readers: Arc<ReaderPool>, clock: Arc<dyn Clock+Send+Sync>,
  attachments: Arc<AttachmentService>, repo: Arc<SqliteChatRepository>, ws_tx: Option<Arc<broadcast::Sender<WsEvent>>> }
new(writer, readers, clock, attachments) ; with_ws_tx(self, Arc<Sender<WsEvent>>) -> Self
feed(&self, caller: &Identity, request_id: i64) -> Result<ChatFeedDto, AppError>
mark_read(&self, caller: &Identity, request_id: i64) -> Result<(), AppError>
unread_summary(&self, caller: &Identity) -> Result<UnreadSummaryDto, AppError>
```
DTO (serde camelCase, `#[specta(type = i32)]` на i64, как соседние DTO):
- `ChatFeedDto { items: Vec<ChatItemDto>, can_post: bool, max_size_bytes: i64, first_unread_id: Option<String>, resolution_notes: Option<String> }`
- `ChatItemDto` — `#[serde(tag = "kind", rename_all = "snake_case")]` enum: `Message(ChatMessageDto)`, `Event(ChatEventDto)`, `AttachmentEvent(ChatAttachmentEventDto)`; у каждого внутренней структуры `key: String` (стабильный: `m{id}` / `e{id}` / `a{attachment_id}:{action}:{created_at_utc}`) и `created_at_utc`
- `ChatMessageDto { key, id, created_at_utc, actor_user_id: Option<i64>, actor_name: Option<String>, author_role: Option<String> /* admin|manager|requester|participant */, is_own: bool, text: String, moved_from_request_id: Option<i64>, attachments: Vec<AttachmentDto> }`
- `ChatEventDto { key, id, created_at_utc, actor_user_id, actor_name, action: String, notes: Option<String>, related_request_id: Option<i64>, show_notes: bool }` (поля notes/related_request_id считаются тем же кодом, что у `RequestHistoryEntryDto` в request_service::get_history)
- `ChatAttachmentEventDto { key, created_at_utc, event: AttachmentHistoryEventDto }`
- `ChatSendOutcomeDto { message: Option<ChatMessageDto>, reject_code: Option<String> }` (используется планом 06)
- `UnreadSummaryDto { items: Vec<UnreadItemDto>, requests_with_unread: i32 }`, `UnreadItemDto { request_id: i64, count: i32 }`
</interfaces>
