## Судьба «Комментария специалиста»

| Option | Description | Selected |
|--------|-------------|----------|
| Поле остаётся, текст становится сообщением | resolutionNotes публикуется как сообщение, отдельный блок исчезает | |
| Убрать поле совсем | Причина пишется отдельным сообщением | |
| Оставить как есть плюс переписка | Противоречит прежней формулировке MSG-01 | |

**User's choice (свободный ответ):** прежний блок остаётся — в нём нужная история и общая
информация. Под шапкой с кнопками две вкладки: «Информация» (текущий блок) и «Чат» (полноценный
чат Администраторов, Специалистов и сотрудников-участников, включая присоединённых к общей заявке).
Счётчики непрочитанного: на вкладке «Чат», у раздела «Заявки» в сайдбаре и у заявок в списке.
Файлы из чата видны и в блоке «Вложения» с маленькой иконкой-облачком в углу.

## Когда писать можно

| Вопрос | Варианты | Выбор |
|--------|----------|-------|
| Статусы | любой / все кроме отменённых / только открытые | Только открытые (open, in_progress, in_repair) ✓ |
| Типы | ремонт + картридж + «Другое» / только ремонт | Ремонт, картридж, «Другое» ✓ |
| Объединение заявок | перенести в целевую с временем / оставить в поглощённой | Перенести ✓ |
| Содержимое | текст и/или файлы до 4000, Enter / то же с Ctrl+Enter | Текст и/или файлы, Enter ✓ |
