# Phase 41.5 Plan 22: серверный переключатель оповещений чата Summary

Настройка «оповещения отключены» хранится в БД по паре (пользователь, заявка), отдаётся в `chat_unread_summary` как `mutedRequestIds` и синхронизируется между устройствами владельца через `ChatReadChanged`.

## Коммиты

- 4d1a8a5b — V055, репозиторий (`set_muted_on`, `muted_request_ids_on`), поле DTO, тесты infra
- ddadf60f — `ChatService::set_muted`, тесты `chat_mute`, вердикт гейта, мутационные доказательства

## Что сделано

- V055: только `CREATE TABLE`, последняя строка `PRAGMA user_version = 55;`, без DROP. Тест проверяет user_version `>= 55`, первичный ключ, последнюю строку файла и отсутствие DROP.
- `set_muted`: `authorize` (посторонний и `ad_register` дают Forbidden, нет заявки NotFound, нет user_id Forbidden), запись через writer, затем `ChatReadChanged { user_id }` позиционно после `.await`.
- Счётчики непрочитанного не затрагиваются (D-G2): тест проверяет рост count при заглушённой заявке.
