# Phase 41.5 Plan 18: цикл эффекта «Чат» закрытой заявки Summary

Эффект сброса черновика в RequestChat теперь вызывает `clearDraft` внутри `untrack`, а `clearDraft` ничего не пишет в реактивные поля на пустом черновике; возврат дефекта ловит новый структурный гейт в `pnpm lint`.

## Просмотренные эффекты (шаг 3 задачи 1)

- RequestChat.svelte, эффект смены заявки: вызовы внутри `untrack` — безопасно.

- RequestChat.svelte, эффект сброса при закрытой заявке: БЫЛ дефектом, исправлен.
- RequestChat.svelte, эффект фокуса: `untrack(() => composer?.focus())` — безопасно.
- RequestDetail.svelte, эффект useDraftFor: под `untrack` — безопасно.
- Находка для плана 21/27 (ChatComposer НЕ правился): эффект «закрытая заявка» вызывает `clearDraft()` без untrack, но под условием `draft.text !== '' || draft.chips.length > 0`, а clearDraft теперь идемпотентен — цикла нет (сходится за один проход). Для единообразия в плане 21 обернуть в `untrack`, затем убрать запись из EXEMPT в гейте (иначе E4 «устарел» покажет красный — это намеренно).
