# Phase 41.5 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Источник: `41.5-RESEARCH.md` → `## Validation Architecture`.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust `cargo test` (suite-бинарники, `autotests=false`, `tokio::test`); UI — `node scripts/check-*.mjs`, `svelte-check`, eslint/prettier |
| **Config file** | `crates/trackly-app/Cargo.toml` (`[[test]]`), `crates/trackly-app/tests/suites/*.rs` |
| **Quick run command** | `cargo test -p trackly-app --test app_chat -- --test-threads=1` |
| **Full suite command** | `cargo test --workspace --no-fail-fast -- --test-threads=1` (4,5–6 ч; один раз на границе последней волны, в фоне, без параллельных `cargo test`) |
| **Estimated runtime** | quick ~100–300 s; per-wave (5 suite) ~15–30 мин; full 4,5–6 ч |

При exit 69 на линковке — префикс `DEVELOPER_DIR=/Library/Developer/CommandLineTools`.

---

## Sampling Rate

- **After every task commit:** целевой suite (`--test app_chat` / `app_gates` / `app_repairs` / `app_server`) + `cargo fmt --all -- --check` + `cargo clippy -p trackly-app --all-targets -- -D warnings` при Rust-правках; `pnpm --dir ui exec svelte-check` **и** `pnpm --dir ui lint` при UI-правках (разные команды).
- **After every plan wave:** `cargo test -p trackly-app --test app_chat --test app_gates --test app_attachments --test app_repairs --test app_server -- --test-threads=1`
- **Before `/gsd-verify-work`:** сплошной workspace-прогон зелёный + `pnpm --dir ui build` + живая проверка UI-SPEC §18 человеком
- **Max feedback latency:** ~300 s на задачу
