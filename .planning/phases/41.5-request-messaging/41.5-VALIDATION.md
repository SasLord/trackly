## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust `cargo test` (suite-бинарники, `autotests=false`, `tokio::test`); UI — `node scripts/check-*.mjs` (структурные гейты + поведенческий стенд `_rune-harness.mjs`), `svelte-check`, eslint/prettier |
| **Config file** | `crates/trackly-app/Cargo.toml` (`[[test]]`), `crates/trackly-app/tests/suites/*.rs`, `crates/trackly-infra/tests/suites/infra.rs` (единственная цель `infra_tests`) |
| **Quick run command** | `TRACKLY_AD_MOCK=1 TRACKLY_SNMP_MOCK=1 cargo test -p trackly-app --test app_chat -- --test-threads=1` |
| **Full suite command** | `cargo test --workspace --no-fail-fast -- --test-threads=1` (4,5–6 ч; один раз на границе волны, в фоне) |
| **UI gates** | `pnpm --dir ui lint`; `pnpm --dir ui exec svelte-check --threshold error`; `pnpm --dir ui build` — три РАЗНЫЕ команды |
| **Estimated runtime** | app_chat ~2 с прогона + сборка; UI lint ~2–3 мин (поведенческие гейты ~40 с из них) |

При exit 69 на линковке — префикс `DEVELOPER_DIR=/Library/Developer/CommandLineTools`.
Ниже `E=` означает `TRACKLY_AD_MOCK=1 TRACKLY_SNMP_MOCK=1` (и при необходимости `DEVELOPER_DIR`).

**Поведенческий стенд рун** (`ui/scripts/_rune-harness.mjs`, добавлен аудитом): исполняет настоящие
`*.svelte.ts` в Node (typescript → `svelte/compiler` `compileModule`, хуки `module.register`), без
новых npm-пакетов; работает на Node 20 (CI) и 24. Заглушаются только внешние границы (WS, API,
authStore, systemNotify, plugin-shell, svelte-spa-router). Каждый гейт в `--selftest` гоняет мутантов
НАСТОЯЩЕГО исходника в отдельных процессах. Это логика сторов без DOM — не замена проверке в
WKWebView/WebView2.

## Sampling Rate

- **After every task commit:** целевой suite + `cargo fmt --all -- --check` + `cargo clippy -p trackly-app --all-targets -- -D warnings` при Rust-правках; `svelte-check` **и** `pnpm --dir ui lint` при UI-правках.
- **After every plan wave:** `cargo test -p trackly-app --test app_chat --test app_gates --test app_attachments --test app_repairs --test app_server -- --test-threads=1`
- **Before `/gsd-verify-work`:** сплошной workspace-прогон + `pnpm --dir ui build` + живая проверка UI-SPEC §18
- **Max feedback latency:** ~300 s на задачу
