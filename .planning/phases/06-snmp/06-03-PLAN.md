<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → axum /api/v1/ws | WebSocket upgrade — auth по session cookie до upgrade |
| Tauri invoke → AppCtx | Trusted admin identity (или залогиненный при desktop lock) |
| axum handler → build_* helpers | Единая бизнес-логика для обоих транспортов |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-09-E | Elevation of Privilege | WS auth bypass | mitigate | Session extractor ДО ws.on_upgrade() (Pitfall 6); если session отсутствует → return StatusCode::UNAUTHORIZED.into_response() (http 401 до upgrade) |
| T-06-10-E | Elevation of Privilege | requests_transition от employee | mitigate | authorize(caller, &Action::TransitionRequests) в build_requests_transition; HTTP handler → 403; тест role×endpoint в Plan 04 |
| T-06-11-T | Tampering | SSRF через printers_discover | mitigate | discover доступен только admin; IP парсируется через std::net::Ipv4Addr::from_str |
| T-06-12-I | Information Disclosure | CSP connect-src | mitigate | CSP обновляется на connect-src 'self' wss: — разрешает только same-origin WS |
</threat_model>
