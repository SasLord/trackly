<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → printers_admit | недоверенные IP/community; admit пишет device + printers |
| client → printers_create (ручная форма) | недоверенный device_id/ip/community |
| SNMP probe → admit | данные принтера из сети (sys_name/model) — недоверенный источник имени устройства |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-08-01 | Elevation of Privilege | printers_admit / printers_create | mitigate | `authorize(caller, MutatePrinters)` (Admin\|Manager) в начале build_*; сотрудник не может заводить принтеры |
| T-06-08-02 | Tampering | admit использует sys_name из SNMP как device.name | mitigate | DeviceService::validate_new валидирует непустое name; sys_name трактуется как данные, не как SQL (params!), длина/санитизация на UI-слое при отображении |
| T-06-08-03 | Information Disclosure | community string при admit/create | accept | community хранится как Secret<String> в service-слое; PrinterDto не сериализует community (Pitfall 4, community_configured: bool) |
| T-06-08-04 | Spoofing | дубликат принтера по IP | mitigate | admit пропускает уже заведённые IP (is_duplicate / repo-проверка) — нет двойного учёта |
</threat_model>
