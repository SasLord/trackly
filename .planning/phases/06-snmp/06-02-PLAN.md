<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| RequestService::create → DB | Пользовательские данные из браузера — validated через DTO |
| PrinterService::discover → сеть | IP-диапазон от admin — потенциальный SSRF к внутренней сети |
| broadcast::Sender → WS clients | Роль-фильтр не в channel, а в WsEvent::is_visible_to |
| Secret<T> community | community_configured: bool в DTO — строка НИКОГДА не передаётся клиенту |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-04-S | Elevation of Privilege | RequestService::transition | mitigate | authorize(caller, &Action::TransitionRequests) + validate_from_status проверяет допустимый статус; нельзя пропустить через HTTP (D-RBAC-01) |
| T-06-05-T | Tampering | PrinterService::discover (SSRF) | mitigate | discover только для admin (authorize MutatePrinters); IP парсится через Ipv4Addr::from_str (невалидный → ошибка); RFC1918-проверка опциональна — в Phase 6 только admin может запустить |
| T-06-06-I | Information Disclosure | WsEvent broadcast leakage | mitigate | WsEvent::is_visible_to(&identity) server-side role filter; PrinterAlert только admin; сотрудник не видит чужих заявок |
| T-06-07-I | Information Disclosure | community в PrinterDto | mitigate | community_configured: bool (NOT String) в PrinterDto; Secret<String> wrapping при SNMP вызове; тест test_secret_debug подтверждает что Debug печатает "***" |
| T-06-08-T | Tampering | optimistic lock на requests | mitigate | transition_in_tx проверяет version=expected; несовпадение → AppError::Validation (стандартный паттерн Phase 3/4) |
</threat_model>
