```rust
pub trait PlaceRepository {
    type Conn;
    fn create(&self, conn: &mut Self::Conn, new: &PlaceNew, now_utc: i64) -> Result<i64, AppError>;
    fn get(&self, conn: &Self::Conn, id: i64) -> Result<PlaceRow, AppError>;
    fn list_children(&self, conn: &Self::Conn, parent_id: Option<i64>) -> Result<Vec<PlaceRow>, AppError>;
    fn list_all(&self, conn: &Self::Conn, include_archived: bool) -> Result<Vec<PlaceRow>, AppError>;
    fn rename(&self, conn: &mut Self::Conn, id: i64, name: &str, version: i64, now_utc: i64) -> Result<PlaceRow, AppError>;
    fn move_node(&self, conn: &mut Self::Conn, id: i64, new_parent_id: Option<i64>, version: i64, now_utc: i64) -> Result<PlaceRow, AppError>;
    fn archive(&self, conn: &mut Self::Conn, id: i64, version: i64, now_utc: i64) -> Result<(), AppError>;
    fn unarchive(&self, conn: &mut Self::Conn, id: i64, version: i64, now_utc: i64) -> Result<(), AppError>;
    fn delete_hard(&self, conn: &mut Self::Conn, id: i64, version: i64) -> Result<(), AppError>;
    fn subtree_stats(&self, conn: &Self::Conn, root_id: i64) -> Result<SubtreeStats, AppError>;
    fn list_subtree_contents(&self, conn: &Self::Conn, root_id: i64, nested: bool) -> Result<Vec<PlaceContentRow>, AppError>;
    fn list_storage_place_ids(&self, conn: &Self::Conn) -> Result<Vec<i64>, AppError>; // D-11.4: is_storage=true on self OR any ancestor
    fn full_path(&self, conn: &Self::Conn, id: i64) -> Result<String, AppError>;
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Any caller (Tauri/HTTP) → `authorize(identity, action)` | Every places mutation/read must cross this gate before reaching the repository — this plan defines the gate, later plans (05, 12) wire callers to it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-02-01 | Elevation of Privilege | `auth.rs::authorize` for `Action::MutatePlaces` | mitigate | `MutatePlaces` placed in the Admin-only match arm, verified by `authorize_manager_mutate_places_forbidden` — this is the exact regression this test exists to catch (RESEARCH Common Pitfall 3) |
| T-39-02-02 | Information Disclosure | `Action::ReadPlaces` for Employee | mitigate | Employee has neither `ReadPlaces` nor `MutatePlaces`; verified by `authorize_employee_read_places_forbidden` |
| T-39-02-03 | Tampering | `PlaceKind::from_str` accepting an unvalidated string | mitigate | Closed match with explicit `Err(AppError::Validation)` fallback — no `unwrap`/silent default, unknown kind values are rejected at the domain boundary before reaching any repo/SQL layer |
</threat_model>
