<objective>
Rename every location-bearing domain struct field across `acts.rs`, `cartridges.rs`,
`printers.rs`, `requests.rs` to its `place_id`-based equivalent, matching the V038 schema from
Plan 01 exactly. This is a pure, mechanical Rust-only change (no SQL, no service logic) — it makes
the domain layer compile against the new schema's column names before any repo/service plan
touches these entities, so Wave 3 plans (device/act/cartridge/report service migrations) start
from a domain layer that already speaks `place_id`.

Purpose: decouple the (large) domain-struct rename from the (larger, per-entity) service/repo
migration work, so those Wave 3 plans can run in parallel without re-deriving field names.
Output: four modified domain files with `place_id`/`bulk_place_id`/`place_id_override`/
`place_path_snapshot` replacing every `location`/`location_id` variant.
</objective>
