## Склад как место

### Чем становится склад в дереве

| Option | Description | Selected |
|--------|-------------|----------|
| Обычный узел + флаг is_storage | Склад живёт в реальной географии, попадёт на план этажа в фазе 43 | ✓ |
| Седьмой тип узла «склад» | Явная семантика, но тип начинает означать «для чего используется», а не «что это физически» | |
| Без выделения вообще | Склад — просто обычное помещение без признаков | |

**User's choice:** свободный ответ — «Склад может быть отдельной комнатой (помещением), а также
в кабинете может быть небольшой склад, например для картриджей. На складе также могут быть АРМ
и другие устройства в работе.»
**Notes:** Ответ подтверждает вариант «обычный узел + флаг» и добавляет два ограничения:
(1) склад может быть вложенным узлом внутри кабинета; (2) складское место НЕ означает, что всё
в нём выведено из эксплуатации.

### Какое поведение меняет признак «склад»

| Option | Description | Selected |
|--------|-------------|----------|
| Форма возврата | Складские места вверху списка / по умолчанию в акте возврата | ✓ |
| Отчёты и фильтры | Быстрый фильтр «на складе / в эксплуатации» | ✓ |
| Статус устройства | Перемещение на склад меняет статус на «на складе» | ✓ |
| Ничего не меняет | Флаг только в схеме, на будущее | |

**User's choice:** первые три
**Notes:** Выбор «Статус устройства» противоречил утверждению «на складе есть АРМ в работе» —
противоречие вынесено пользователю отдельным вопросом (см. ниже) и разрешено в пользу
«предлагать, не навязывать».

### Склад внутри кабинета

## Claude's Discretion

Пользователь явных предпочтений не высказал — оставлено researcher'у и planner'у:

- Способ хранения дерева в SQLite (adjacency list + рекурсивный CTE / денормализованный путь /
  closure table / materialized path).
- Защита от циклов при перемещении узла.
- Механика синхронизации FTS (триггеры vs сервисный слой) для требования «без ручной
  переиндексации».
- Форма хранения снимка пути в акте: колонка в `acts`, в `act_items` или в обеих.
- Конкретные имена таблиц и колонок (`places`, `place_id`, `is_storage`, `level`, `sort_order` —
  рабочие имена из обсуждения, не обязательство).
