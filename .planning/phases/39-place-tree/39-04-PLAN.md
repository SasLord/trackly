| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-39-04-01 | Tampering | Every SQL string in `places_sqlite.rs` | mitigate | `rusqlite::params![...]` parameterization throughout, matching the established pattern in `devices_sqlite.rs` — no raw string interpolation of caller-supplied values into SQL text |
