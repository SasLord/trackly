  <behavior>
    - Беседа без курсора -> запись со сводкой и последней страницей сообщений (по возрастанию seq), reload=false.
    - Курсор отстаёт -> только сообщения с rev > cursor, по возрастанию rev; курсор равен last_seq -> беседа в ответе отсутствует.
    - Изменений больше SYNC_RELOAD_THRESHOLD -> reload=true и последняя страница (тест на 205 сообщений).
    - Курсор на беседу, где пользователь не участник, молча игнорируется; в ответ не попадают чужие беседы даже при наличии их id в cursors.
