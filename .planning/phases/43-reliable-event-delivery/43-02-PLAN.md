## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| клиент -> WS-цикл | клиент присылает произвольные кадры (текст, бинарные) |
| сервер -> «мёртвый» peer | отправка в сокет без читателя может зависнуть |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-43-02-01 | Denial of Service | handle_ws_socket | mitigate | idle-таймер 60 с закрывает молчащих; send_text с SEND_TIMEOUT не даёт зависнуть на мёртвом peer |
| T-43-02-02 | Tampering | клиентский текст | mitigate | разбирается только JSON type=ping длиной <=256 байт, всё прочее игнорируется |
| T-43-02-03 | Information Disclosure | resync_required | accept | кадр без данных, не раскрывает ничего; не проходит видимость WsEvent |
| T-43-02-04 | Denial of Service | Lagged-лавина | mitigate | клиент получает resync_required один раз на событие Lagged; ёмкость канала не увеличивается (D-07); дебаунс на клиенте — План 03 |
| T-43-02-05 | Elevation of Privilege | ws auth | mitigate | ws_auth_middleware остаётся перед upgrade (401 без сессии); план не меняет |
</threat_model>
