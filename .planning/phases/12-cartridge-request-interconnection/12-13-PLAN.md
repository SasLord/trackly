<objective>
Расширить агрегатор автокомплита имён `suggest_person()` (GAP-12-06, A3) третьим источником: значением поля «Кто выдал» (`given_by_name`), которое сейчас пишется ТОЛЬКО в JSON-payload audit-лога картриджных операций (install/to_refill) и никогда не попадает в подсказки автокомплита — в отличие от «Кому выдал» (`given_to_name`), которое сохраняется в queryable-колонку `cartridges.holder_name` и уже агрегируется.

Purpose: оператор, который несколько раз был указан как «выдавший» в разных картриджных операциях, видит своё имя в автокомплите при следующем вводе — не только как «получивший».

Текущий `suggest_person()` (act_service.rs:1077-1132) — структура SQL (восстановить точный текст при чтении, не изобретать заново):
```
SELECT name, COUNT(*) freq FROM (
    SELECT giver_name AS name FROM acts WHERE deleted_at_utc IS NULL AND giver_name IS NOT NULL AND giver_name LIKE ?1
    UNION ALL
    SELECT receiver_name AS name FROM acts WHERE deleted_at_utc IS NULL AND receiver_name IS NOT NULL AND receiver_name LIKE ?1
    UNION ALL
    SELECT holder_name AS name FROM cartridges WHERE deleted_at_utc IS NULL AND holder_name IS NOT NULL AND holder_name LIKE ?1
) GROUP BY name ORDER BY freq DESC, name LIMIT ?2
```
(Восстановить точные имена колонок/параметров при чтении `<read_first>` — не точная копия, прочитать реальный код перед редактированием.)
