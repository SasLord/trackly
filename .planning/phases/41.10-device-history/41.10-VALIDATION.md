## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust `cargo test` (suite-бинарники `app_*`, `autotests = false`); UI — node-гейты `ui/scripts/check-*.mjs`, eslint/prettier, `svelte-check` |
| **Config file** | `crates/trackly-app/Cargo.toml` (`[[test]]`), `ui/package.json` (`scripts.lint`) |
| **Quick run command** | `DEVELOPER_DIR=/Library/Developer/CommandLineTools cargo test -p trackly-app --test <suite> -- <filter>` |
| **Full suite command** | команда `ci-full`: `cargo fmt --all -- --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace --no-fail-fast -- --test-threads=1` |
| **Estimated runtime** | быстрый скоуп — минуты; ci-full — часы (в фоне, один раз на границе фазы) |

Один `cargo test` одновременно. Команды `timeout` на машине нет.

---

## Sampling Rate

- **After every task commit:** скоупленная команда по затронутому suite + фильтру
- **After every plan wave:** `cargo test -p trackly-app --test app_gates` + затронутые suite-бинарники
- **Before `/gsd-verify-work`:** ci-full зелёный, затем `pnpm --dir ui lint`, `pnpm --dir ui svelte-check`, `pnpm --dir ui build`
- **Max feedback latency:** скоупленный прогон — минуты
