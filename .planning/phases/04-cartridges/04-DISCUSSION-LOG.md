## Модель: поля и совместимость

### «Название» модели

| Option | Description | Selected |
|--------|-------------|----------|
| Бренд + Модель (как в V005) | Два поля brand+model, отображать «Бренд Модель» | ✓ (через расширение) |
| Отдельное поле name | Свободное поле «Название» поверх brand/model | |

**User's choice (free-text):** Расширить домен — учитывать и картриджи, и **фотобарабаны** (всё относится к картриджам). Нужны два отдельных поля **Бренд** и **Модель** с focus-open автокомплитом. Модель бывает оригинальная или совместимая (видно по бренду). Совместимость с моделями принтеров — нужна; картриджи будут использоваться с принтерами в БД.
**Notes:** Примеры — Cactus/TL-5120P (совм. картридж), Cactus/DL-5120 (фотобарабан), Pantum/TL-5120X (оригинал, повыш. ёмкость).
