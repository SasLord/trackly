  <action>
    Создать `ui/src/lib/utils/dropdownAnchor.ts`, экспортирующий: интерфейс
    `DropdownAnchorParams { anchorEl: HTMLElement | null; gap?: number; maxHeight?: number }`
    и функцию `dropdownAnchor(node: HTMLElement, params: DropdownAnchorParams)` — Svelte
    use-action, возвращающая `{ update(newParams: DropdownAnchorParams): void; destroy(): void }`.
    Внутренняя функция `reposition()`: если `params.anchorEl` равен null — ничего не делает
    (защита от гонки до монтирования якоря); иначе вычисляет `rect =
    params.anchorEl.getBoundingClientRect()`, устанавливает
    `node.style.position = 'fixed'`, `node.style.left = rect.left + 'px'`,
    `node.style.width = rect.width + 'px'`. Вычисляет `gap = params.gap ?? 4` (соответствует
    `--space-xs`) и `maxHeight = params.maxHeight ?? 240`. Вычисляет `spaceBelow =
    window.innerHeight - rect.bottom`; если `spaceBelow >= Math.min(maxHeight, node.scrollHeight || maxHeight)`
    — открывает вниз: `node.style.top = (rect.bottom + gap) + 'px'`, `node.style.bottom = 'auto'`;
    иначе — флип вверх (D-02): `node.style.bottom = (window.innerHeight - rect.top + gap) + 'px'`,
    `node.style.top = 'auto'`. При инициализации action вызвать `reposition()` сразу, затем
    подписаться `window.addEventListener('scroll', reposition, true)` (третий аргумент
    `true` — capture-фаза, чтобы скролл ЛЮБОГО overflow-контейнера-предка триггерил
    репозицию, не только скролл окна) и `window.addEventListener('resize', reposition)`.
    `update(newParams)`: сохранить `params = newParams`, вызвать `reposition()` немедленно
    (нужно для потребителей вроде будущего Plan 18-04, где `anchorEl` меняется между
    строками таблицы через reactive-обновление параметров action). `destroy()`: снять оба
    listener (`removeEventListener('scroll', reposition, true)` — capture-флаг должен
    совпадать с addEventListener, иначе listener не снимется; `removeEventListener('resize', reposition)`).
    НЕ закрывать/скрывать дропдаун при scroll/resize — только пересчитывать координаты
    (в отличие от `DeviceContextMenu.handleScrollOrResize`).
  </action>
