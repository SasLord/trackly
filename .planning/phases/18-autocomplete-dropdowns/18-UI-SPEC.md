> Инкрементальная UX-фаза. Новых экранов и новых данных устройства нет. Меняется только

## Typography

Типографика зафиксирована глобально. Все элементы фазы используют существующие токены.

| Роль | Размер | Вес | Line Height | Токен |
|------|--------|-----|-------------|-------|
| Body (наименование устройства, значение опции) | 14px | 400 | 1.5 | `--font-size-body`, `--font-weight-regular` |
| Наименование в опции (акцент строки) | 14px | 500 | 1.5 | `--font-size-body`, `--font-weight-medium` |
| Label (SN / инв.№ / модель / состояние, хедер группы) | 13px | 400 | 1.4 | `--font-size-label`, `--font-weight-regular` |
| `×count` бейдж и заголовок drill-in (акцент) | 13px | 500 | 1.4 | `--font-size-label`, `--font-weight-medium` |

Используются ровно 2 веса из глобальной шкалы: **400 (regular)** для основного текста и мета-полей, **500 (medium)** для акцентных элементов (наименование в опции, `×count`-бейдж, заголовок drill-in). Вес 600 (semibold) в этой фазе НЕ используется. Задействованы 2 размера (14px body / 13px label); глобальные heading 20px / display 28px в пикере не применяются. Новых размеров/весов не вводится.

## Color

Палитра зафиксирована глобально (light + dark в `_tokens.scss`). Новых токенов НЕ вводится.

| Роль | Light | Dark | Использование в фазе |
|------|-------|------|----------------------|
| Доминирующий фон (60%) | `#ffffff` (`--color-bg`) | `#0f1419` | Фон инпута-якоря |
| Вторичная поверхность (30%) | `#ffffff` raised / `#f5f6f8` surface | `#1a1f26` | Фон portal-дропдауна (`--color-surface-raised`), hover-строки (`--color-surface-sunken`) |
| Акцент (10%) | `#2563eb` (`--color-accent`) | `#3b82f6` | ТОЛЬКО: фокус-кольцо инпута-якоря, активный (клавиатурный) элемент дропдауна, `×count`-бейдж группы |
| Деструктивный | `#dc2626` (`--color-destructive`) | `#ef4444` | ТОЛЬКО row-error валидации позиции («Выберите устройство») — существующее поведение |

Акцент зарезервирован ТОЛЬКО за: (1) фокус-обводкой поля-якоря, (2) активным по клавиатуре элементом дропдауна, (3) `×count`-бейджем группы/подгруппы. Наведение (hover) на элемент дропдауна — `--color-surface-sunken`, без акцентного текста.

Тень portal-дропдауна: `--shadow-elev-2` (light) / `--shadow-elev-2-dark` (dark) — унаследовано, соответствует существующим `box-shadow: var(--shadow-md)` в `LocationAutocomplete`.

## AUTO-01 — Portal-дропдаун: визуальный и позиционный контракт

### Позиционирование

| Свойство | Правило |
|----------|---------|
| Рендер-узел | `document.body` (portal) — вне overflow-контейнера модалки |
| CSS position | `position: fixed` |
| Ширина | Равна ширине инпута-якоря (`anchorRect.width`) |
| Горизонталь | `left = anchorRect.left` |
| Вертикаль (по умолчанию) | `top = anchorRect.bottom + var(--space-xs)` (4px зазор на сетке) |
| Флип вверх | Если снизу не помещается `min(contentHeight, 240px)` до нижней кромки viewport → `bottom = viewportHeight - anchorRect.top + var(--space-xs)` (раскрытие вверх) |
| Репозиция | На `scroll` (capture, любой контейнер) и `resize` окна — пересчёт координат, дропдаун СЛЕДУЕТ за якорем (D-02). НЕ закрывать при скролле |
| Закрытие | Клик вне (`mousedown` outside), `Escape`, выбор элемента, `blur` якоря без выбора |
| z-index | `1000` (над модальным оверлеем; модалки в проекте < 1000) |
| max-height | `240px`, `overflow-y: auto` — внутренний скролл ТОЛЬКО у дропдауна |

### Визуал (без изменений относительно текущих дропдаунов)

- Фон: `--color-surface-raised`
- Рамка: `1px solid var(--color-border)`, `border-radius: var(--radius-sm)` (4px)
- Тень: `--shadow-elev-2` / `--shadow-elev-2-dark`
- Элемент: `padding: var(--space-sm) var(--space-md)`, hover/active — см. раздел Color

**Инвариант AUTO-01:** открытый в модалке дропдаун раскрывается ПОВЕРХ содержимого диалога — без обрезки overflow-контейнером, без появления внутреннего скролла у модалки, без искажения её вёрстки.

## AUTO-02 / AUTO-03 — Focus-open + фильтрация пикера устройства

### Focus-open (AUTO-02, D-03)

Реплицировать канонический паттерн `LocationAutocomplete.handleFocus`:

| Событие | Поведение |
|---------|-----------|
| `onfocus` на инпут пикера | `suppress = false`; немедленный fetch (delay 0) — показать список без ввода |
| Пустой ввод при фокусе | Показать **top-20** групп, отсортированных по остатку `count DESC` (D-04) |
| `ArrowDown` при закрытом дропдауне | Триггерит открытие (тот же fetch delay 0) |
| `Escape` | Закрыть дропдаун |

Убрать текущий early-return `if (v.trim().length < 1)` — пустой ввод теперь валиден и открывает список.

### Фильтрация (AUTO-03, D-04)

| Событие | Поведение |
|---------|-----------|
| Ввод символов | Дебаунс (сохранить существующие 200–250ms); фильтр по **наименованию + инвентарному № + серийному №** (backend `list_grouped` расширяется) |
| Реалтайм | Список перестраивается при каждом вводе; `activeIndex` сбрасывается в `-1` |
| Дедуп DEF-2A | Исключить группы, чьи `ids` пересекаются с уже выбранными в других строках |

**Инвариант AUTO-03:** фильтрация фактически работает (сейчас — регресс). Ввод текста сужает список; совпадение по инв.№/SN, а не только по префиксу имени.

## AUTO-04 — Группировка name+model с drill-in

### Уровень 1 — список групп

Группа верхнего уровня = **name + model** (model если есть) — D-05.

Строка группы (collapsed) показывает:

```
┌────────────────────────────────────────────────────────┐
│ {name}  {model?}                              ×{count} │   ← кликабельно
└────────────────────────────────────────────────────────┘
```

| Элемент | Стиль |
|---------|-------|
| `{name}` | `--font-size-body` 14px, `--font-weight-medium` 500, `--color-text-primary` |
| `{model}` | `--font-size-label` 13px, `--color-text-secondary` (опускается если null) |
| `×{count}` бейдж | `--font-size-label` 13px, `--font-weight-medium` 500, `--color-accent`; выравнивание вправо (`margin-left: auto`) |
| chevron `›` (14×14) | опционально справа от бейджа для раскрываемых групп — сигнал drill-in |

**D-08 — нераскрываемая группа:** если группа состоит ТОЛЬКО из несерийных И безынвентарных устройств с ОДНИМ состоянием — клик по строке группы **сразу выбирает** устройство (clone-семантика, qty вводится в колонке «Количество»), drill-in НЕ открывается, chevron НЕ показывается. Если состояния внутри разные — строки по состоянию (см. D-07 подгруппировка), клик по строке-подгруппе выбирает с указанием количества.

### Уровень 2 — drill-in (раскрытая группа, D-06)

Клик по раскрываемой группе **заменяет** список группами → членами этой группы. Сверху — кнопка «← назад».

```
┌────────────────────────────────────────────────────────┐
│ ← Назад            {name} · {model?}                   │   ← хедер drill-in
├────────────────────────────────────────────────────────┤
│ SN 12345  ·  инв. A-001  ·  Рабочее                    │   ← серийный/инвент. экземпляр (qty=1)
│ SN 12346  ·  Рабочее                                    │
│ Без номера · Требует ремонта              ×3           │   ← подгруппа по состоянию (несер./безынв.)
│ Без номера · Рабочее                      ×7           │
└────────────────────────────────────────────────────────┘
```

**D-07 — представление членов раскрытой группы:**

| Тип экземпляра | Отображение | Выбор |
|----------------|-------------|-------|
| Серийный ИЛИ инвентаризированный | Отдельная строка: `SN {serial}` и/или `инв. {inv}` (что есть) + состояние | Выбор = qty 1 (жёстко) |
| Несерийный И безынвентарный | Подгруппируются по состоянию (condition); одна строка на состояние: `Без номера · {состояние}` + `×{count}` + инпут количества | Выбор с указанием количества (cap по count) |

Строка-хедер drill-in: кнопка «← Назад» слева (`--color-text-secondary`, hover `--color-text-primary`), название группы справа (`--font-size-label` 13px, `--font-weight-medium` 500, `--color-text-secondary`). Разделитель `border-bottom: 1px solid var(--color-border)`.

Мета-разделитель между полями строки — ` · ` (пробел-точка-пробел, `--color-text-muted`).

## AUTO-05 — Единственная группа → плоский список (D-09)

Если после фильтрации остаётся **ровно одна** группа (name+model) — строка-группа НЕ показывается. Вместо неё сразу выводится **плоский список экземпляров** этой группы — то же представление, что и в drill-in (D-07), но **без** хедера и кнопки «← назад».

```
┌────────────────────────────────────────────────────────┐
│ SN 12345  ·  инв. A-001  ·  Рабочее                    │
│ SN 12346  ·  Рабочее                                    │
│ Без номера · Рабочее                      ×7           │
└────────────────────────────────────────────────────────┘
```

**Инвариант AUTO-05:** пользователь не делает лишний клик «раскрыть» когда группа одна — экземпляры видны сразу.

## Interaction Contract (сводка)

| Событие | Поведение |
|---------|-----------|
| Focus на пикер устройства | Открыть дропдаун, top-20 групп по остатку (AUTO-02) |
| Ввод текста | Debounce → фильтр name+инв.№+SN, реалтайм (AUTO-03) |
| Список = 1 группа | Плоский список экземпляров без строки-группы (AUTO-05) |
| Клик по раскрываемой группе | Drill-in: заменить список членами + «← назад» (AUTO-04/D-06) |
| Клик по нераскрываемой группе (D-08) | Сразу выбор устройства, qty в колонке «Количество» |
| Клик «← Назад» | Вернуться к списку групп |
| Клик по строке-экземпляру (серийн./инвент.) | Выбор, qty = 1 |
| Клик по строке-подгруппе (по состоянию) | Выбор с вводом количества (cap по count) |
| ArrowUp/Down | Навигация по видимым строкам текущего уровня; акцентная подсветка активного |
| Enter/Tab на активном | Выбор активного элемента |
| Escape | Закрыть дропдаун (без выбора) |
| Скролл контейнера/окна | Дропдаун репозиционируется, следует за якорем (D-02) |
| Ресайз окна | Дропдаун репозиционируется; флип вверх при нехватке места снизу |
| Клик вне / blur без выбора | Закрыть дропдаун |

### Сохранить (не регрессировать) — D-08 Note

- Clone-on-handover qty-семантика (V015); `MAX_CLONE_QTY = 1000` hard-cap (UX-зеркало backend).
- Ограничение qty доступным остатком `stock_available` (нельзя выбрать больше, чем на складе).
- Дедуп уже выбранных устройств между строками позиций (DEF-2A).
- Серийные устройства: qty жёстко = 1, поле количества `disabled`.

## Accessibility

- Инпут-якорь: `role` не меняется, `aria-autocomplete="list"`, `autocomplete="off"` (существующий паттерн).
- Дропдаун (portal): `role="listbox"`; элементы — `role="option"` c `aria-selected` для активного.
- Drill-in: кнопка «← Назад» — нативный `<button type="button">` (клавиатурно-доступна, Tab/Enter).
- `Escape` закрывает дропдаун и возвращает фокус на якорь.
- Портирование в `body` не должно разрывать связь `aria-controls`/`aria-activedescendant` — если используется, id элементов сохраняются.
- Минимальная высота кликабельного элемента: `--touch-target-min` (36px) — комфортный тач/клик.
- Нативный `title=` на обрезанных мета-полях (SN/инв.№) — по паттерну 03.3 ITEM-2, при усечении.
