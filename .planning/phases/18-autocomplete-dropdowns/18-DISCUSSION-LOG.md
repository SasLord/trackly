## AUTO-04 — Группа vs количество / ключ группировки

| Option | Description | Selected |
|--------|-------------|----------|
| Экземпляр=qty1, ключ name+model+condition | Экземпляр → qty1; группа → ×count с qty (DEF-2B ключ) | |
| Группировать только по name | По тексту AUTO-04/05; model/condition видны внутри | ✓ (уточнено) |

**User's choice:** «Группировать только по name», затем уточнено freeform-ответом:
верхний уровень = **name + model**; строки экземпляров показывают SN/инв.№ и
состояние; несерийные+безынвентарные — подгруппировка по состоянию с ×count; группа
без инв.№/SN не раскрывается (клик = выбор с указанием количества).

**Notes:** Дословно — см. `<specifics>` в 18-CONTEXT.md. Итог зафиксирован как
D-05..D-08.
