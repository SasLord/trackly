# Phase 41.4 Plan 49: форма заявки и область принтеров (D-41)

Форма «Замена картриджа» показывает пояснение при успешной пустой загрузке принтеров; отказ сервера Forbidden при создании показывается у поля «Принтер». Клиентской фильтрации нет.

## Коммит

- `5608fc58` feat(41.4-49)

## Что сделано

- `printersLoaded` ($state): сбрасывается при открытии формы, ставится true сразу после `await requests.printerOptions()` (в catch не ставится). Пояснение под полем: «Нет доступных принтеров: принтер должен быть связан с вашей группой. Обратитесь к Специалисту.» только при `printersLoaded && availablePrinters.length === 0`.
- Forbidden при `requests.create` (cartridge_replace): прежний путь показывал сырое `message` тостом сверх общего тоста client.ts. Теперь в `handleSubmit` код FORBIDDEN даёт `printerError` «Этот принтер недоступен: он не связан с вашей группой. Выберите другой.», сбрасывает выбор, перезагружает список; второй тост не добавляется. client.ts не менялся (общий тост «Недостаточно прав» остаётся для всех экранов); форма не закрывается.
- Гейт `check-request-flow`: правило [F] (вложенность пояснения в `{#if printersLoaded && length===0}` без printersLoading; присвоение после await и вне finally; запрет `.filter(`/`.slice(`/самоприсваивания availablePrinters). Мутанты selftest: нет текста, printersLoading вместо printersLoaded, присвоение до await, клиентский filter. Правила [A]-[E] зелёные.
