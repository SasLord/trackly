## Shared Patterns

### Единственный writer + рассылка после коммита
**Источник:** `request_service.rs:540-578`, `cartridge_service.rs:138-152`
**Применять к:** `repair_service.rs` и всем мутациям цикла. Запись и чтение для побочных проверок — внутри одной транзакции (не из reader-пула); `broadcast_entities("<литерал>", ...)` и `RequestStatusChanged` только после `.await?`.

### Авторизация на тонком адаптере
**Источник:** `tauri_cmds/acts.rs:201`, `tauri_cmds/reports.rs:228`
**Применять к:** всем `build_*`: `authorize(caller, &Action::...)?` первой строкой; сотрудник не допущен к мутациям цикла (`role_endpoint_matrix.rs`); BOLA для сотрудника проверяется на сервере (`request_service.rs:93-97`).

### Пара «Tauri-команда + HTTP-маршрут»
**Источник:** `http/acts.rs:373-381`, `http/reports.rs:339-353`
**Применять к:** каждой новой команде, включая печать акта, отчёт, предзаполнение места и опции устройств формы. `spa_fallback` теперь отдаёт 404 на неизвестный `/api/`, но экран по LAN всё равно ломается; ловит `http_route_parity.rs`.

### Ошибки
**Источник:** `device_service.rs:1374-1380`, `number_template_service.rs:658-671`
`AppError::Validation { field, message }` для понятных отказов (текст на русском, ведущий к заявке), `AppError::Conflict { reason }` для D-19/D-21/D-22, `OptimisticLockMismatch` из CAS (`requests_sqlite.rs:154-161`). Нарушение частичного индекса D-19 отображать в `Conflict`/присоединение, не в `Internal`.

### Статусы по `code`
Сравнивать и искать по `code` (`на_ремонте`, `в_ремонте`, `на_ремонте`, `на_складе`, `в_работе`, `на_списание`), не по подписи и не по числовому id (41.1 D-03).

### Приватность
В шаблонах, тестах и фикстурах только переменные и вымышленные имена («Иванов И.И.», «Петров П.П.», «ООО Демо Организация»). Реквизиты — только из `org_settings`.
