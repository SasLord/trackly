# Phase 41.4 — Validation Strategy

> Per-phase validation contract. Карта «требование → тест» — в 41.4-RESEARCH.md §Validation Architecture.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | cargo test; UI — svelte-check, eslint, `ui/scripts/check-*.mjs` |
| **Config file** | `.github/workflows/ci-fast.yml`, `ci-full.yml` |
| **Quick run command** | `cargo test -p <crate> --test <файл>` (один за раз) |
| **Full suite command** | `cargo test --workspace --no-fail-fast -- --test-threads=1` (в фоне, только перед verify) |
| **Estimated runtime** | целевой тест — минуты; сплошной прогон — часы |

## Sampling Rate

- **After every task commit:** целевой тест изменённой области + `cargo fmt --all -- --check`
- **After every plan wave:** gate-тесты из RESEARCH + `cargo clippy --workspace --all-targets -- -D warnings` + `pnpm --dir ui svelte-check` + `pnpm --dir ui lint`
- **Before `/gsd-verify-work`:** сплошной прогон зелёный
