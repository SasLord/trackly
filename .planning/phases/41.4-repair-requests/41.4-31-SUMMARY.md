# Phase 41.4 Plan 31: печатный отчёт о ремонтах устройства Summary

Персонал печатает полный отчёт по устройству (шапка организации, устройство, сводка, заявки с заходами) из серверного HTML на обоих транспортах; шаблон редактируется в общем редакторе, предпросмотр не падает.

## Что сделано

- Шаблон `repair_device_report.html`: шапка `_header.html`, устройство, сводка, цикл по заявкам с таблицей заходов (уход/возврат, сервис, акт, неисправность, работы, стоимость, скан), ветка «Ремонтов не было»; без `| safe`.
- Регистрация: `DEFAULT_HTML_TEMPLATES`, пустая запись `KNOWN_LEGACY_DEFAULTS` (первое тело, снимок снять перед следующей правкой), полная ветка `demo_context_for_kind` (две заявки, три захода, null-значения), подпись и переменные в `TemplateEditor.svelte`, тест предпросмотра, счётчик видов 4 -> 5.
- `render_device_report(repairs, device_id, caller)`: authorize(TransitionRequests), данные из `RepairService::device_history`, русские статусы через `translate_request_status` (теперь `pub(crate)`), запись в БД отсутствует.
- `build_repairs_render_device_report`, команда `repairs_render_device_report`, маршрут HTTP (`text/html; charset=utf-8`), specta, строки в матрице ролей (HTTP и Tauri-билдеры), bindings перегенерированы (`ui/src/bindings.ts` в .gitignore, в коммит не входит).

## Deviations from Plan

1. [Архитектура, мелкая] `RepairService` передаётся параметром `render_device_report`, а не зависимостью конструктора (см. decisions); конструктор и 9 мест вызова не тронуты, `repair_act_render` зелёный.
2. [Процесс] TDD-красная фаза соблюдена только в задаче 1 (тест предпросмотра падал «must exist in DEFAULT_HTML_TEMPLATES» до регистрации). В задачах 2-3 рендерер написан до тестов; несущую силу тестов подтверждают мутации.
3. [Rule 1 - тест] HTTP-тест сначала использовал сессию Manager для пользователя с ролью employee в БД и получал не 200; добавлен отдельный пользователь-менеджер.
4. Мутация «убрать вызов device_history» заменена на «очистить requests после вызова» (без вызова нет значения для остального кода).
5. Предупреждения прежних сборок: rustc зависал на 0% CPU при почти полном swap; процесс перезапускался (код не менялся).
