# Phase 41.4 Plan 19: сборка карточки заявки Summary

Карточка заявки подключает попапы цикла ремонта, секцию «Заходы в сервис» и читаемую историю; кнопки шапки строятся по таблице UI-SPEC §3.

## Что сделано

- `RequestDetail.svelte`: состояние ремонта (`repairs.getState`) грузится при открытии, по смене версии заявки и по WS `entities_changed`; защита от устаревших ответов счётчиком `repairLoadSeq`, итог действия сразу пишется в состояние.
- Шапка по состояниям: Создана (с устройством — попап перемещения; «Другое» — без попапа), В работе (свежая/перемещённая/после возврата/«Другое»), В ремонте (primary «Забрать из ремонта», «Отменить ремонт» disabled с подсказкой и aria-describedby, без «Завершить»). Одна primary в каждом состоянии.
- «Отклонить» и «Отменить заявку» для repair идут через `repairs.reject` / `repairs.cancelByAuthor`; остальные типы без изменений.
- «Отменить ремонт» — модалка подтверждения (фокус на «Назад»), тосты по UI-SPEC.
- История: `entryText` с подписями событий ремонта; неизвестные `repair_*` -> «Изменение заявки», сырых кодов нет.
- Статус «В ремонте» (Badge warning), тип «Ремонт».
- `RequestsPage.svelte`: закрыт хвост плана 07 — карточка открывается по `?id=N` (ссылки отчёта и «Открыть заявку №…»).
- `Button.svelte`: необязательный `ariaDescribedby`.

## Deviations from Plan

**1. [Rule 2 - Missing critical functionality] Данные для истории ремонта на сервере**
- **Issue:** история заявки отдаёт только `notes` из payload; место перемещения, сервис и описание присоединившегося туда не попадали, а «Забрать на склад» писало аудит только на сущность «устройство».
- **Fix:** в `repair_service.rs` в payload добавлен `notes` (путь места / сервис / описание) для `repair_accept`, `repair_send`, `repair_join`; в `move_to_storage` добавлена запись `custom:repair_move` на заявку.
- **Files:** crates/trackly-app/src/services/repair_service.rs. **Commit:** 6426af71
- Файл вне `files_modified` плана; изменения аддитивны.

**2. [Rule 3] Button.ariaDescribedby и RequestsPage ?id=** — нужны для aria-describedby и закрытия стаба плана 07. **Commit:** a6326189
