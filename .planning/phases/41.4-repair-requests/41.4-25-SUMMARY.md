# Phase 41.4 Plan 25: календарь, автораскрытие, вложенный якорь Summary

Иконка календаря в общем DatePicker выровнена по правому краю правилами для `::-webkit-datetime-edit` и `::-webkit-calendar-picker-indicator`; попапы перемещения и завершения заявки открываются с фокусом на «Отмена» (список мест не раскрывается сам); клиентская блокировка вложенного якоря снята.

## Выполнено

1. DatePicker: `::-webkit-datetime-edit { flex: 1 1 auto; text-align: left }`, `::-webkit-calendar-picker-indicator { margin-left: auto; cursor: pointer }`. Публичные props и Repair*Modal не тронуты.
2. RepairMoveModal: `initialFocus=".modal-footer .btn-secondary"`; удалены производная вложенности, `disabled` у PlacePicker, условие скрытия быстрого выбора склада, ранний выход в `move()`, подсказка про группу; подсказка про детали блока остаётся по `isAnchor && groupBlockSize > 0`. RepairCompleteModal: при `moved` фокус на «Отмена».
3. Гейт `ui/scripts/check-repair-modal-focus.mjs` (+ `--selftest`), подключён в `lint` в конец цепочки. Читает только `ui/src/features/requests/Repair*Modal.svelte`, комментарии снимает через `_strip.mjs`.

Мутационная проверка: в реальном RepairMoveModal.svelte `initialFocus` временно возвращён на `"#rep-move-place"` (якорь уникален, найден 1 раз) — гейт красный: `FAIL: RepairMoveModal.svelte: initialFocus указывает на PlacePicker #rep-move-place`, exit=1. После восстановления гейт зелёный, `git diff` по файлу содержит только намеренные правки задачи 2.
