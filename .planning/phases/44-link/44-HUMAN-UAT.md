# Фаза 44 — живая проверка (план 44-20, задача 3)

Отмечать «проверено» только то, что прогнано руками на реальной платформе. Остальное — «не проверено», соответствующие требования остаются Pending.

**Подготовка:** код в `main` → `pnpm --dir ui build` → Trackly в режиме сервера (Настройки → Сеть → запустить), в настройках виден «Отпечаток для Link (SPKI):». Для Windows — сборка из CI.
