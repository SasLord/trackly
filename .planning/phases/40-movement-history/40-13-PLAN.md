analog and the exact source of the item list this mutation walks:
```rust
pub async fn list_subtree_contents(&self, caller: &Identity, root_id: i64, nested: bool) -> Result<Vec<PlaceContentRow>, AppError> {
    authorize(caller, &Action::ReadPlaces)?;
    let readers = self.readers.clone();
    let repo = self.repo.clone();
    tokio::task::spawn_blocking(move || {
        let conn = readers.acquire();
        repo.list_subtree_contents(&conn, root_id, nested)
    }).await.map_err(|e| AppError::Internal { source_chain: format!("spawn_blocking: {e}") })?
}
```
`PlaceContentRow` has `kind: 'device'|'printer'|'cartridge'` and `id` — walk this SAME shape inside ONE
`self.writer.execute(move |conn| { let tx = conn.transaction()...` block (D-13: reuses
`MutateDevices`/`MutateCartridges` per row kind, `kind='printer'` treated identically to `kind='device'`
since both address `devices.place_id`).
From Plan 40-05: `record_movement_if_applicable(...)` — call once per item, `MovementSource::Manual`
(D-28 IS a manual bulk action per the UI-SPEC's copy — "Перенести" is not a distinct source token; D-07
only has four values and bulk-move is user-initiated exactly like a single manual edit, just batched).
