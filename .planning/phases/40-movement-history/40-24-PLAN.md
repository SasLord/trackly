<interfaces>
`ActsPage.svelte` (строки 25-59, 96-137):
```
type TabKey = 'handover' | 'returns' | 'archive';
const initialFocusId = parseIdFromHash();
let activeTab = $state<TabKey>('handover');
let selectedActId = $state<number | null>(initialFocusId);
```
`baseFilter` (строка 54-59): `act_type: activeTab === 'returns' ? 'return' : 'handover'`,
`archived: activeTab === 'archive' ? true : activeTab === 'handover' ? false : null`.
Значит: `act_type==='return'` → ОБЯЗАНА быть вкладка `'returns'` (archived для returns не
фильтруется — `null`); `act_type==='handover' && archived===true` → вкладка `'archive'`;
иначе → `'handover'`.

Существующий guard-эффект (строки 96-105): `isFirstTabEffectRun` пропускает первый прогон
эффекта, следящего за `activeTab`, чтобы не обнулить `initialFocusId` сразу при монтировании.
Эффект на строке 114-137 вызывает `acts.get(id)` при каждом изменении `selectedActId` и
кладёт результат в `selectedAct` — это готовое место прочитать `act_type`/`archived`
целевого акта, ТАК КАК deep-link уже устанавливает `selectedActId = initialFocusId` при
инициализации `$state`.

`ActDto` (crates/trackly-app/src/dto/act.rs) содержит `act_type: String` ('handover'|'return')
и `archived: bool` — оба поля уже приходят с бэкенда, ничего расширять не нужно.

`format_act_number(act_type: ActType, number: i64, sub_number: Option<i64>, parent_number:
Option<i64>, sibling_return_count: Option<i64>) -> String` (crates/trackly-app/src/dto/act.rs:23)
— единственный владелец форматирования номера акта. `SqliteActRepository::SELECT_ACTS`
(crates/trackly-infra/src/repos/acts_sqlite.rs:34-49) показывает канонический запрос
`parent_number`/`sibling_return_count`:
```
SELECT a.number, a.sub_number, a.act_type, p.number AS parent_number,
       (SELECT COUNT(*) FROM acts r WHERE r.parent_act_id = COALESCE(a.parent_act_id, a.id)
          AND r.deleted_at_utc IS NULL) AS sibling_return_count
  FROM acts a LEFT JOIN acts p ON p.id = a.parent_act_id
 WHERE a.id = ?1
```

`place_movement_service.rs::get_timeline` (строки 93-103) — текущий код для замены:
```
let act_number: Option<String> = row.act_id.and_then(|act_id| {
    conn.query_row("SELECT number FROM acts WHERE id = ?1", params![act_id],
        |r| r.get::<_, i64>(0))
        .optional().ok().flatten().map(|n| n.to_string())
});
```
