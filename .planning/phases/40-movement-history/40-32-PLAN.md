From `ui/src/features/places/PlaceTree.svelte` (current buggy cache, lines 309-330):
```
let statsCache = $state<Record<number, number>>({});
const statsInFlight = new Set<number>();

$effect(() => {
  for (const row of visibleNodes) {
    const id = row.place.id;
    if (statsCache[id] !== undefined || statsInFlight.has(id)) continue;
    statsInFlight.add(id);
    apiCall<SubtreeStatsDto>('places_subtree_stats', { rootId: id })
      .then((s) => { statsCache = { ...statsCache, [id]: s.device_count + s.cartridge_count }; })
      .catch(() => {})
      .finally(() => { statsInFlight.delete(id); });
  }
});
```
Deleting a key from `statsCache` (producing a NEW object without it) makes this existing
effect re-fetch it the next time that id appears in `visibleNodes` — no new fetch logic
needed, only cache eviction.
