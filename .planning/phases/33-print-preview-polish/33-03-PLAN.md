<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| User-editable HTML template output ↔ preview `<iframe>` | This plan changes the iframe's `sandbox` attribute from `""` to `"allow-scripts"` for the paginated case — the first time this document is allowed to execute script (D-05). |
| Preview `<iframe>` (opaque origin) ↔ parent (`PdfPreviewModal.svelte`) | New bidirectional `postMessage` channel (Plan 33-01's bridge, wired here). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-33-03-01 | Elevation of Privilege | `<iframe>` `sandbox` attribute: `""` → `"allow-scripts"` for the paginated preview (D-05) | mitigate | `allow-same-origin` is deliberately NOT added — the iframe document keeps an opaque origin, so even though the injected Paged.js script can now execute, it has no access to `document.cookie`, `localStorage`, or the parent window's DOM. `postMessage` (with strict `event.source` identity checks, T-33-03-02) is the only cross-boundary channel. The document rendered inside originates from a user-editable HTML template (pre-existing Phase 16 D-03 boundary); this sandbox posture, stacked with Plan 33-02's CSP hash-source, is the compensating control for that boundary. The degraded fallback (T-33-03-04) reverts to the original `sandbox=""` posture, so the widened capability only exists while Paged.js is actually confirmed to be running the expected script. |
| T-33-03-02 | Spoofing | `postMessage` sender validation (`attachBridge`, wired via `iframeEl`) | mitigate | Validates `event.source === iframeEl.contentWindow` (object identity), never `event.origin` (always the literal string `"null"` for an opaque-origin sender and thus unusable) — implemented in Plan 33-01, wired in this plan's Task 1. |
| T-33-03-03 | Information Disclosure | Parent → iframe `trackly-theme-update` postMessage uses `targetOrigin: '*'` | accept | The opaque-origin iframe has no addressable origin to target more narrowly; the payload is a non-secret CSS color hex string, not user/session data. |
| T-33-03-04 | Denial of Service (soft) | Paged.js pagination hangs or errors (e.g. a Plan 33-02 CSP regression, or a pathological template) | mitigate | 8-second client-side timeout (D-02) forces the degraded fallback (`sandbox=""`, raw unpaginated `srcdoc`) instead of an indefinite spinner or blank screen; `console.warn` logs the reason for diagnosability, matching UI-SPEC's explicit instruction that this is a developer-facing log concern, not a user-facing alarm. |
</threat_model>
