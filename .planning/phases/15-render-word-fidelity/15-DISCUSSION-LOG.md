## Мультиустройство: таблица vs карточки (PDFA-02)

| Option | Description | Selected |
|--------|-------------|----------|
| Карточка на устройство | Повтор вертикального key-value блока на каждую позицию (как в образце); длинные поля переносятся естественно | |
| Широкая ItemsTable | Одна строка на устройство, 8 колонок; overflow длинных ячеек на A4 portrait → landscape/мелкий шрифт | |
| Гибрид | Компактная таблица для коротких полей + отдельный блок на устройство для длинных (Комплектация/Тех.хар-ки/Состояние) | ✓ |

**User's choice:** Гибрид
**Notes:** Компромисс между компактностью таблицы и читаемостью длинных полей; точное расположение — Claude's Discretion в рамках «без overflow, читаемо при 1 и N».
