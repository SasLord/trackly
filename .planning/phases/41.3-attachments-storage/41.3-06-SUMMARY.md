# Phase 41.3 Plan 06: HEIC и Windows-спайк Summary

Тело `heic_to_jpeg` под `cfg(feature = "heic")` (план 02) уже соответствовало спецификации: потолок 100 Мпикс до декодирования, `ignore_transformations` не задаётся, JPEG q90 без EXIF. В этом плане добавлены тесты, ручной спайк-workflow и уведомление о лицензии.

## Что сделано

- **Задача 1** (7fffcd6c): `tests/attachments_heic.rs`. Обычная сборка: `heic_to_jpeg` возвращает `Unavailable`, sniff помечает синтетический заголовок ftyp-heic как `is_heic`, не просматриваемый. Под фичей: мусорный HEIC даёт `Failed`; конвертация образца проверяет сигнатуру FF D8 FF и декодирование через `image`.
- **Задача 2** (db76a5a3): `heic-spike.yml` — только `workflow_dispatch`; vcpkg `libheif[core,libde265]:x64-windows-static-md` (без x265, без cargo-vcpkg), `VCPKGRS_TRIPLET`, `crt-static` не задан; сборка, тесты, `dumpbin /dependents` с провалом job при heif.dll/libde265.dll, артефакт отчёта. Условие успеха для включения фичи в релиз описано в комментарии (решение человека, план 15). `THIRD-PARTY-NOTICES.md`: LGPL-3, ссылки на исходники, порядок пересборки.
