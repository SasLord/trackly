# Phase 41.3 Plan 02: Файловый и медиа-слой вложений Summary

Хранилище блобов по хешу (`<root>/<2 hex>/<64 hex>`) и медиа-модуль (определение типа по сигнатуре, миниатюры с лимитами, sha256, заглушка HEIC), без БД и транспорта.

## Что сделано

- **Задачи 1** (4792133c): зависимости (`multipart` у axum, `infer`, `percent-encoding`, image `webp`+`gif`, `tempfile` в обычные зависимости, `libheif-rs` опционально за фичей `heic`, не в default; `cargo tree` не содержит libheif). `AttachmentStore`: `ensure_dirs`, `root_available`, `blob_path`/`thumb_path` (только валидный хеш), `begin_staging` в `.tmp`, `commit_staged` (fsync + `persist_noclobber`, 3 повтора при PermissionDenied), `remove_blob`, `scan` через `symlink_metadata` с пропуском симлинков. Тесты: 6.
- **Задачи 2 и 3** (d0352141): `sniff` по сигнатурам (JPEG/PNG/GIF/WebP, HEIC с флагом, PDF, DOCX/XLSX/ODT/ODS, DOC/XLS только по полному буферу, ZIP, 7z, текст по расширению txt/csv/log без NUL) с deny-листом (MZ, ELF, Mach-O, `#!`, HTML/SVG/script). `make_thumbnail`: лимиты декодера до декодирования (16384 и 512 МиБ), EXIF-ориентация, 272x192, альфа на белом, JPEG q80, запись через `.tmp`. `sha256_file` блоками по 8 КиБ. `heic_to_jpeg`: без фичи `Err(Unavailable)`, с фичей реализация на libheif-rs. Тесты: 14.

## Проверка

- `cargo test -p trackly-app --lib attachment_store`: 6/6; `--lib attachment_media`: 14/14.
- `cargo clippy -p trackly-app --all-targets -- -D warnings` и `cargo fmt --check` чисты; privacy-гейт пройден.

## Deviations from Plan

**1. [Rule 3 - Blocking] Разрешение dead_code.** Модули `pub(crate)` пока не используются, `-D warnings` падает; добавлен `#![allow(dead_code)]` с комментарием, снять в планах 05-08.

**2. Фикстуры без дублирования.** План допускал дубль генераторов в unit-тестах; вместо этого один файл подключается через `#[path]`.

**3. Ветка `heic` не компилировалась.** Реализация под `cfg(feature = "heic")` написана по API libheif-rs 3.0, но в этой сборке (macOS, без системного libheif) не собиралась; финальная проверка отнесена к плану 41.3-06.
