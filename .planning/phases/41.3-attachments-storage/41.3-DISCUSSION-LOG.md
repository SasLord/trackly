## Лимиты и типы файлов

| Вопрос | Варианты | Выбрано |
|--------|----------|---------|
| Размер | 20 МБ в настройках / 10 МБ фикс / 50 МБ фикс | 20 МБ, меняется в настройках |
| Типы | Фото+PDF+Office+txt / то же + ZIP/7z / Только фото и PDF | То же + ZIP/7z |
| HEIC | Как файл на скачивание / Конвертировать в JPEG / Отклонять | Конвертировать в JPEG |

| WebP | Хранить как есть, показывать / Конвертировать в JPEG | Хранить как есть, показывать |
| Количество | Несколько, без предела / По одному / Не больше N | Несколько, без предела |

**Notes:** пользователь отдельно попросил поддержку WebP. Выбор libheif на сервере сделан, зная про риск DLL; в CONTEXT зафиксирована статическая сборка и возврат к пользователю, если она невозможна.

## Удаление и дубли

| Вопрос | Варианты | Выбрано |
|--------|----------|---------|
| Кто удаляет | Загрузивший+специалисты / Только специалисты / Никто, только скрыть | Загрузивший+специалисты (с уточнением) |
| Файл на диске | Стирается при отсутствии ссылок / Остаётся | Остаётся до «удалить навсегда» администратором |
| Удаление родителя | Следуют за родителем / Всегда остаются | Следуют за родителем |
| Целостность | Тихая уборка при запуске / Плюс отчёт в настройках / Не нужна | Плюс отчёт в настройках |

**Notes:** у загрузившего и специалистов удаление мягкое и визуально полное. Администратор видит удалённые с пометкой, может восстановить или удалить навсегда; файл на диске стирается только после этого.
