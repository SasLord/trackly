## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| webview URL → URI-scheme handler | path is attacker-influenced (any script in the webview) |
| invoke headers → upload | name/parent come from the client |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41.3-39 | Elevation | scheme bypass of authorization | mitigate | handler only calls open_for_read (same authorize); parse_uri strict numeric id + whitelist kind; tests |
| T-41.3-40 | Tampering | path traversal via URI | mitigate | URI yields only an integer id; disk path built from DB hash |
| T-41.3-41 | Elevation | stored XSS via inline content | mitigate | inline only raster+PDF; nosniff; Content-Type from DB |
| T-41.3-42 | DoS | oversized raw invoke body | mitigate | length compared with limit before staging; ceiling 100 MiB |
| T-41.3-43 | Tampering | header injection in Content-Disposition | mitigate | ascii fallback strips CR/LF/quote/backslash; unit tests |
| T-41.3-44 | Information disclosure | ACAO header | accept | scheme only reachable inside the webview; requests still authorize |
</threat_model>
