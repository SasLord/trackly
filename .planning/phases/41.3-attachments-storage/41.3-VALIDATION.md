## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust `cargo test` (tokio::test, tempfile); UI: eslint + prettier + `svelte-check` + `ui/scripts/check-*.mjs` (no vitest) |
| **Config file** | `clippy.toml`, `ui/package.json` (`lint`), `.github/workflows/ci-fast.yml` / `ci-full.yml` |
| **Quick run command** | `TRACKLY_AD_MOCK=1 TRACKLY_SNMP_MOCK=1 cargo test -p trackly-app --test <phase test file> -- --test-threads=1` (one `cargo test` at a time) |
| **Full suite command** | the `ci-full` command sequence, once at a wave boundary, in background, raw output to a file (4.5–6 h; no `timeout` binary on this machine) + `pnpm --dir ui lint && pnpm --dir ui exec svelte-check && pnpm --dir ui build` |
| **Estimated runtime** | targeted test ~1–3 min (fresh binary waits ~1 min); full suite 4.5–6 h |

`trackly-app` tests need `TRACKLY_AD_MOCK=1 TRACKLY_SNMP_MOCK=1` and a real pnpm-built `ui/dist`.

---

## Sampling Rate

- **After every task commit:** the task's targeted `cargo test --test <file>` + `cargo clippy -p <crate> -- -D warnings` + `cargo fmt --check`; UI tasks: `pnpm --dir ui lint` AND `pnpm --dir ui exec svelte-check` (separate commands).
- **After every plan wave:** `--test http_route_parity`, `--test entities_changed_gate`, `--test security_headers`, `--test backup_service`, `node scripts/check-privacy.mjs --hashes scripts/privacy-tokens.sha256`, `pnpm --dir ui build`.
- **Before `/gsd-verify-work`:** full `ci-full` green; Windows HEIC spike job result recorded.
- **Max feedback latency:** ~180 s for targeted tests.
