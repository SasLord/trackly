## The Three Migration Rules (read this before touching any file)

Three different token families migrate under **three different rules**. Conflating them is the exact
footgun REQUIREMENTS.md warns about (642 silent `--space-*` moves). Executor must apply the correct rule
per family:

1. **Color (`--color-*` → `--tr-*`) — migrate BY ROLE, values ARE allowed to change.**
   This is the redesign. `--color-bg` (`#ffffff`) becomes `--tr-bg` (`#eef1f6`) — that's intentional, not a bug.
2. **Spacing & Radius (`--space-*`, `--radius-*` → `--tr-space-*`, `--tr-radius-*`) — migrate BY VALUE, values must NOT change.**
   Success criterion DS-04 is a hard "no layout shift" gate. Use the pixel-value map below, never the name.
   Two named exceptions (radius-sm split, radius-lg fix) are called out explicitly — everything else is silent value preservation.
3. **Typography (`--font-size-*`/`--font-weight-*`/`--line-height-*` → `--tr-text-*` / decomposed axis tokens) — migrate BY ROLE, sizes MAY shift onto the nearest of 9 defined levels.**
   DS-03 only requires text render on "one of 9 levels" — it does not require byte-identical old sizing. The one shift worth knowing about: display 28px → 30px (see table).

## Typography Scale (9 levels)

Each role is a bundle of size + weight + line-height (not independent axes) — this matches DS-03's
"renders on one of 9 levels" framing. **Recommended implementation:** define both a composite shorthand
token (usable via `font: var(--tr-text-{role})`) and the three decomposed axis values, so call sites that
today set size/weight/line-height independently (132/71+48+13/37 usages respectively) have a safe,
mechanical migration path without forcing a shorthand-only rewrite.

```scss
// Pattern per role, e.g. body:
--tr-text-body: 400 14px/1.5 var(--tr-font-family);   // font: var(--tr-text-body); + separate color
--tr-font-size-body: 14px;
--tr-font-weight-body: 400;
--tr-line-height-body: 1.5;
```

| Role | Token | Size | Weight | Line-height | Sample usage |
|------|-------|------|--------|-------------|---------------|
| Дисплей | `--tr-text-display` | 30px | 600 | 1.15 | Page-level hero headings |
| Заголовок H2 | `--tr-text-h2` | 24px | 600 | 1.25 | Section headings ("Список устройств организации") |
| Заголовок H3 | `--tr-text-h3` | 20px | 600 | 1.3 | Card/modal titles ("Акт приёма-передачи № A-000142") |
| Подзаголовок | `--tr-text-subtitle` | 16px | 600 | 1.4 | Widget/panel subtitles |
| Текст | `--tr-text-body` | 14px | 400 | 1.5 | Default body copy, table cells |
| Текст · акцент | `--tr-text-body-strong` | 14px | 600 | 1.5 | Emphasized inline values ("Ноутбук Dell Latitude 5540") |
| Подпись | `--tr-text-label` | 13px | 500 | 1.4 | Field labels |
| Мелкий | `--tr-text-caption` | 12px | 500 | 1.35 | Meta text, timestamps |
| Микро | `--tr-text-micro` | 11px | 500 | 1.3 | Uppercase stat labels ("ВСЕГО 342") |
| Моноширинный | `--tr-text-mono` + `--tr-font-mono` | 13px | 500 | tabular-nums | **Required by DS-03** for inventory №, serial №, act №. Apply `font: var(--tr-text-mono); font-variant-numeric: tabular-nums;` — font stack: `ui-monospace,'SF Mono','Segoe UI Mono',Menlo,Consolas,monospace` |

## Spacing Scale (BY VALUE — hard no-shift constraint, DS-04)

11 levels (old system had 7; new adds 4 finer/coarser steps). **Migrate every existing call site to the
value-matched new name — never rename by matching old-name-to-new-name-of-similar-spelling.**

| Old token | Value | → New token (value-matched) | Same name? |
|-----------|-------|------------------------------|------------|
| `--space-xs` | 4px | `--tr-space-2xs` | **no** — old "xs" ≠ new "xs" |
| `--space-sm` | 8px | `--tr-space-xs` | **no** |
| `--space-md` | 16px | `--tr-space-md` | yes ✓ |
| `--space-lg` | 24px | `--tr-space-xl` | **no** |
| `--space-xl` | 32px | `--tr-space-2xl` | **no** |
| `--space-2xl` | 48px | `--tr-space-4xl` | **no** |
| `--space-3xl` | 64px | `--tr-space-5xl` | **no** |

New-only additions (no old equivalent, purely additive — no migration needed, available for finer control): `--tr-space-3xs` (2px), `--tr-space-sm` (12px), `--tr-space-lg` (20px), `--tr-space-3xl` (40px).

**The trap, spelled out:** if the executor naively keeps the old name `--space-xs` but silently redefines its
value from 4px to whatever a same-named new token would be, every one of that name's ~N call sites shifts
layout with zero build error. The correct move is: retire the 7 old names entirely, and mechanically replace
each of their 642 call sites with the value-matched `--tr-space-*` name from the table above.

## Motion Decision (resolves the open question flagged in REQUIREMENTS.md)

§Motion") stays scoped to **theme-switch color/background transitions only** — this is what DS-02 requires
