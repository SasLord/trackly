Правило 1 (old-name gate), из `23-RESEARCH.md` §Pattern 1:
Регулярное выражение `OLD_FAMILY_RE = /--(?:color|space|radius|font-size|font-weight|line-height|shadow)-[a-z0-9-]+/gi`
применяется к содержимому КАЖДОГО файла целиком (не только `<style>`-блокам) в `ui/src` —
подтверждено research: layout-константы (`--sidebar-width` и т.д.) НЕ пересекаются ни с одним из
шести префиксов, отдельный exclude-список не нужен.

Правило 2 (hex-in-style gate), из `23-RESEARCH.md` §Pattern 1:
`STYLE_BLOCK_RE = /<style[^>]*>([\s\S]*?)<\/style>/g`, применяется только к `.svelte`-файлам.
Внутри найденных блоков — `HEX_RE = /#[0-9a-fA-F]{3,4}\b|#[0-9a-fA-F]{6}\b|#[0-9a-fA-F]{8}\b/g`
(3/4/6/8-значные hex — валидные CSS-длины, не `{3,8}` — устраняет теоретические 5/7-значные
"хвосты" совпадений).

Правило 3 (closed-world existence gate), из `23-RESEARCH.md` §Pattern 1:
`DEFINE_RE = /(--tr-[a-z0-9-]+)\s*:/gi` применяется к содержимому `ui/src/styles/_tokens.scss`
(извлекает множество РЕАЛЬНО ОПРЕДЕЛЁННЫХ имён). `USE_RE = /var\((--tr-[a-z0-9-]+)/gi` применяется
ко всем `.svelte`/`.scss`-файлам в `ui/src` (извлекает множество ИСПОЛЬЗУЕМЫХ имён). Нарушение —
любое использованное имя, отсутствующее в определённом множестве.

Value-map верификатор (D-08), из `23-RESEARCH.md` §Pattern 2 — принимает `<base-ref>` как
единственный CLI-аргумент, вызывает `git diff --unified=0 <base-ref> -- '*.svelte' '*.scss'`
(исключая `ui/src/styles/_tokens.scss` — файл легитимно вводит новые значения, не rename, sweep
по нему бессмысленен), разбивает вывод по `@@`-хункам (`diffText.split(/^@@/m).slice(1)`), внутри
каждого хунка собирает удалённые токены (`/^-.*?(--(?:space|radius)-[a-z0-9]+)/gm`) и добавленные
(`/^\+.*?(--tr-(?:space|radius)-[a-z0-9]+)/gm`), сравнивает count и попарно проверяет соответствие
карте (см. Task 2 ниже). `RADIUS_EXCEPTION_FILES` — путь файла как параметр функции ожидания цели
(`Button.svelte`/`Input.svelte`/`Select.svelte`/`Textarea.svelte` → `--tr-radius-sm`; всё
остальное → `--tr-radius-xs`).

Конвенция логирования (из `tools/procmon-check/src/main.rs`, единственный house-style пример в
репозитории, Rust — переносить только конвенцию поведения, не синтаксис): префикс
`[имя-скрипта] сообщение` в stderr для прогресса/ошибок, финальная строка `PASS — …` при успехе,
ненулевой `process.exit(1)` + `console.error` при провале.
