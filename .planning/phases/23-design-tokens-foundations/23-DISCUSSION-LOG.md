## Промежуточный вид

### Приемлемость «полуготового» состояния

| Option | Description | Selected |
|--------|-------------|----------|
| Да, принимаем как есть | Новые значения сразу; каждая следующая фаза строит компоненты на реальных цветах. Релиз в середине v1.2 не планируется | ✓ |
| Новые значения за флагом | Имена мигрируем, значения включаем позже — но тогда DS-01/DS-02 в фазе 23 нечем проверить | |
| Затянуть в фазу 23 минимум из 24-й | Подправить то, что сильнее всего разъедется; риск размытия границ фазы | |

**User's choice:** Да, принимаем как есть
**Notes:** Находка разведки: поверхности инвертируются — `--color-bg` #ffffff → `--tr-bg` #eef1f6, `--color-surface` #f5f6f8 → `--tr-surface` #ffffff. Было «белый холст / серые панели», станет «серый холст / белые панели». В UI-SPEC это явно не проговорено (там только «`--color-bg` value changes, intentional»).

### Как обходиться с инверсией

| Option | Description | Selected |
|--------|-------------|----------|
| Строго по карте UI-SPEC, разбор на UAT | `--color-surface` → `--tr-surface` везде; пропавший контраст чинится точечно через `--tr-border`/`--tr-elev-1`/`--tr-surface-sunken` | ✓ |
| Исполнитель триажит каждый surface-call-site | «Панель на холсте?» → surface, «подложка внутри панели?» → sunken. Точнее, но это дизайн-решения внутри токенной фазы | |

**User's choice:** Строго по карте UI-SPEC, разбор на UAT

## Моношрифт и типографика

### Способ применения моношрифта

| Option | Description | Selected |
|--------|-------------|----------|
| Глобальный класс `.tr-mono` | Одно определение в `global.scss`, в компонентах `class="tr-mono"`. Грепается, охват легко аудитить. Новый паттерн — глобальных классов сейчас только `.skip-link` | ✓ |
| Локальный стиль в каждом компоненте | Консистентно со scoped-стилями проекта, но дублирование и труднее проверить охват | |
| Компонент `<Mono>` | Самый явный, но новый примитив = территория фазы 24 | |

**User's choice:** Глобальный класс `.tr-mono`

### Охват моношрифта

| Option | Description | Selected |
|--------|-------------|----------|
| Списки + карточки/детали | Везде, где идентификатор — это данные: строки таблиц, детали акта/устройства, выпадайки автокомплитов. НЕ в полях ввода, НЕ в печатных шаблонах | ✓ |
| Только таблицы и детали | Минимальный охват; автокомплиты — по мере редизайна в 25-28 | |
| Везде, включая поля ввода | Инв./серийный № моноширинные и при вводе | |

**User's choice:** Списки + карточки/детали

### Миграция 344 call-site типографики

| Option | Description | Selected |
|--------|-------------|----------|
| Декомпозированные оси, shorthand есть но не обязателен | Обе формы в `_tokens.scss` (как в UI-SPEC); миграция 1:1 по осям, без переписывания блоков; shorthand доступен для нового кода в 24+ | ✓ |
| Переписать всё на shorthand `font:` | Чище и гарантирует «один из 9 уровней», но `font:` сбрасывает font-family/variant — риск побочки в 344 местах | |
| Только shorthand в `_tokens.scss` | Осей не заводить — вынуждает полный переписыв | |

**User's choice:** Декомпозированные оси, shorthand не обязателен
**Notes:** Отложенный риск лучше немедленного — в фазе, где единственный автоматический гейт это грепы.
