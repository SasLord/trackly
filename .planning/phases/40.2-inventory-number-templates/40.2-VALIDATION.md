# Phase 40.2 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust: `cargo test`; UI: `svelte-check` + `eslint` + `prettier --check` + `node scripts/check-*.mjs` via `pnpm --dir ui lint` |
| **Config file** | `crates/*/Cargo.toml`; `ui/package.json` (`lint` script) |
| **Quick run command** | `cargo test -p <crate> <module>` (одна cargo-сессия за раз, память `cargo_no_concurrent_test`) / `pnpm --dir ui lint` |
| **Full suite command** | `TRACKLY_AD_MOCK=1 TRACKLY_SNMP_MOCK=1 cargo test --workspace -- --skip login_remember_persistent_cookie` + `pnpm --dir ui build && pnpm --dir ui lint` |
| **Estimated runtime** | ~300 seconds |

---

## Sampling Rate

- **After every task commit:** targeted `cargo test -p <crate> <module>` for touched files, or `pnpm --dir ui lint` for UI tasks
- **After every plan wave:** full suite command
- **Before `/gsd-verify-work`:** Full suite must be green + manual UAT items below
- **Max feedback latency:** 300 seconds
