    `border: none`, `color: var(--tr-text-primary)`, `border-radius: var(--tr-radius-sm)`,
    `display:flex; align-items:center; justify-content:center`, `&:hover { background:
    var(--tr-surface-sunken); }`, `&:focus-visible { outline:none; box-shadow: 0 0 0 3px
    var(--tr-focus-ring); border-color: var(--tr-accent); }`, `&:disabled { opacity: 0.45;
    cursor:not-allowed; }`) — этот класс становится единственным источником стиля «GHOST,
    квадратная, только иконка, 36×36» (UI-SPEC §10, вариант б: совпадение гарантировано
    конструкцией). Применить его В `Button.svelte`'s `.btn-icon-only` (Task 1) через композицию
    классов (`class="btn btn-{variant} btn-{size} tr-btn-ghost-icon"` только когда
    `variant==='ghost' && iconOnly` — не менять поведение других вариантов).

    В `ActionMenu.svelte` расширить `variant` union до `'default' | 'ghost-sm' | 'ghost-md'`.
    Добавить пропсы: `icon?: Snippet` (рендерится вместо трёх точек, когда передан), `panelMinWidth
    ?: string`, `portal?: boolean = false`. Триггер при `variant==='ghost-md'` получает класс
    `action-menu-trigger--ghost-md tr-btn-ghost-icon` (тот же общий класс из `global.scss`, НЕ
    дублировать стили внутри `ActionMenu.svelte`). Панель при `portal=true`: обернуть
    `use:portal` (импортировать ту же директиву, что `Dropdown.svelte` использует — читать её
    реализацию/путь импорта в `Dropdown.svelte` перед использованием), переключить
    `.action-menu-panel` на `position: fixed` вместо `position: absolute` и вычислить координаты
    так, чтобы правый край панели совпадал с правым краем кнопки-триггера (UI-SPEC §3:
    «Правый край панели выровнен по правому краю кнопки, отступ 4px вниз; если снизу меньше
    места, чем высота панели, — открывается вверх»). При `panelMinWidth` — inline
    `style:min-width={panelMinWidth}` на `.action-menu-panel`. Пункт с `aria-disabled="true"`
    внутри `children` (переполненный шаблон, реализуется в плане 12) не должен закрывать меню по
    клику — существующий `onclick={() => close(true)}` на `.action-menu-panel` закрывает ЛЮБОЙ
    клик внутри панели; задокументировать в JSDoc-комментарии компонента, что элементы,
    которые не должны закрывать меню, обязаны вызывать `event.stopPropagation()` в своём
    обработчике клика — ответственность потребителя (план 12), не переделывать сам ActionMenu.

    В `ButtonsSection.svelte` (витрина) добавить новую строку «Ghost — только иконка»: рядом
    `Button variant="ghost" size="md" iconOnly ariaLabel="Вставить номер по шаблону"
    title="Вставить номер по шаблону"` с `IconInsertTemplate` внутри, и `ActionMenu
    variant="ghost-md"` с тем же `icon` (пустое меню-заглушка допустимо для витрины) — обычная и
    `disabled` версии обеих. Это и есть постоянная регрессионная проверка UI-SPEC §10 (открывать
    в приложении, светлая/тёмная тема, hover/focus-visible/disabled — визуально идентичны, т.к.
    оба используют `.tr-btn-ghost-icon`).
