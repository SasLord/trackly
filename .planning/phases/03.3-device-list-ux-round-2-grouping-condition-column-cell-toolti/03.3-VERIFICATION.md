### Code Review Findings (из 03.3-REVIEW.md)

**CR-01 (Critical): location_distinct_count не реализован** — при group_by_condition=false группа с устройствами в разных локациях показывает произвольную локацию (MAX(location_id)) вместо «разное». Это предсуществующая проблема в логике, аналогичная той, что исправлена для condition. Код phase 03.3 не вводит этот баг — он был до фазы (DEF-2B не имел location_distinct_count). Однако фаза 03.3 не исправила его, хотя вводит аналогичный паттерн для condition. Отмечается как WARNING, не BLOCKER (задача 03.3 — закрыть именно 4 ITEM-а; CR-01 не входит в scope).

**WR-08 (Warning): condition_distinct_count игнорирует NULL** — устройство с `state=NULL` и другое со `state='Новое'` дадут `condition_distinct_count=1`, UI покажет 'Новое' вместо «разное». Корректность ITEM-1 частично нарушена для mixed NULL/value групп. Не blocker для 03.3 (UAT-сценарий использует «Новое» и «Б/У», оба ненулевые).

**Остальные WR-01..WR-07, IN-01..IN-05:** Предсуществующие или вне scope 03.3. Не влияют на закрытие ITEM-1..4.
