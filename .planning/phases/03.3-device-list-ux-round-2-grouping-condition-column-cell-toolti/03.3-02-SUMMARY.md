## Decisions Made

- `showStatus = statusFilter === null` вычисляется в DevicesPage и передаётся вниз prop chain — нет дублирования логики в дочерних компонентах
- `conditionDisplay` через `condition_distinct_count > 1` на клиенте — не требует изменения API или бэкенда
- `allItems $derived` объединяет обе секции для единообразной клавиатурной навигации (activeIndex охватывает обе секции)
- HTTP handler делегирует в `build_locations_autocomplete` из `tauri_cmds` — единая business-логика, нет дублирования
