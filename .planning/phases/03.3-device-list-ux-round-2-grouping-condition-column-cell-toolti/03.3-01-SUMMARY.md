# Phase 03.3 Plan 1: Флаг group_by_condition и condition_distinct_count — SUMMARY

Реализован флаг `group_by_condition: bool` в `DeviceFilter` (domain + DTO) и поле `condition_distinct_count: i64` в `DeviceGroupRow` / `DeviceGroup` DTO; SQL `list_grouped` разделён на две статические ветки (`sql_with_condition` / `sql_without_condition`); 18 тестов зелёные; TypeScript-биндинги обновлены.

## What Was Built

- **DeviceFilter.group_by_condition: bool** — добавлено в domain (`trackly-core`) и DTO (`trackly-app`). Default = `false` — правильное поведение для страницы Устройств.
- **DeviceGroupRow.condition_distinct_count: i64** — добавлено в domain, DTO `DeviceGroup`, SQL SELECT и маппинг строк.
- **Две SQL-ветки в `list_grouped`**:
  - `sql_with_condition`: GROUP BY `(type_id, name, condition)` — сохраняет DEF-2B (акт-форма)
  - `sql_without_condition`: GROUP BY `(type_id, name)` + `MAX(d.condition)` — схлопывает разные condition (страница Устройств)
  - Обе ветки содержат `COUNT(DISTINCT d.condition) AS condition_distinct_count`
- **Фронтенд**: DevicesPage передаёт `group_by_condition: false`; ActFormItemsTable передаёт `group_by_condition: true`
