## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser→axum | All requests cross HTTPS boundary; session cookie validates identity |
| Session cookie→identity | session.get::<Identity>("identity") is the only legitimate identity source for axum handlers |
| Tauri invoke→identity | desktop_identity() resolves trusted-admin identity; no network crossing |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-09 | Tampering | CSRF via cross-origin POST | mitigate | SameSite=Strict cookie (D-Session-02); additional Origin/Referer check on mutation endpoints in middleware |
| T-05-10 | Denial of Service | brute-force /login | mitigate | tower_governor rate limit: burst_size=5, per_second=10; >5 rapid requests → 429 (D-Auth-02) |
| T-05-11 | Info Disclosure | session identity bypass | mitigate | Identity extracted ONLY from session.get() — never from request body or query params |
| T-05-12 | Spoofing | fake login without password | mitigate | Tauri login calls ctx.auth.login() (argon2 verify); no bypass path |
| T-05-13 | Elevation of Privilege | accessing protected routes without session | mitigate | SessionManagerLayer returns 401 for missing/invalid session on all protected routes |
| T-05-14 | Info Disclosure | security headers missing | mitigate | SetResponseHeaderLayer applied globally in build_router(); verified by security_headers test |
| T-05-15 | Tampering | cert private key path traversal | mitigate | cert/key PEM files written only to ctx.paths.exe_dir() (portable path discipline per CLAUDE.md) |
| T-05-SC | Tampering | cargo installs (tower_governor, tower-sessions) | mitigate | slopcheck [ASSUMED] for tower_governor per RESEARCH audit; no blocking checkpoint as disposition = Approved |
