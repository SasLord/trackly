## Десктоп-доступ и первый админ

### Bootstrap первого админа
| Option | Description | Selected |
|--------|-------------|----------|
| Без seed: десктоп = неявный admin | Никакого default-пользователя; десктоп всегда trusted-admin; админ создаёт юзеров вручную | |
| Auto-seed admin/admin | Дефолтный пользователь + форс-смена; риск забытого дефолт-пароля | |
| First-run мастер | Экран «создайте админа» при первом запуске | ✓ |

**User's choice:** First-run мастер
**Notes:** Создаёт реальную строку users с role='admin'; явный владелец, без висячего дефолт-пароля.

### Десктоп-лок (USR-04)
| Option | Description | Selected |
|--------|-------------|----------|
| Тот же экран логина, что и в вебе | argon2id-аутентификация; флаг в app_settings (БД); единый код логина | ✓ |
| Отдельный lock-экран (PIN/пароль) | Два разных пути аутентификации | |

**User's choice:** Тот же экран логина, что и в вебе
**Notes:** Флаг лока хранится в app_settings, не в config.toml.

### Роль trusted-десктопа без логина
| Option | Description | Selected |

**User's choice:** Всегда admin (полный доступ)

## Веб-сессия и безопасность

### Срок жизни сессии
| Option | Description | Selected |
|--------|-------------|----------|
| Sliding, 8 часов бездействия | Рабочий день, ночью сброс | |
| Fixed, 12 часов | Жёсткий срок | |
| Sliding, 30 дней | Долго не просит пароль | ✓ |

**User's choice:** Sliding, 30 дней

### CSRF-защита (SRV-02)
| Option | Description | Selected |
|--------|-------------|----------|
| SameSite=Strict + проверка Origin | Минимум частей для одно-origin SPA на LAN | ✓ |
| Double-submit CSRF token | Больше кода на фронте и бэке | |

**User's choice:** SameSite=Strict + проверка Origin

### Политика паролей (USR-01)
| Option | Description | Selected |
|--------|-------------|----------|
| Мин. 8 симв., сброс админом + смена своего | Без жёсткой сложности; ручной сброс; смена со старым | ✓ |
| Мин. 12 симв. + форс-смена при первом входе | Строже, больше трения | |
| Мин. 8 симв., без самостоятельной смены | Только админ управляет | |

**User's choice:** Мин. 8 симв., сброс админом + смена своего

### Rate-limiting на /login (SRV-02)
| Option | Description | Selected |
|--------|-------------|----------|
| Да: брутфорс-защита по IP/логину | 5–10 попыток/мин, затем задержка/блок | ✓ |
| Отложить (только argon2id-задержка) | Меньше кода сейчас | |

**User's choice:** Да: брутфорс-защита по IP/логину
