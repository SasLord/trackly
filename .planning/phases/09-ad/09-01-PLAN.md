## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| login string → LDAP filter | untrusted user input interpolated into an LDAP search filter |
| AD password → bind | secret crosses the process; must never persist/log |
| dev macOS → no DC | RealAdClient must fail closed (Unreachable), mock substitutes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Spoofing/Elevation | RealAdClient/MockAdClient empty-password bind | mitigate | Reject empty/whitespace password -> BadCreds BEFORE any simple_bind (Pitfall 1, RFC 4513 §5.1.2); unit test in both impls |
| T-09-02 | Tampering | RealAdClient LDAP filter build | mitigate | `ldap3::ldap_escape(login)` per RFC 4515 before filter interpolation (Pitfall 5); grep gate + behavior |
| T-09-03 | Information Disclosure | AD password in Secret<String> | mitigate | `&Secret<String>` through trait; `.expose()` only at simple_bind call site; no Debug/Serialize (secret.rs); never persisted |
| T-09-04 | Information Disclosure | MockAdClient not-found vs wrong-password | mitigate | Both return BadCreds (generic) — no user enumeration via the port |
| T-09-05 | Info Disclosure | LDAPS cert verification | mitigate | LDAPS default + verify via OS trust store (tls-rustls-ring + rustls-native-certs); `no_tls_verify` off by default, opt-in only (Pitfall 3) |
| T-09-SC | Tampering | ldap3/hickory installs | mitigate | Task 0 blocking-human legitimacy checkpoint (both [ASSUMED]) before cargo add |
</threat_model>
