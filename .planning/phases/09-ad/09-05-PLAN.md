<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| login UI → server | UI must not reveal account state; all decisions server-side |
| settings UI → server | privileged AD config edited by admin only (server-enforced) |
| ad_register rows → non-admin UI | must not render for non-admins |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-20 | Information Disclosure | login error copy | mitigate | Single generic «Неверный логин или пароль» for all credential/account failures; distinct message ONLY for Unreachable (not account state) — UI-SPEC Copywriting Contract |
| T-09-21 | Info Disclosure | ad_register visible to non-admin in UI | mitigate | Admin-only filter at list level in UI AND server (REQ-06); defense-in-depth (server is authoritative) |
| T-09-22 | Elevation | role select on approve | mitigate | Default «Сотрудник»; server re-validates via authorize(ManageUsers) — UI cannot bypass (USR-06) |
| T-09-23 | Spoofing | reserved SSO button | mitigate | No click handler, visibly disabled, no fabricated display name (D-UX-03) |
</threat_model>
