<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → AuthService::login | untrusted credentials; single shared decision point |
| local-fail → AD bind | empty-password trap must be closed before the network call |
| post-bind → users table | must distinguish blocked/deleted from unknown (no accidental re-admit) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-06 | Spoofing/Elevation | login() empty-password AD fallback | mitigate | Reject empty/whitespace before bind in service layer (Pitfall 1); test empty_password_rejected proves AdClient not reached |
| T-09-07 | Information Disclosure | enumeration via timing/error | mitigate | Preserve dummy-hash constant-time local path; generic Unauthorized for BadCreds + unknown-local (reuse CR-05 path) |
| T-09-08 | Info Disclosure | AD password in login() | mitigate | Secret::new wrap; .expose only inside AdClient; never logged/persisted (password_hash stays NULL) |
| T-09-09 | Elevation | blocked/deleted user re-admit after bind | mitigate | find_user_any_state distinguishes blocked/deleted → typed non-session outcome (no silent re-admit); active-only get_by_login for the happy path |
</threat_model>
