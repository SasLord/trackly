<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| self-registration → users table | a bound-but-unknown AD user must not self-elevate |
| ad_register list → non-admin | registration requests must not leak to non-admins |
| approve → role assignment | role elevation is an admin-only privileged action |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-10 | Elevation | auto-register role | mitigate | Auto-register hard-codes role='employee'; any other role requires admin approve (Security V4) |
| T-09-11 | Info Disclosure | ad_register visible to non-admin | mitigate | Admin-only filter at query level (REQ-06); test ad_register_admin_only proves non-admin list excludes them |
| T-09-12 | Elevation | approve sets arbitrary role | mitigate | approve gated by authorize(ManageUsers); role validated via Role::from_str; default employee |
| T-09-13 | Tampering | writes outside single-writer | mitigate | All user create/activate/soft-delete + request mutations through WriterHandle::execute (CLAUDE.md invariant); grep gate |
| T-09-14 | Repudiation | unattributed AD admin actions | mitigate | audit_log entries for every create/activate/soft-delete/approve/reject |
</threat_model>
