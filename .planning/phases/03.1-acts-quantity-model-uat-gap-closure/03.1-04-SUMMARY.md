# Plan 03.1-04: DatePicker + Qty Bound + W-5 Summary

**G-2 (DatePicker UX для всех date-полей в ActFormBody + новое «Когда отдали» persisted в backend) + G-3 (qty browser-enforced bound через native max attr + W-5 serial defensive guard) — все три закрыты на code+test level.**

## Performance

- **Duration:** ~50 минут
- **Tasks:** 4 (Tasks 1-3 implemented; Task 4 manual UAT deferred)
- **Files modified:** 18 (включая 10 test files через batch sed)

## Accomplishments

- **G-2 (DatePicker):** `ui/src/lib/components/DatePicker.svelte` — thin wrapper над native `<input type="date" lang="ru">`. ActFormBody теперь использует DatePicker для «Сроком до» (deadline) и нового поля «Когда отдали» (required, default = todayISO()). Submit payload содержит `handover_date_utc: isoToUnix(handoverDateISO)`.
- **G-2 backend:** ActCreateDto.handover_date_utc (Option<i64>, serde default), ActRow.handover_date_utc (i64), V015 column persistence через insert_act_in_tx. ActService::create использует `payload.handover_date_utc.unwrap_or(now())` для backward-compat.
- **G-3 (qty bound):** ActFormItemsTable использует native `<input type="number" min="1" max="1000">` для browser-level enforcement; backend MAX_CLONE_QTY (план 01 T-03.1-02) обеспечивает defence-in-depth.
- **W-5 (defensive UX):** Если selected device.serial_no !== null → max=1, qty clamp к 1, tooltip «У устройства есть серийный номер; для нескольких единиц используйте отдельные позиции», visible warning hint «Сер. номер — qty фикс. 1» под input.
- **Test maintenance:** ActCreateDto получил Default derive для упрощения будущих field additions; 10 test files updated batch-sed (`handover_date_utc: None,` injected после `deadline_utc:` lines).
