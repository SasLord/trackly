<objective>
Закрыть G-6 (ReturnModal per-row override UX) и G-10 (показывать только outstanding devices к возврату). Переписать ReturnModal/ReturnItemsTable под G-12 DTO model (device_ids array вместо quantity). Интегрировать default-swap для PersonAutocomplete (giver/receiver from parent handover).

Purpose:
- G-6 (severity:major): inconsistency — при apply_to_all=false condition блокировался, а location нет. Симметрия — оба разблокированы.
- G-10 (severity:blocker): ReturnModal предлагал вернуть уже-возвращённые позиции; нужен «outstanding only».

Depends on:
- **03.1-01** — ActItemDto.outstanding_device_ids; ActReturnItemDto.device_ids; backend rejects не-outstanding device_id.

- ReturnItemsTable полностью переписана: render по device_id, не по act_item (один act_item с outstanding_device_ids=[10,11] → 2 строки).
- ReturnModal: default-swap для PersonAutocomplete, validate-before-submit, выкл bulk-controls когда apply_to_all=false.
- Updated `acts.ts` payload mapping (device_ids array).

      const itemsMap = new Map<number, ReturnRowState[]>();

        if (!itemsMap.has(r.act_item_id)) itemsMap.set(r.act_item_id, []);
        itemsMap.get(r.act_item_id)!.push(r);
      }
      const items = [...itemsMap.entries()].map(([act_item_id, rows]) => ({
        act_item_id,
        device_ids: rows.map(r => r.device_id),
        condition_override: rows[0].conditionOverride,  // если различаются — split на multiple items
