## Accomplishments

- **G-10 (outstanding-only):** `ReturnModal` flatten'ит rows из `act.items.flatMap(it => it.outstanding_device_ids.map(...))`. Если act_item имеет outstanding_device_ids=[10,11,12] — 3 rows; если =[] — никаких rows; если все items пусты — empty-state «Все позиции уже возвращены».
- **G-6 (symmetric apply_to_all):** `ReturnItemsTable` теперь применяет **одинаковую** `disabled = !checked || applyToAll` формулу к condition И location inputs. Раньше location был только `!checked` (asymmetric — UAT major bug, на котором был user-reported repro).
- **G-12 (DTO contract):** Submit payload содержит `device_ids: number[]` per item (W-4 ниже определяет как именно).
- **PersonAutocomplete swap (G-6 secondary):** На mount ReturnModal заполняет `giverName = parent.receiver_name`, `receiverName = parent.giver_name` (тот кто принимал в handover — становится giver на return).
- **W-4 PER-ROW SPLIT INVARIANT:** `buildReturnItems(rows, applyToAll)` использует composite-key grouping по `(act_item_id, condition_override, location_name_override)`:
  - **Identical overrides** между rows одного act_item_id → coalesce в один `ActReturnItemDto` с device_ids array.
  - **Distinct overrides** → SEPARATE ActReturnItemDto entries (one per distinct triple). **NEVER** "first row wins".
  - Order-preserving (через `groupOrder[]`) — стабильный output для отладки.
  - applyToAll=true: groups только по act_item_id, overrides=null (backend uses bulk).
- **canSubmit validation:**
  - `applyToAll=true`: требует `bulk_condition.trim() !== ''`.
  - `applyToAll=false`: каждая checked-row должна иметь condition + location.
- **Inline error hints:** показывают что именно нужно заполнить если canSubmit=false.

## ReturnRowState Final Shape

```ts
export interface ReturnRowState {
  actItemId: number;       // Backend act_item.id (parent act_item) — для grouping
  deviceId: number;        // Один device_id per row (G-12: 1 act_item ↔ 1 device_id)
  deviceLabel: string;     // UI display: "{name} (инв. {inv_no})" или "{name} #{deviceId}"
  checked: boolean;        // Default true; user снимает чтобы не возвращать
  conditionOverride: string | null;
  locationOverrideName: string;
}
```

`quantity` field удалён — derived через `device_ids.length` на submit (один device = qty 1).
