## Known Constraints

1. **Char-approximation для PDF text measure** (avg_glyph_w = 0.5 * font_size): неточно для variable-width шрифтов; для DejaVu Sans (~0.5 en-em ratio) достаточно good. Если real-world UAT покажет overflow всё ещё происходящим — открыть follow-up issue для real font measure через rustybuzz.
2. **tauri-plugin-shell::open scope ограничен по URL pattern**, не по file pattern (Tauri v2 capability spec). Mitigation: temp PDF файлы создаются исключительно trusted backend pipeline'ом (`PdfPreviewModal.handleOpen` writes via plugin-fs to `BaseDirectory.Temp` с детерминированным prefix `trackly-preview-{timestamp}.pdf`); user не может задать произвольный path для open. T-03.1-05-02 noted.
3. **Windows VM verification** для печати на Edge / Adobe Reader — отложено; macOS smoke через Preview.app проверит open/save flow.
4. **PDF determinism (B-3)** preserved — `truncate_to_width` имеет byte-identity early return для fixture rows; logo path-null в fixture не задействует scale_logo_dimensions.
