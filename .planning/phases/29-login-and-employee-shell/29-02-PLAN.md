AuthShell.svelte (29-01 Task 2):
```typescript
interface Props {
  maxWidth?: number;  // default 360
  stack?: boolean;    // default false — true renders flex-column + gap (BlockedScreen-style)
  children?: Snippet;
}
```
Usage: `<AuthShell>{title/form as children, no title prop}</AuthShell>`. LoginPage does NOT need
`stack` (its form already provides its own internal gap via `.login-form`). FirstRunWizard passes
`maxWidth={400}` to preserve its existing wider card exactly as today.

FormField.svelte (29-01 Task 3):
```typescript
interface Props {
  label: string;
  id: string;
  error?: string | null;
  hint?: string;
  children: Snippet<[{ describedBy: string | undefined; invalid: boolean }]>;
}
```
Usage pattern (Svelte 5 snippet-with-params):
```svelte
<FormField label="Логин" id="login-input" error={loginError} hint="Логин: us100, user@domain или DOMAIN\User">
  {#snippet children({ describedBy, invalid })}
    <Input id="login-input" type="text" bind:value={login} disabled={loading} {invalid} aria-describedby={describedBy} autocomplete="username" />
  {/snippet}
</FormField>
```
Note: `hint` is only shown when `error` is falsy (FormField's own `{:else if hint}` branch) — do not
conditionally pass `hint` from the call site, always pass it and let FormField decide.

Input.svelte (29-01 Task 1 — type union now includes 'password'):
```typescript
type?: 'text' | 'number' | 'search' | 'password';
```

Button.svelte (unchanged, existing primitive):
```typescript
interface Props {
  variant?: 'primary' | 'secondary' | 'destructive' | 'ghost' | 'link';
  size?: 'sm' | 'md';
  loading?: boolean;
  disabled?: boolean;
  type?: 'button' | 'submit';
  onclick?: () => void;
  children?: Snippet;
}
```
`disabled` (via `isDisabled = disabled || loading`) sets the native `disabled` attribute AND
`pointer-events:none` — this already removes the element from tab order per HTML semantics, so a
reserved-SSO `<Button disabled>` needs no explicit `tabindex="-1"` to reproduce the current
"unclickable, unfocusable" contract (D-UX-03).

Checkbox.svelte (unchanged, existing primitive):
```typescript
interface Props {
  checked?: boolean;   // $bindable
  disabled?: boolean;
  invalid?: boolean;
  id?: string;
  onchange?: (_checked: boolean) => void;
  children?: Snippet;  // label content, rendered after the box
}
```
Usage: `<Checkbox bind:checked={remember} disabled={loading}>Запомнить меня</Checkbox>`.
