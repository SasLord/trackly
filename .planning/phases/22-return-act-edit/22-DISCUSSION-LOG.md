## Дата возврата

| Option | Description | Selected |
|--------|-------------|----------|
| Добавить «Дату возврата» | Новое поле — фактическая дата возврата, у return своя дата | ✓ |
| Править унаследованную дату | Менять handover_date_utc возврата (сейчас = дата родителя) | |
| Даты нет в scope | Только состав/состояние/расположение | |

**User's choice:** Добавить «Дату возврата».
**Notes (прямая цитата):** «Новое поле, редактируемое с попапом выбора даты из
календаря, по умолчанию — сегодняшнее число. Дата создания акта тут не при чём —
надо, чтобы можно было указать, когда реально вернули устройство по этому
возврату. Список Возвратов сортируется именно по указанной дате возврата, а не по
дате создания акта. Дата архивации акта формируется от указанной даты возврата при
полном/последнем возврате акта.» → D-03..D-08.

## Дата: отображение + миграция (follow-up)

| Option | Description | Selected |
|--------|-------------|----------|
| Own date; старым = created_at | Отображать/сортировать по return_date; backfill старых = created_at_utc | ✓ (по смыслу) |
| Own date; старым = handover_date | Backfill старых = унаследованная дата родителя | |
| Новое поле — только в форме | Отображение остаётся handover_date | |

**User's choice:** Новое отдельное поле «Дата возврата» с date-picker, default =
сегодня; отображение и сортировка возвратов — по нему; дата архивации родителя — от
даты возврата последнего/полного возврата. Backfill исторических возвратов принят
= `created_at_utc` (лучший доступный сигнал «когда вернули»). → D-05, D-06, D-07, D-08.
