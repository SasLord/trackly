## Что есть «дата акта» (ACT-01)

| Option | Description | Selected |
|--------|-------------|----------|
| handover_date везде | «Дата» = handover_date_utc в списке, карточке, PDF/печати и сортировке; created_at внутренний | ✓ |
| Только отображение+печать | handover_date как «Дата» в UI/PDF, но сортировка/группировка списка по created_at | |

**User's choice:** handover_date везде
**Notes:** Отчёты уже фильтруют/группируют по handover_date_utc — консистентно. Backend уже сохраняет handover_date_utc корректно; правка на стороне отображения/сортировки/рендера.

## Объём редактирования (ACT-02)

| Option | Description | Selected |
|--------|-------------|----------|
| Только шапка | №, даты, Сдал/Принял, сроки, комплектация; позиции не трогаются | |

## Побочные эффекты на технику (ACT-02)

| Option | Description | Selected |
|--------|-------------|----------|
| Согласовывать дельту | Сравнить старый/новый списки позиций, откат убранных, перевод добавленных, история на каждое | |
| Шапка свободно, позиции с эффектами | Шапка меняется без затрагивания техники; изменение позиций пересобирает эффекты по дельте | ✓ |
| Пересоздание (delete+create) | Откатить старый акт и создать заново — переиспользует пути, но меняет №/id | |

**User's choice:** Шапка свободно, позиции с эффектами
**Notes:** Прагматично — частый случай (правка шапки) дешёвый, редкий (правка позиций) через дельта-согласование.

## Какие акты редактируемы (ACT-02)

| Option | Description | Selected |
|--------|-------------|----------|
| Только handover, не архив/возврат | Только handover-акты без возврата и не архивные | |
| Все handover (вкл. с возвратом) | Любой handover-акт, даже с уже выполненным возвратом; требует валидации правки позиций против возвратов | ✓ |
| handover и return | Редактировать можно и return-акты — максимум гибкости, максимум риска | |

**User's choice:** Все handover (вкл. с возвратом)
**Notes:** Return-акты не редактируются (кнопка неактивна). Правка позиций у актов с возвратом — с валидацией против существующих возвратов; правка шапки свободна.
