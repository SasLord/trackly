<objective>
ACT-01: make the user-entered "Когда отдали" date (`handover_date_utc`) the act's displayed/sorted "Дата" everywhere in the app — list, detail card, PDF/HTML print, and sort order. `created_at_utc` becomes purely internal (D-02).

The backend already saves `handover_date_utc` correctly on create (D-03) — this plan fixes the READ side only: `ActDto` is currently missing the field entirely (Pitfall 1), two SQL `ORDER BY` clauses sort by `created_at_utc`, the PDF render context reads `created_at_utc`, and two Svelte components derive their displayed date from `created_at_utc`.

Purpose: closes ACT-01 (Requirements.md) end-to-end — the "always shows today's date" symptom the user reported.
Output: `ActDto.handover_date_utc` (wire field), corrected sort order in `list()`/`search_acts()`, corrected date fields in `render_pdf`'s act+parent blocks, corrected `ActListRow`/`ActDetail` displays, regenerated `ui/src/bindings.ts`, and a new regression test proving sort-order correctness.
</objective>
