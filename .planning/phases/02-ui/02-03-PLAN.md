Если affected == 0 → query actual version (`SELECT version FROM devices WHERE id=?1`), если NotFound → AppError::NotFound, иначе → AppError::OptimisticLockMismatch { entity: "device", id, expected, actual }. Если affected == 1 → возврат свежего get(id).
