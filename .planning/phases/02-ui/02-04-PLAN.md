| UI autocomplete field name → SQL column name | Untrusted enum-mapping — must whitelist |
| UI grouping query → GROUP BY clause | Filter args (status_id/type_id) — parameterized only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04-01 | Tampering | FTS5 query injection (user input `(AND OR)`, quotes) | mitigate | `build_fts_query` sanitizer: escape `"`, drop `\0`, quote each token, append `*` (RESEARCH §Pitfall 3). Result — data, not code. |
| T-02-04-02 | Tampering | Autocomplete `field` parameter SQL injection через column name | mitigate | `AutocompleteField` enum whitelisted (Name/Model/Specs/Kit/State/Location); `AutocompleteField::from_str(input)?` returns AppError::Validation если не из whitelist; column name берётся ТОЛЬКО из enum (PATTERNS §Example C). |
| T-02-04-03 | DoS | Unbounded autocomplete без prefix | mitigate | LIMIT 30 hardcoded в SQL; LIKE pattern `{prefix}%` — partial-index использует prefix даже когда prefix="". |
| T-02-04-04 | DoS | Rate-limit autocomplete endpoints | accept | Phase 2: no auth/server-mode yet; debounce 200ms на UI стороне снижает request frequency. Phase 5+ добавит rate-limit на axum для serve-mode. |
| T-02-04-05 | Information Disclosure | FTS rank/score leak | accept | rank используется только для ORDER BY (relevance); не serializ в response. |
