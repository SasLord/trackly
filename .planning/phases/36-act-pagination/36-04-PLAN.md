<objective>
Реализовать повторение <thead> appendix-таблицы на каждом печатном листе через кастомный Paged.js
Handler на хуке afterPageLayout, идентично зарегистрированный в обоих путях рендера
(bootstrapScript.js для превью/desktop и printViaTopLevel для LAN), с обязательным пересчётом
CSP sha256-константы и живой проверкой на обоих транспортах — единственный участок фазы с реальным
риском реализации (D-15a).

Purpose: bundled pagedjs 0.4.3 не клонирует <thead> при разрыве таблицы нативно (апстрим-PR #160
не влит) — без этого плана длинная appendix-таблица теряет заголовки колонок на втором и
последующих листах, что напрямую нарушает Критерий #3 фазы. Пользователь явно решил 2026-08-12
реализовать хендлер напрямую, без предварительного спайка.
Output: RepeatTableHeadHandler в bootstrapScript.js и в PdfPreviewModal.svelte::printViaTopLevel,
обновлённая CSP-константа, живое подтверждение на обоих транспортах.
</objective>

Форма хендлера (общая для обоих мест регистрации — RESEARCH.md Pitfall 1, подтверждено прямым
чтением ui/node_modules/pagedjs/src/chunker/chunker.js:99-113 и layout.js:520-650):

Класс extends window.PagedModule.Handler (UMD) / Handler из import('pagedjs') (ESM) — конструктор
принимает (chunker, polisher, caller), вызывает super(chunker, polisher, caller) и сохраняет
исходный thead каждой table.appendix-table (клонировать ДО пагинации, например в конструкторе через
document.querySelectorAll('table.appendix-table') -> table.querySelector('thead') ->
cloneNode(true), сложить в Map по table как ключу или по индексу таблицы на странице — в документе
ожидается не более одной table.appendix-table на акт, поэтому допустим и упрощённый вариант без
Map). Метод afterPageLayout(pageElement, page, breakToken, chunker) — сигнатура подтверждена в
chunker.js:111 — на каждом вызове: pageElement.querySelectorAll('table.appendix-table').forEach(
table => { if (table.querySelector('thead')) return; /* уже есть thead — первый фрагмент */
table.insertBefore(savedThead.cloneNode(true), table.firstChild); }). Регистрация — вызов
registerHandlers(RepeatTableHeadHandler) ПЕРЕД созданием Previewer (и в bootstrapScript.js, и в
printViaTopLevel) — оба симфола (Handler/registerHandlers) подтверждены присутствующими и в UMD
(window.PagedModule.Handler/registerHandlers, grep на paged.min.js), и в ESM
(ui/node_modules/pagedjs/src/index.js) сборках.

querySelectorAll должен быть скоуплен строго к 'table.appendix-table' — не трогать никакой другой
DOM на странице (T-36-03, threat_model ниже).
