## Требует ручной проверки

**Статус: UNVERIFIED (deferred to human UAT).** Живая проверка в `cargo tauri dev` не проводилась ни агентом, ни (задокументированно) человеком на момент закрытия этого плана. Требуется отдельный проход в рамках фазовой human UAT со следующими точными шагами воспроизведения:

1. Убедиться, что у организации активен шаблон номеров актов с нецифровой маской (например «[YYYY]/[MM]-[X]») — Настройки → Организация → Шаблоны номеров, тип «Акты» (или временно создать такой шаблон, если сейчас активен цифровой).
2. Выполнить `pnpm --dir ui build` (LAN/HTTP-режим показывает актуальную сборку — project memory `dev_browser_testing_needs_ui_build`), затем `cargo tauri dev`.
3. Оформить акт передачи с этим шаблоном (номер получится вида «2026/09-1»).
4. Оформить возврат по этому акту.
5. Проверить текст тоста после сохранения — номер должен быть **«№2026/09-1в»** (без дублирования вида «№2026/09-1/09-1в»).

Ожидаемый результат основан на статическом чтении кода (`ret.number` теперь используется напрямую, сервер уже отдаёт готовое отображаемое значение в `ActDto.number`), но фактически в приложении не пронаблюдён.
