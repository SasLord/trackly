# Phase 40.3 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust `cargo test` (trackly-core, trackly-infra, trackly-app); UI `pnpm --dir ui lint` (svelte-check + eslint + prettier + `scripts/check-*.mjs`) |
| **Config file** | `crates/*/Cargo.toml`; `ui/package.json` (`lint`) |
| **Quick run command** | `TRACKLY_AD_MOCK=1 TRACKLY_SNMP_MOCK=1 cargo test -p <crate> <module>` / `pnpm --dir ui lint` |
| **Full suite command** | `TRACKLY_AD_MOCK=1 TRACKLY_SNMP_MOCK=1 cargo test --workspace -- --skip login_remember_persistent_cookie` + `pnpm --dir ui build && pnpm --dir ui lint` |
| **Estimated runtime** | ~300 seconds (full), ~60 seconds (targeted) |

Одна `cargo test`-сессия за раз. При exit 69 на линковке — префикс `DEVELOPER_DIR=/Library/Developer/CommandLineTools`.

---

## Sampling Rate

- **After every task commit:** targeted `cargo test -p <crate> <module>` или `pnpm --dir ui lint`
- **After every plan wave:** full suite command
- **Before `/gsd-verify-work`:** Full suite must be green + живая проверка N-1/N-2 в `cargo tauri dev`
- **Max feedback latency:** 300 seconds
