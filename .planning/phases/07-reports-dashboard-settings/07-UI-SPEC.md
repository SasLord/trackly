## Layout Contracts

### Dashboard Layout (DASH-01..05, D-09, D-10)

**Route:** `/` (already the home route in `routes.ts` — no routing change needed)

**Grid:** Fixed 2-column responsive grid at 1280px+ breakpoint:
- Column 1 (left, wider): StatWidget «Устройства», StatWidget «Картриджи», ChartWidget «Динамика расхода»
- Column 2 (right, narrower): StatWidget «Заявки», StatWidget «Принтеры»
- Below 1280px: single-column stacked

**Widget card anatomy:**
```
┌─────────────────────────────────┐
│  Widget title (--font-size-body, │
│  --font-weight-semibold)         │
│                                  │
│  [28px stat number]              │
│  [13px sub-label]                │
│                                  │
│  [breakdown rows at 13px]        │
└─────────────────────────────────┘
```
Widget cards: `background: var(--color-surface); border: 1px solid var(--color-border); border-radius: var(--radius-md); padding: var(--space-lg);`

**Dashboard period selector (D-12):** Above the widget grid. Affects Заявки widget and others but NOT the chart (chart has its own 3/6/12 switcher). Render as a compact button group (same visual pattern as the report switch-bar tabs).

**DASH-02 — low stock alert:** Inside the «Картриджи» widget, below the stat number. Uses `--color-warning` tint block (same pattern as `LowStockBanner.svelte`), smaller — no `role="alert"` (it is not time-critical, already visible on load).

**DASH-03 — chart widget (D-11):** Line chart, 3/6/12 month toggle rendered as a button group above/inside the chart card. Chart library choice is at Claude's discretion — prefer a dependency already in `package.json` or a minimal SVG-drawn approach. **Recommended:** hand-drawn SVG path (no new npm dep) using a simple path generator from data points, or `Chart.js` via CDN-free import (already absent from package.json — avoid adding heavy deps). Simplest viable: inline SVG polyline/path rendered from computed data points. The chart does NOT need animation (reduced-motion is the established global rule).

**DASH-05 — «проблемные принтеры»:** Count badge uses `Badge variant="destructive"` for error/offline count. Toner warning badges use `Badge variant="warning"`.

### Reports Layout (RPT-01..08, D-01..D-08)

**Route:** `/reports`

**Two-level navigation (D-01):**
```
[Устройства] [Картриджи]          ← domain sub-nav (same visual as page tabs)
  [Акты] [Возвраты] [В работе] [На складе]  ← switch-bar for report type
```
Domain sub-nav: full-width row, same `tab` button style as `ActsSearchAndTabs.svelte` but without the `Badge` counter. Switch-bar for report type: same tab button style, with `Badge variant="default"` showing row count (loaded with report data).

**Toolbar row** (between switch-bar and table): period selector (hidden/disabled for snapshot reports per D-02) + filter chips + search input + export buttons (CSV, PDF) + print button. All on one row at 1280px+; wraps below.

**Period selector (RPT-03):** Three-option button group: «Месяц» | «Год» | «Диапазон». When «Месяц» is active: month/year picker (two `<select>` dropdowns: month name + year). When «Год»: year `<select>`. When «Диапазон»: two `DatePicker` fields. Default: «Месяц» = current month (D-03).

**Report table:** Standard HTML `<table>` with sticky column headers. Row height: `--row-height` (40px). Dense mode for month-separator rows: `--row-height-dense` (32px). Month-separator row: full-width `<tr>` with `colspan`, background `--color-surface-sunken`, text `--font-size-body` weight `--font-weight-semibold`, left-padded to `--space-md`. Example: «Сентябрь 2026» in Russian month name.

**Snapshot reports (D-02):** No month-separator rows. Grouped by location/status using the same separator row pattern but with location/status label instead of month name.

**Export buttons:** `Button variant="secondary" size="sm"` for CSV and PDF. Print button: `Button variant="ghost" size="sm"` with print icon SVG. These three live in the toolbar row, right-aligned.

### Settings Layout (SET-01..07, SET-09, D-15..D-21)

**Route:** `/settings`

**Existing SettingsPage.svelte** gets new sections added below `NetworkSettings`. The page uses a vertical stack of section cards (established pattern from `NetworkSettings.svelte`):
- `background: var(--color-surface); border: 1px solid var(--color-border); border-radius: var(--radius-md); padding: var(--space-lg);`
- `max-width: 640px` for all settings cards (established constraint)

**Settings sections order:**
1. Серверный режим (existing NetworkSettings)
2. Безопасность рабочего стола (existing)
3. Организация (SET-01, SET-02) — new
4. Хранилище данных (SET-03) — new
5. Бэкапы (SET-05, SET-06, SET-07) — new
6. Порог низкого остатка (SET-04) — new (compact, single-field card)
7. Шаблоны документов (SET-09) — new

**Logo upload (SET-02):** Inline upload within the «Организация» card. Display existing logo as `<img>` (max 128×64px display, object-fit contain). Upload button: `Button variant="secondary" size="sm"`. No separate modal — inline state swap.

**DB path display (SET-03):** Read-only path in a `<code>` element. Two buttons: «Открыть папку» (`Button variant="ghost" size="sm"`) and «Сменить расположение» (`Button variant="destructive" size="sm"`). The destructive button triggers a confirmation modal before proceeding.

**Manual backup (SET-06):** `Button variant="secondary"` with loading spinner. Shows last backup timestamp in `--font-size-label --color-text-muted` below the button after first backup.

**Auto-backup (SET-07):** Three fields within the Бэкапы card:
- Папка: read-only display + «Выбрать папку» button (tauri-plugin-dialog)
- Расписание: `<Select>` with options «Ежедневно» / «Еженедельно» / «Отключено»
- Ретенция: `<Input type="number" min="1" max="99">` with inline label «копий»

**Template editor (SET-09, D-20):** Full-width within its card (ignores max-width: 640px constraint — template textarea needs width). Structure:
- Template selector: `<Select>` with template names
- Variable panel: collapsible `<details>` element listing available MiniJinja variables at `--font-size-label`
- Textarea: `font-family: monospace; min-height: 320px; width: 100%`
- Footer row: «Проверить / Превью PDF» (`Button variant="secondary"`) + «Сохранить шаблон» (`Button variant="primary"`) + «Сбросить до умолчания» (`Button variant="destructive"`)

## Interaction Contracts

### Report Navigation (D-01)

- Domain sub-nav tabs are mutually exclusive (Устройства / Картриджи).
- Report type switch-bar is mutually exclusive within the active domain.
- Switching domain resets report type to the first tab of the new domain.
- Switching report type preserves the current period selection (if the new report supports it) or hides/disables the period selector (if the new report is a snapshot type per D-02).
- No URL-based state for sub-navigation — in-component state only.

### Period Selector (RPT-03, D-02, D-03)

- Default on mount: «Месяц» = current calendar month in org timezone (TZ from config).
- «Месяц» option: renders two `<select>` dropdowns — month name (январь…декабрь, Russian locale) + year (current year - 3 … current year). Selecting either triggers immediate report reload.
- «Год» option: single year `<select>`. Triggers reload on change.
- «Диапазон» option: two `DatePicker` fields (начало / конец). Report reloads on blur of each field if valid range (start ≤ end). Shows validation message «Начало не может быть позже окончания» inline if invalid.
- For snapshot reports (Что в работе, Что на складе): period selector is rendered but disabled with helper text «Отчёт отражает текущее состояние».

### Export / Print (RPT-07, RPT-08, D-06, D-07)

- Export scope: «что видно сейчас» — current filters + search + period (D-07).
- Export buttons enter loading state (spinner) during generation. On success: file download begins (browser) or save dialog appears (Tauri).
- Print: Tauri desktop path — generate PDF, open in system viewer (`tauri-plugin-shell`). Browser path — `window.print()` or PDF download.
- Print button is always enabled (no disabled state). Loading state during PDF generation.

### Dashboard Widget Refresh

- On page mount: load all widgets in parallel (independent API calls).
- Each widget shows `Spinner` independently while loading.
- Widgets do NOT auto-refresh (no polling in v1). Manual refresh via page reload (no explicit refresh button in Phase 7).
- Dashboard period selector triggers reload of period-sensitive widgets only. Chart reloads only when its own 3/6/12 toggle changes.

### Settings Sections (D-15..D-21)

- Each settings section is independent; saving one section does not reload or reset others.
- Org fields: auto-save is NOT used. User must press «Сохранить настройки организации» explicitly.
- Logo upload: file picker via `tauri-plugin-dialog` on desktop; `<input type="file">` on browser. Accepted formats: PNG, JPG, SVG (max 512 KB). Show error inline if over limit: «Файл слишком большой. Максимальный размер: 512 КБ.»
- Threshold field: `<input type="number" min="1" max="999">`. Saves on blur (no explicit save button needed — single field, low risk). Confirm with success toast «Порог обновлён».
- Auto-backup folder: if no path set, the schedule field is disabled with helper text «Выберите папку для активации автобэкапа».
- Template editor: the «Проверить» button is enabled only when textarea content differs from last-saved content OR the user has not yet saved (always enabled on fresh load). This avoids the confusion of previewing a stale version.

### Destructive Actions

- All destructive actions require confirmation via `Modal` (size="md") before proceeding.
- Confirmation modal follows established pattern from prior phases: title in `--font-size-heading` semibold, body in `--font-size-body` regular, footer buttons right-aligned per `Modal.svelte` footer pattern.
- After DB move confirmation: immediately disable all other settings interactions and show a full-card message «Приложение будет перезапущено…» while the operation runs.

## Accessibility

Inheriting all established patterns from Phase 2–6:

- Focus rings: `box-shadow: 0 0 0 3px var(--color-accent-focus)` on `:focus-visible` (global CSS already covers this)
- `prefers-reduced-motion`: no animations (global rule in `global.scss` already applied)
- Report table: `<table>` with `<thead>/<tbody>`, `scope="col"` on `<th>`, `scope="row"` where applicable
- Dashboard widgets: each card wrapped in `<section aria-labelledby="widget-title-{id}"`
- Chart (DASH-03): include `role="img" aria-label="График динамики расхода картриджей за {period}"` on the SVG element; include a visually-hidden data table as fallback
- Month-separator rows: `aria-hidden="true"` — they are presentational (screen reader reads the data rows without needing the separator)
- Period selector: each button group uses `role="group" aria-label="Выбор периода"`
- Modal confirmations: follow existing `Modal.svelte` pattern (`role="dialog" aria-modal="true" aria-labelledby`)
