    Helper fn compute_period_utc(dto: &PeriodDto, tz_offset: UtcOffset) -> (Option<i64>, Option<i64>):
    - mode="month": use time::Date::from_calendar_date(dto.year, Month::try_from(dto.month).unwrap(), 1).midnight().assume_offset(tz_offset).unix_timestamp() for start; compute end as last second of the month (day = days_in_month, time = 23:59:59). If API deviates from assumption, fall back to: start = beginning-of-month epoch - tz_offset_seconds; end = start + month_days*86400 - 1.
    - mode="year": start = Jan 1 00:00 in tz, end = Dec 31 23:59:59 in tz
    - mode="range": parse dto.date_from/date_to as ISO date strings, convert to UTC epoch using tz offset
    - snapshot reports: return (None, None) — no period filter

    Helper fn get_tz_offset(&self) -> UtcOffset: reads config.organization.timezone, returns fixed UTC+3 for "Europe/Moscow" (hardcoded match arm), falls back to UTC+0 for unknown values. Does NOT call chrono — uses time::UtcOffset::from_hms(3,0,0).unwrap().
