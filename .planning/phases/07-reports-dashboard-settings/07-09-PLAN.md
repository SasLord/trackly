<objective>
Fix three settings components where the frontend has incorrect DTO shape expectations
or broken Tauri environment detection.

GAP-S3: StorageSettings.svelte expects settings_get_db_path to return { path: string }
but the backend returns a plain String. Also uses wrong Tauri detection (__TAURI__ instead
of __TAURI_INTERNALS__).

GAP-S4: BackupSettings.svelte uses window.__TAURI__ for desktop detection, which is
Tauri 1 API and always undefined in Tauri 2. The correct check is __TAURI_INTERNALS__.

GAP-S5: ThresholdSettings.svelte expects settings_get_low_stock_threshold to return
{ threshold: number } but backend returns plain i64. Also number input needs styling
fix for spinner positioning.

Purpose: These are pure frontend fixes — no Rust changes. Each component reads a
primitive value from a Tauri command but wraps it in a destructuring call that fails
silently (leaves the field undefined/NaN).

Output: Three patched Svelte components; pnpm svelte-check clean.
</objective>
