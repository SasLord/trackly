|----------|-------------|
| Logo BLOB upload | Untrusted bytes cross at HTTP handler / Tauri command; validated in OrgDbService.save_logo |
| Backup destination path | User-provided string; UNC rejection + canonicalize in backup_service |
| MiniJinja template body | User-controlled string; rendered only server-side via render_with_timeout with fuel limit |
| scheduled_tasks payload_json | Written by server, not user; but should be parsed defensively |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
