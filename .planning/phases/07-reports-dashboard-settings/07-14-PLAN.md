<objective>
Close gap G2-5: (a) right-align the export/print button block in the controls-row of
ReportsPage; (b) show REAL per-status row counts on ALL report-type tabs simultaneously
(user decision 2026-06-17).

G2-5a root cause: .controls-row in ReportsPage.svelte has display:flex but no
justify-content, so PeriodSelector and the export-block (inside ReportFilters) both align
left. Fix: add justify-content:space-between + align-items:center.

G2-5b root cause: ReportSubNav receives only a single rowCount prop (the active tab's total).
Inactive tabs show "–" because there is no per-type count data for them. User decision
requires real counts on ALL tabs simultaneously. This requires a new backend query
reports_get_report_counts that runs lightweight COUNT-only queries for every report type in
the active domain and returns a map of { key → count }. ReportsPage fetches this map
whenever domain or period changes and passes it as a statusCounts prop to ReportSubNav.

Purpose: Complete the Reports page visual design and fulfill the user's badge decision.
Output: New Rust DTO + service method + Tauri command + specta_export registration +
regenerated bindings + ReportsPage + ReportSubNav updates.
</objective>
