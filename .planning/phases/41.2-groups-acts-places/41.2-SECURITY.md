| Boundary | Description | Data Crossing |
|----------|-------------|---------------|

| клиент → `places_contents` / `places_group_members` / `groups_act_expansion` / `devices_list` | `expand_groups` (обязателен), `group_id`, `group_members_only` | идентификаторы групп, режим выборки |
| writer-транзакция → `act_group_effects`, `group_devices`, `place_movements`, `audit_log` | единая точка записи; план групп, перенос, откат и следы в одной транзакции | целостность состава групп и истории перемещений |
| сервер → UI (попапы, тосты, таймлайн, печать акта) | имена групп, устройств, мест, тексты уведомлений, комплектация | XSS-поверхность |
| `localStorage` → `PlacesPage` | режим «Разворачивать группы» | булево отображения |
| рабочая копия → публичный репозиторий | тесты, фикстуры, `.planning/`-артефакты | реальные данные организации и ФИО (жёсткое условие проекта) |
| исполнитель → чекпоинт живой проверки / сплошной прогон | подтверждение поведения и зелёного набора | достоверность приёмки |

## Observations (не блокеры)

1. **A-WR-01 не исправлен — остаточный риск у T-41.2-13/-31.** `act_service.rs:494-501` строит вход
   планировщика как `once(item.device_id).chain(item.device_ids)`, а позиции при непустом
   `device_ids` берутся только из `device_ids` (`:593`); `validate_create` (`:302-315`) не требует,
   чтобы `device_id` входил в `device_ids`. Устройство, которого нет среди позиций, может уехать
