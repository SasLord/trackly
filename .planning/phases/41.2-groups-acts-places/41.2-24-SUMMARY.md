# Фаза 41.2 План 24: сервис возврата UD-2 (выбор разбиения и предварительный вопрос)

Сервис возврата принимает выбор для частично возвращаемой контейнерной группы и умеет заранее ответить, будет ли группа разбита.

## Что сделано

- Коммит 11711f8c.
- `do_return` стал обёрткой над `do_return_with_split(..., GroupSplitChoiceDto::Release)`; тело прежнее, выбор передаётся в `apply_return_plan_in_tx` (~80 вызовов `do_return` в тестах не менялись, `ActReturnDto` без нового поля).
- `return_group_split_preview`: читающее соединение, проверка живой выдачи, тот же `returned_devices_and_places` + `load_snapshot` + `plan_for_return`, что у `do_return`. Возвращает `items` (группа, возвращаемые и остающиеся имена, место-цель, `places_match`, имя родителя) и `place_conflicts` (D-46, без ошибки). Записей нет, новых вызовов `plan_for_return_in_tx`, `release_*_in_tx` нет.
- Из `group_act_plan.rs` удалён мёртвый `split_items()` (потребителем стал бы только preview, которому нужны другие поля).
- Страж порядка и якоря `group_write_sites` переведены на `do_return_with_split`.

## Тесты

- 8 новых в `acts_groups` (52 зелёных): preview (partial, whole/anchor пусто, разные места), контроль Release, MoveGroup (4 члена, 2 возвращены), откат акта возврата, целиком с разными местами отклоняется без записей (с контролем одинаковых мест), partial при разных местах: MoveGroup отклонён, Release работает.
- Мутация реального `act_service.rs` (split всегда `Release`): краснеют 3 теста (MoveGroup, undo, разные места); файл восстановлен, `diff -q` чистый. Undo-тест сначала проходил под мутацией - добавлена проверка состояния до отката (группа переехала, 2 члена).
- Зелёные: `acts_group_plan_order_guard` (17, мутанты сохранили силу), `acts_returns`, `group_write_sites` (34), `entities_changed_acts`, `acts_changed_place_ids`, `number_space_broadcast_gate`; `cargo fmt --check`, `cargo clippy -p trackly-app --all-targets -- -D warnings`.

## Отклонения от плана

**1. [Rule 3 - блокер] Тип параметра `do_return_with_split`.** План называл `GroupSplitChoice`, но он `pub(crate)`: pub-метод с таким параметром даёт предупреждение private_interfaces и недоступен интеграционным тестам. Принят `GroupSplitChoiceDto`.

**2. [Rule 1] `group_write_sites.rs`: якоря `pub async fn do_return(`** (ACT_DIRECT_PATH_SIGS и мутант 3) нашли бы обёртку без release; переведены на `do_return_with_split(`. Гейт не ослаблен: счётчик прямых release = 5 сохранён.
