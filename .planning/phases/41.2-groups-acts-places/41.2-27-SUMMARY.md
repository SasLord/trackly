# Фаза 41.2 План 27: вопрос при разбиении группы возвратом (UD-2)

Перед отправкой возврата `ReturnModal` спрашивает сервер (preview) и, если возврат разбивает контейнерную группу, показывает один попап «Отмена / Вывести из группы / Изменить расположение группы».

## Что сделано

- **2d886448 (RED).** Гейт `check-return-group-split.mjs` на неисправленных исходниках: exit 1, 14 нарушений (нет попапа, нет вызовов preview, нет `send`, нет `place_conflicts`, нет методов api).
- **78da48d0 (GREEN).**
  - `api/acts.ts`: `returnGroupSplitPreview`, `updateReturnGroupSplitPreview`; `doReturn(actId, payload, groupSplit?)` и `updateReturn(payload, groupSplit?)` кладут `groupSplit` в вызов только когда он задан.
  - `GroupSplitChoicePopup.svelte`: презентационный, начальный фокус на «Отмена», по каждой группе тексты D-45, списки возвращаемых и остающихся устройств с внутренней прокруткой; «Изменить расположение группы» `disabled`, если у любой группы `places_match = false`, с пояснением (D-46).
  - `ReturnModal.svelte`: `handleSubmit` собирает payload (`build`), спрашивает preview, затем: `place_conflicts` -> встроенная ошибка формы (`formError`, `role="alert"`), без попапа и отправки; `items` -> `splitPrompt`, отправки нет; иначе `send`. Вся отправка вынесена в `send(built, groupSplit?)`, дублирования между созданием и правкой нет. Попап стоит рядом с `Modal` формы (стек Modal), Отмена сбрасывает `submitting` и оставляет введённое. Ошибка preview -> error-тост без отправки. Серверная ошибка отправки теперь тоже в блоке `formError` (вместо тоста).
  - Гейт подключён в `pnpm lint`.
- **67a8064e.** UI-SPEC §10.6 с попапом, ошибкой разных мест и снятием прежнего правила «без подтверждения».

## Гейт

`--selftest` ловит 13 мутантов реальных исходников с уникальным якорем: удалён preview (создание и правка); перестановка `send(` выше preview; перестановка `send(` выше проверки `place_conflicts`; убрана проверка `place_conflicts`; убран третий аргумент `doReturn`; убран второй `updateReturn`; убран `initialFocus`; `acts.doReturn(` в попапе; потерян исход «Вывести из группы»; снята зависимость `moveDisabled` от `places_match`; попап под чужим `{#if}`; `doReturn` в api без `groupSplit`. Пустой набор файлов даёт нарушение (M).

## Отклонения от плана

**1. [Rule 3 - блокировка] Allowlist словаря групп.** `check-group-vocabulary` (GRD-06) покраснел на литералах попапа и ошибки формы. Добавлены записи с узкими маркерами реальных литералов для `GroupSplitChoicePopup.svelte` и `ReturnModal.svelte` (маркер `Группа «`) по образцу плана 41.2-22.

**2. Форма гейта.** Вместо «preview выше doReturn в handleSubmit» отправка живёт в отдельной `send`; гейт проверяет порядок preview -> place_conflicts -> splitPrompt -> `send(` внутри `handleSubmit` и запрещает `acts.doReturn(`/`acts.updateReturn(` вне `send`. Сила проверки не ослаблена.

**3. Ошибки отправки.** Серверная ошибка возврата показывается встроенным блоком вместо error-тоста (требование D-46: тот же блок).

## Для живой проверки пользователем (чек-лист плана 41.2-28)

Гейт структурный и этого не доказывает. Проверить в запущенном приложении:
1. Контейнерная группа из 3 устройств, акт выдачи. Вернуть 1 устройство: открывается один попап «Группа будет разделена» без смещения формы и без двух окон; названа группа, «Возвращается 1 из 3», списки «Возвращаются» и «Останутся вне группы».
2. Начальный фокус на «Отмена»; Enter не отправляет; Esc, крестик и подложка возвращают в форму с введёнными данными, возврат не создан; повторное «Оформить возврат» снова спрашивает.
3. «Вывести из группы»: возвращаемое выходит из группы, группа на месте. «Изменить расположение группы»: группа с возвращаемым переезжает в место возврата, остальные выходят из группы и остаются на прежнем месте.
4. Условие: возврат части группы в РАЗНЫЕ места по строкам (режим без «Применить ко всем») - кнопка «Изменить расположение группы» недоступна, виден текст про разные места.
5. Возврат всей группы целиком в одно место: попапа нет, группа сохраняется.
6. Возврат всей группы целиком в РАЗНЫЕ места: попапа нет, под таблицей встроенная ошибка «Группа «…» возвращается целиком…», форма сохранила введённое, после исправления возврат проходит.
7. Те же сценарии на пути правки возврата (кнопка «Сохранить»).
8. Вид в WebView2/WKWebView и в браузере по LAN; длинные названия переносятся, длинный список прокручивается.

`entities_changed_gate` красный по `device_service.rs::create` (quick 261105-s6s), вне области.
