# Phase 41.2 Plan 06: Act expansion and group members commands Summary

**Two read-only commands on both transports: groups_act_expansion turns a group into a flat list of act units via the planner's own act_units, and places_group_members returns a group's physical composition as place-content rows.**

## Accomplishments

- `GroupService::act_expansion` (`ReadGroups` first line): snapshot via `group_act_plan::load_snapshot`, units from `act_units`, names and inventory/serial numbers in one chunked query. An anchor group expands to its single anchor; nested containers are flattened with `via_group_name`; soft-deleted devices are skipped; an empty group gives an empty list; a missing group gives `NotFound`.
- `GroupSearchHitDto` gained `place_path_short` (server formula `compute_place_path_short_with_conn`, `None` for a sleeping group), as the act picker hint needs.
- `PlaceService::group_members` (`ReadPlaces` first line) wraps `list_group_members` from 41.2-05.
- Both commands: `build_*`, Tauri command, HTTP handler and `.route`, `collect_commands!` entry, registry rows (`ro(GROUP,"act_expansion")`, `ro(PLACE,"group_members")`), a separate role-matrix test each, and `group_cases()` / route-completeness count updated (15 -> 16).
