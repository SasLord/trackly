# Phase 41.2 Plan 05: Group rows in place contents Summary

**expand_groups=false now returns one 'group' row per root live group with a place, hides its members (devices and printers) with a single shared predicate, and bulk move is pinned to the physical listing by a guard proven by mutation.**

## Accomplishments

- `list_subtree_contents_impl` implements the collapsed mode. `member_count` / `printer_member_count` come from one `closure(root, id)` recursive join (members of nested groups included, soft-deleted devices excluded). Number, code and status of a group row are NULL; no seventh status was invented.
- `subtree_stats_impl` is untouched (D-23): counters stay physical in both modes.
- `PlaceRepository::list_group_members` returns the flat live composition (direct, nested groups, anchor) as `device`/`printer` rows; missing or soft-deleted group gives an empty list. Row assembly (path shortening) is shared via `content_row_from_row`.
- Bulk move: the single `list_subtree_contents(&tx, root_id, true, true)` call is pinned by a behavioural test and a source guard.
