# Phase 41.2 Plan 14: Group composition expansion in place contents Summary

The chevron on a group row in «Места» now expands the group's live composition inline in the same table. A printer that is a member of a group, hidden while the mode is off, is visible there with its ordinary status and place.

## What was built

- `RowChevron` (the shared component, no fourth implementation) precedes the group name. `toggleGroup` swaps in a new `Set`, so expansion is reactive and lives only as long as the screen (UI-SPEC 11.3).
- `loadMembers(groupId, key)` is the single place calling `places_group_members`. It keeps a per-group load sequence and in-flight key as plain Maps. `membersByGroup` and `loadedKeyByGroup` are written only in `.then`. On error the one group collapses and the toast `Не удалось загрузить состав группы. Попробуйте ещё раз.` appears.
- The `$effect` reads `rows`, `rowsGen`, `expandedGroupIds` and `loadedKeyByGroup` and calls `loadMembers` for expanded groups with a stale cache. It makes no request and writes no state itself.
- Rendering after the group row: full-width `Загрузка…` while no cache exists, `Состав пуст` for an empty composition, otherwise `TableRow indent` rows with `last` on the final one, rendered by the same `rowCells` snippet as ordinary rows (clicks open «Просмотр»; no chevron, so no second level).
- `handleExpandGroupsChange(v)` clears `expandedGroupIds` when `v` is true and then calls `onExpandGroupsChange(v)`; the checkbox uses it. Tab counters come from `rows` and do not change on expand or collapse.
- Styles reuse the DeviceGroupRow `children-loading-row` look with tokens only; no `:global` was needed.

## Gate changes (check-places-expand-groups.mjs)

- Rule D: the chevron tag is cut out before counting; the remaining branch must still have exactly one `onclick` (the name button), no `openView(`, no `role="button"`. The double click must reach `openGroup(` directly or through a handler whose body calls `openGroup(` and not `openView(`.
- E: exactly one `<RowChevron` in the file and in the group branch, its `onclick` calls `toggleGroup(`, `toggleGroup` changes `expandedGroupIds`, no `tr-row-chevron` markup.
- F: exactly one `apiCall('places_group_members')`, inside `loadMembers`, never inside a `$effect`; some effect calls `loadMembers(` and writes no composition state; inside `loadMembers` the first state write comes after `.then(`.
- G: `handleExpandGroupsChange` clears `expandedGroupIds` on true and calls `onExpandGroupsChange(v)`; the checkbox is wired to it.
- H: `rowCells` has no chevron, is used at least twice, and the group branch renders members through `rowCells(member)`.
