В PlaceContents.svelte (реализуя D-19, D-20, D-18, D-23):
1. Перед именем группы в ячейке «Название» строки группы поставить `<RowChevron expanded={...} onclick={...} />` (общий шеврон, настоящая `<button>` с aria-expanded; четвёртой реализации шеврона не создавать). Состояние: `expandedGroupIds = $state<Set<number>>(new Set())`, `membersByGroup = $state<Record<number, PlaceContentDto[]>>({})`, `loadedKeyByGroup` и `rowsGen = $state(0)` (инкрементируется в продолжении основной загрузки строк после await — состав перечитывается, когда строки места перезагрузились, например по placeContentEventsStore.reloadSeq или reloadToken). Кэш состава валиден, пока `loadedKey === `${groupId}@${rowsGen}``.
2. Загрузка — отдельная функция `loadMembers(groupId, key)` с `loadSeq` (отбрасывание устаревших ответов) и `loadingKey` как ОБЫЧНЫМИ переменными (не $state): `apiCall<PlaceContentDto[]>('places_group_members', { groupId })`; запись `membersByGroup`/`loadedKeyByGroup` — ТОЛЬКО в продолжении `.then` после await, не в теле `$effect` (риск effect_update_depth_exceeded). `$effect` лишь вызывает loadMembers для раскрытых групп, у которых кэш не тот; сам apiCall в теле эффекта не стоит. При ошибке — сворачивание строки (удалить id из набора) и `pushToast('error', 'Не удалось загрузить состав группы. Попробуйте ещё раз.')`.
3. Рендер: сразу после строки группы, если id в expandedGroupIds: пока состав грузится и кэша нет — одна строка на всю ширину (`colspan={columnCount}`) `Загрузка…` (`--tr-text-tertiary`, фон `--tr-bg`); при пустом составе — строка `Состав пуст`; иначе строки состава ПЛОСКО — те же ячейки, что у обычных строк (вынести разметку ячеек обычной строки в `{#snippet rowCells(row)}` и использовать для обычных строк и строк состава, без дублирования), `<TableRow indent last={isLast}>`; строки состава открывают «Просмотр» (openView) как обычные; шеврона у строк состава нет (второй уровень раскрытия не делается).
4. `handleExpandGroupsChange(v)`: при `v === true` обнулить `expandedGroupIds = new Set()` и затем вызвать `onExpandGroupsChange(v)` (запись состояния — в обработчике, не в эффекте); чекбокс использует этот обработчик.
5. Двойной клик по строке группы по-прежнему переходит в раздел «Группы» и НЕ меняет раскрытие (одиночный клик по телу строки инертен); раскрытие и сворачивание не вызывают пересчёта счётчиков вкладок (они считаются по rows из основной загрузки).
6. Стили строки загрузки/пустоты — только токены; если нужен `:global` внутри `:has(...)`, писать `:global` ВНУТРИ `:has` (иначе Svelte вырежет селектор — мёртвое правило).
