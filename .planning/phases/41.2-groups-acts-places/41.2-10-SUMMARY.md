## Behaviour

- Sections are sorted by section number before they reach Dropdown (contiguous); an empty section draws no heading.
- Storage request is the previous `listGrouped` call unchanged (status "на_складе"). Group request is `groups.search(query, null)` filtered to roots, no status. Member request is a non-collapsing `devices.list` with `group_members_only: true`, `status_id: null`, plus one `groups.forDevices` call for the group name of each member. Each source has its own `.catch`, so one failing source does not blank the others. The statuses dictionary is needed only by the storage source.
- Dedup: sections 2 and 3 drop devices already in other rows; a member already covered by a storage collapse is dropped from section 3; a group is never dropped.
- `pickGroupHit`: expansion error / empty group / everything already present are toasts and leave the rows alone; limit is checked before the first `onChange(`; the first unit replaces the picked row, the rest are appended at the end; one `onChange` for the whole insert; each row has `quantity: 1`, `has_serial: true`, `group_ids: [device_id]`.
- Anchor group: one row (the anchor) plus the hint "Состав группы попадёт в комплектацию акта" kept in a session `$state<Set<number>>`, dropped on row removal, on query edit, and on a different pick.

## Deviations from Plan

**1. [Rule 3 - Blocking] check-place-path-short.mjs needed a new verdict kind**
- **Found during:** Task 3 (`pnpm lint`)
- **Issue:** the picker reads `hit.place_path_short` in script for a Dropdown slot. The gate requires a verdict for every file using the path identifier, and none of the existing kinds fit (DATA_ONLY/FULL_BY_DESIGN demand a full-path identifier, ROW_CELL/LINK_BUTTON read markup, PASSTHROUGH wants both keys). Lint was red.
- **Fix:** added exempt kind `SLOT_TEXT` (short path in script, no full path in the file, no short path in markup), one verdict for the picker, `MIN_VERDICTS` 22 to 23, two selftest cases (short appears in markup, full path appears). Selftest 25 cases pass.
- **Files modified:** `ui/scripts/check-place-path-short.mjs` (not in the plan's file list)
- **Commit:** 233fc141

**2. [Rule 1 - Bug] Dropdown auto-flattens a single non-expandable result**
- **Found during:** Task 1 (reading Dropdown)
- **Issue:** Dropdown calls `onExpandGroup` for a single remaining result regardless of `isGroupExpandable`; a lone group or member would have hit the storage-only expansion path.
- **Fix:** `expandItem` returns one synthetic member row for group/member kinds (precedent: `GroupContentsTable`); `pickMember` dispatches by kind. No shared-component change.
- **Commit:** 24aafce1

**3. [Plan wording] limit gate checks `MAX_ACT_ITEMS`, not the literal `100`**
- The limit lives in `const MAX_ACT_ITEMS = 100`; the gate asserts that constant equals 100 and that its first use in `pickGroupHit` precedes the first `onChange(`.

**4. [Plan wording] gate rule (D) requires the RETAINED marker at least twice**
- The marker occurs in the device cell and the quantity cell; a one-occurrence check would have let mutant (8) pass.
