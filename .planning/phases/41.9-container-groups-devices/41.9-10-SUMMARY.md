# Phase 41.9 Plan 10: G-2 подсветка сайдбара и G-4 меню свёртки Summary

Шаблон активного пункта сайдбара теперь допускает `?querystring` (общая функция `sidebarActivePattern`), а правый клик по строке свёртки одинаковых открывает собственное меню вместо меню браузера.

## Задача 1: диагностика G-2 (без коммита, правок нет)

Причина установлена воспроизведением (скрипт в scratchpad: `parse` из `regexparam@2.0.2`, тот же, что использует `use:active`). Чтение кода подтверждает цепочку: `active.svelte.js` строит `location = value.location + '?' + querystring`; `Router.svelte` обновляет `router.loc` по `hashchange`, `getLocation` отделяет querystring; шаблон `parse('/groups').pattern` хвоста не допускает. `GroupsPage.handleSelect` и `PlacesPage.handleTreeSelect` пишут адрес через `history.replaceState` без `hashchange`, поэтому внутристраничный выбор подсветку не меняет; любой `push('#/<раздел>?id=...')` из другого раздела её снимает.

Таблица воспроизведения (old = `parse(route).pattern`, new = `sidebarActivePattern`), по каждому из 13 маршрутов `SIDEBAR_ITEMS` результат одинаков по форме; для всех маршрутов:

| строка | old | new |
|--------|-----|-----|
| `<route>` | true | true |
| `<route>?id=5` | **false** | true |
| `<route>?type=3` | **false** | true |
| `<route>/` | true | true |

Ключевой случай из плана: шаблон `/groups` на `/groups?id=5`: old = false, new = true. Все 13 маршрутов (`/`, `/map`, `/places`, `/devices`, `/groups`, `/acts`, `/printers`, `/cartridges`, `/requests`, `/reports`, `/users`, `/settings`, `/showcase`) дали ту же картину. (В прототипе скрипта "new" был эквивалентной копией; реальная функция прогоняется golden-гейтом.) Гипотеза подтверждена, остановка не потребовалась.

Затронутые переходы с querystring (grep по `src`, число упоминаний `#/<раздел>?`): `#/groups?` 18, `#/places?` 7, `#/devices?` 5, `#/acts?` 5, `#/settings?` 2, `#/cartridges?` 1, `#/printers?` 1. Файлы: CartridgeDetail, DeviceContainerRow, DeviceFormBody, DeviceFormModal, DeviceList, DeviceListRow, DeviceRowMenu, GroupPanel, PlaceContents, PlaceEntityViewModal, PrinterDetail, NumberTemplateField. Теряют подсветку пункты «Группы», «Места», «Устройства», «Акты», «Настройки», «Картриджи», «Принтеры». Вывод: причина общая, правка в шаблоне пункта.
