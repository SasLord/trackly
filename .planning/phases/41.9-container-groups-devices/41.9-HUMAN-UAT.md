### G-1. Ошибка лимита при обновлении полностью подгруженного списка
status: resolved
severity: major
symptom: в режиме «Свернуть одинаковые» список подгружен до конца (более 200 строк); после добавления устройств в группу появляется красный тост `validation [pagination.limit]: Максимальный размер страницы — 200`, список не обновляется, устройства при этом добавлены. При подгрузке 100+ строк ошибки нет.
root_cause: подтверждена чтением кода. `fetchList` дробит перечитывание на чанки по `GROUP_MEMBERS_PAGE_MAX` = 200, а `fetchPortion` в режиме свёртки запрашивает `limit + 1` (`DevicesPage.svelte`, вызов `devices.listGrouped`), то есть 201 при серверном пределе 200.
direction: ограничить запрос с учётом «+1» и закрепить кейс тестом правил `rangeChunks`/порций.

### G-2. Сайдбар теряет выбранный раздел при открытии группы из «Устройств»
status: resolved
severity: minor
symptom: после открытия группы из строки АРМ раздел «Группы» открыт, но в сайдбаре не выбран ни один пункт.
root_cause: не установлена. Сайдбар использует `use:active` из `svelte-spa-router` (`Sidebar.svelte`), переход идёт через `push('#/groups?id=N')`, `GroupsPage.handleSelect` переписывает адрес через `history.replaceState` без `hashchange`. Нужна проверка, затронуты ли другие переходы вида `#/groups?id=`.

### G-3. Поиск не находит АРМ по имени
status: resolved
severity: major
symptom: запрос «АРМ» в поле поиска раздела «Устройства» даёт пустой список.
root_cause: подтверждена чтением кода. В режиме поиска клиент передаёт `hide_anchor_members: false` (`shouldHideAnchorMembers` ложно при активном поиске), а `list_containers` строит блок только при `hide_anchor_members = true`. Клиентское правило `shouldShowContainerRows` разрешает строки АРМ при поиске, сервер их отбрасывает. Сервисные тесты проходили с другим набором флагов, чем шлёт клиент.
direction: выровнять условие на сервере и добавить тест с точными флагами клиента.

### G-4. Контекстное меню браузера на строке свёртки

severity: minor
symptom: в режиме «Свернуть одинаковые» правый клик по свёртке одинаковых принтеров открывает меню браузера.

### G-7. Догрузка состава сбрасывает прокрутку
status: resolved
severity: minor
symptom: нажатие «Загрузить ещё» у неполной группы уводит экран к началу списка. G-1, G-2, G-3 и строка «Загрузить ещё» (G-5) при этом подтверждены пользователем.
root_cause: подтверждена чтением кода. После догрузки `loadRest` переводит фокус на шеврон строки группы вызовом `.focus()`, браузер прокручивает к этой строке. Список не перезаполняется.
direction: `.focus({ preventScroll: true })`.
