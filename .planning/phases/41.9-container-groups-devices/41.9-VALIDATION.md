# Phase 41.9 — Validation Strategy

> Контракт проверки на время исполнения фазы. Источник: раздел «Validation Architecture» в `41.9-RESEARCH.md`.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | cargo test (интеграционные `crates/trackly-app/tests/*.rs`), node-гейты `ui/scripts/check-*.mjs` с golden-фикстурами, `svelte-check` |
| **Config file** | `ui/package.json`; Rust — workspace |
| **Quick run command** | `cargo test -p trackly-app --test <цель>` (одна цель; не запускать несколько `cargo test` одновременно) |
| **Full suite command** | команда `ci-full` проекта, в фоне, вывод сырым в файл |
| **Estimated runtime** | целевой тест — минуты; сплошной прогон — 4,5–6 часов |

---

## Sampling Rate

- **После коммита задачи:** целевой `cargo test -p trackly-app --test <цель>` и `node ui/scripts/check-device-list-mode.mjs`
- **На границе волны:** отдельно `pnpm --dir ui lint`, `pnpm --dir ui svelte-check`, `cargo clippy`, `cargo fmt --check`; сплошной прогон — один раз, в фоне
- **Перед `/gsd-verify-work`:** `ci-full` зелёный, затем живая UAT в приложении и LAN-браузере
- **Max feedback latency:** целевой тест, не сплошной прогон
