# Phase 41.9 Plan 03: ключи смешанного списка, контейнеры и прямые дети группы

Репозиторий отдаёт ключи списка «Устройства» (устройства и корневые непустые АРМ) одним `UNION ALL` с `ORDER BY name, kind, id`, строки контейнеров с `device_count` по closure и прямых детей группы.

## Что сделано

- Коммит f2fda862 (обе задачи вместе: методы и тесты делят фикстуру и макросы).
- Типы `EntryKind` (rank 0/1), `EntryKey`, `ContainerRow` в `trackly-core`.
- `DEVICE_LIST_WHERE` вынесен из `count_list_rows`/`select_list_rows`, поведение прежнее (регрессии зелёные).
- `list_entry_keys`: COUNT и выборка строятся из одного текста `entry_union_sql()`; строки контейнеров включаются параметром `?14` только при `hide_anchor_members && status_id IS NULL && !anchors_only && member_of_group_id IS NULL`.
- `list_root_containers`, `container_rows` (плейсхолдеры `?`, порядок как у `ids`, удалённые отсеяны), `group_children_keys` (без фильтра по `type_id`).
- Макросы `nonempty_group_ids_sql!`, `root_container_where_sql!`: некоррелированный closure по образцу `tree_counts`.
