<objective>
Закрыть NEW-1 (третий SQL-путь остатка WR-03): `SqliteDeviceRepository::restore_from_snapshot_in_tx`
(вызывается из `ActService::update`, `update_return` и `undo_device_mutations_for_act` — undo
акта/мягкое удаление) сегодня использует `COALESCE` для пяти clearable-полей устройства
(`serial_number`/`model`/`condition`/`complectation`/`notes`), извлекая их из
`serde_json::Value` через `snapshot.get(key).and_then(|v| v.as_str())` — это схлопывает «ключ
отсутствует в JSON» и «ключ есть, значение `null`» в один и тот же Rust `None`, поэтому
`COALESCE(NULL, current)` молча сохраняет ТЕКУЩЕЕ значение вместо возврата к пустому. Пользователь
чистит поле после создания акта, затем откатывает акт (undo) — поле должно вернуться к пустоте
(snapshot нёс `null` на момент акта), но сегодня остаётся тем, чем было до undo.

Это ТОТ ЖЕ класс бага, что Фаза 40.3 закрыла для `update_in_tx`/`update` (CASE WHEN по presence
вместо COALESCE), но третья, отдельная точка кода с другим источником presence-флага (сырой
`serde_json::Value`, а не типизированный `Option<Option<T>>` DTO). D-01/D-02 (локальные решения
пользователя при планировании этой фазы) фиксируют объём: ТОЛЬКО сценарий «snapshot нёс null,
поле заполнено после акта» (сценарий 1) — не сценарий «snapshot нёс реальное значение, поле
очищено независимой правкой после акта» (сценарий 2, архитектурно другая и дороже задача,
явно НЕ в объёме — записана в `deferred-items.md` этой фазы). Ровно 5 полей CASE WHEN
(`serial_number`/`model`/`condition`/`complectation`/`notes`) — `type_id`/`name` остаются на
`COALESCE` (non-nullable в БД, физически не могут прийти как `null`), `inventory_number`
по-прежнему сознательно не восстанавливается (BE-WR-06).

Purpose: undo акта не должен молча оставлять устройство в состоянии, которое пользователь считает
уже исправленным — очистка поля после акта обязана «держаться» при откате того же акта.
Output: `restore_from_snapshot_in_tx` на presence-based CASE WHEN для 5 полей; расширенный
`DeviceSnap`-хелпер в `acts_undo.rs`; новый регресс-тест, мутационно доказывающий RED→GREEN переход.
</objective>
