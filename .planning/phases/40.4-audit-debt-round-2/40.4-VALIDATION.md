# Phase 40.4 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust `cargo test` (trackly-core, trackly-infra, trackly-app); UI `pnpm --dir ui lint` (svelte-check + eslint + prettier + `scripts/check-*.mjs`, включая `--selftest`-цепочки) |
| **Config file** | `crates/*/Cargo.toml`; `ui/package.json` (`scripts.lint`) |
| **Quick run command** | `TRACKLY_AD_MOCK=1 TRACKLY_SNMP_MOCK=1 cargo test -p <crate> <module> -- --skip login_remember_persistent_cookie` / `pnpm --dir ui lint` |
| **Full suite command** | `TRACKLY_AD_MOCK=1 TRACKLY_SNMP_MOCK=1 cargo test --workspace -- --skip login_remember_persistent_cookie` + `pnpm --dir ui build && pnpm --dir ui lint` |
| **Estimated runtime** | ~300 s (full), ~60 s (targeted) |

Одна `cargo test`-сессия за раз (project memory `cargo_no_concurrent_test`). При exit 69 на
линковке — префикс `DEVELOPER_DIR=/Library/Developer/CommandLineTools`. Пакет `trackly-app`
требует собранный `ui/dist` (`pnpm --dir ui build`) для HTTP/LAN-сценариев.

---

## Sampling Rate

- **After every task commit:** targeted `cargo test -p <crate> <module>` для затронутых файлов,
  или `pnpm --dir ui lint` для UI-задач
- **After every plan wave:** full suite command (полный прогон пакета, не «зелено по своим
  файлам» — project memory `executor_file_scope_vs_package_gate`)
- **Before `/gsd-verify-work`:** full suite зелёный + живая UAT в `cargo tauri dev` для N-3
  (инвалидация дерева) и NEW-3 (массовое создание). Playwright/Chromium-харнесс НЕ засчитывается
  как верификация Svelte-рантайма (project memory `synthetic_harness_not_verification`)
- **Max feedback latency:** 300 s
