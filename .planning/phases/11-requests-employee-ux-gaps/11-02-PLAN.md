Источник данных (паттерн devices_sqlite.rs, l.name = последний столбец):
  SELECT d.id, d.name, l.name AS location
    FROM devices d
    LEFT JOIN locations l ON d.location_id = l.id
   WHERE d.type_id = 2 AND d.deleted_at_utc IS NULL
   ORDER BY l.name IS NULL, l.name, d.name
Параметризованный, без пользовательского ввода (нет фильтра «на первое время» — весь список).
Читать через ctx.readers.acquire() в tokio::task::spawn_blocking (single-writer discipline).

RequestPrinterOptionDto (dto/request.rs), #[serde(rename_all="camelCase")], #[specta(type=i32)] на id:
  { id: i64 (device id → printer_device_id), name: String, location: Option<String> }

Регистрация — 3 точки:
  1. tauri_cmds/requests.rs: build_request_printer_options(ctx, caller) + #[tauri::command] request_printer_options
     (#[specta::specta] СЛЕДУЕТ за #[tauri::command]).
  2. http/requests.rs: handler_request_printer_options + .route("/api/v1/request_printer_options", post(...)).
  3. specta_export.rs collect_commands!: crate::tauri_cmds::requests::request_printer_options.

Read-эндпоинт НЕ должен слать ws_broadcast (это чтение, не мутация).

UI: api.ts mirror listCategories → printerOptions: () => apiCall<RequestPrinterOptionDto[]>('request_printer_options').
