## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| CSV-файл → `import_csv_commit` | подпись типа из ячейки — недоверенный ввод | текст подписи типа/статуса, инвентарные номера |
| `device_types` → CSV-экспорт | подпись типа попадает в файл, открываемый в Excel | строка справочника |
| LAN-браузер → `POST /api/v1/device_types_list` | запрос под сессией, роль определяет доступ | список (id, подпись) типов |
| webview → Tauri `invoke device_types_list` | идентичность из `resolve_tauri_identity` | тот же список |
| ответ сервера → разметка Svelte | подписи типов выводятся в Dropdown как текст | строки справочника |
| UI-обработчик удаления → счётчики дерева мест | при оборванном WS только локальный вызов обновляет UI | id места удалённого предмета |
| исходники `crates/*/src`, `ui/src` → тест-гейты | структурная проверка, код не исполняется | — |
| рабочая копия → публичный репозиторий | всё закоммиченное остаётся в истории git | фикстуры, тесты, артефакты `.planning/` |

## Остаточные ограничения (не блокеры, зафиксированы для следующих аудитов)

- **O-1 (T-41.12-09).** Отдельного теста «без сессии → 401» именно на
  `/api/v1/device_types_list` нет: закрытие опирается на единственный путь получения
  идентичности (`session_identity`, возвращающий `AppError::Unauthorized`) и на общий
  кейс «no session → 401» матрицы ролей для соседнего маршрута. Если появится свой
  экстрактор идентичности — потребуется явный кейс.
- **O-2 (T-41.12-15).** Рантайм-часть проверена на одноразовом стенде в Chromium по
  HTTP-пути (LAN); специфика WKWebView и транспорта Tauri invoke живым прогоном не
  закрыта (зафиксировано в `41.12-HUMAN-UAT.md`).
- **O-3 (T-41.12-24).** `check-privacy.mjs` детектирует зарегистрированные токены по
  хэшам и структурные признаки (реквизиты, бинарные расширения); произвольное реальное
  ФИО он не распознаёт. Защита от такого попадания остаётся процедурной (ревью фикстур
  и артефактов до коммита). Фикстуры и чек-лист этой фазы просмотрены — только
  вымышленные имена.
- **O-4 (T-41.12-26).** Полный workspace-прогон выполнен в четыре части: первый прогон
  оборвался по страховочному таймеру (>2 ч), остаток добит явным списком бинарников,
  определённым по логу. Покрытие полное, но подтверждается суммой четырёх логов вне
  репозитория, а не одним артефактом.
- **O-5 (гейты).** `check-place-path-short.mjs` сознательно не сканирует
  сгенерированные `bindings*.ts` и `*.d.ts`; исключение задокументировано в заголовке
  скрипта. Расхождение «27 grep-совпадений против 24 файлов семейства» полностью
  объяснено (2 × `bindings*.ts`, 1 файл с идентификаторами только в комментариях).
