## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| клиент (LAN-браузер / Tauri) → `/api/v1/devices_update` | тело патча несёт `usb_host_device_id`, `printer_ip_address`, `printer_community` | идентификатор постороннего устройства, сетевой адрес, SNMP-секрет |
| клиент → `/api/v1/devices_create_single_with_number_check` | блок принтера (`PrinterCreateBlockDto`) с IP, community и хостом | то же, на пути создания |
| клиент → `printers_create` (прежний путь) | `PrinterCreateDto.usb_host_device_id` без серверной проверки хоста | идентификатор устройства (см. принятый риск R-05) |
| клиент → `groups_card` | ответ несёт названия, инв./серийные № принтеров и подпись USB-хоста | инвентарные данные организации |
| клиент → `groups_add_devices` | состав группы меняется; продуктовый запрет D-32 снят | принадлежность устройства группе |
| сервер → `RealSnmpClient` (UDP) | сохранённый `printers.ip_address` уходит в сетевой запрос | SSRF-поверхность: адрес и порт назначения |
| сервис → таблицы `devices` / `printers` | единая точка записи (`WriterHandle`), одна транзакция на устройство и строку принтера | целостность конверсии тип ⇄ строка принтера |
| рабочая копия → публичный репозиторий | артефакты фазы, тесты, фикстуры | реальные данные организации и ФИО (жёсткое условие проекта) |
| исполнитель → чекпоинт живой проверки | подтверждение поведения в запущенном приложении | достоверность приёмки (repudiation) |
