# Phase 41.13 Plan 13: подпись USB-хоста в карточке группы Summary

**Под бейджем «USB» в колонке «Связь» второй строкой выводится «Имя» или «Имя · инв. N»; подпись есть только у строк origin usb, структурный гейт держит это правилами F1-F7, перестановка «подпись выше бейджа» краснеет.**

## Как выглядит подпись и где стоит

В `GroupPrintersList.svelte`, ячейка «Связь», внутри `{#if r.origin === 'usb'}`, сразу после `<Badge variant="accent">USB</Badge>`, под `{#if r.hostName}`:

```
<span class="host" title={hostLabel(r)}>{r.hostName}{#if r.hostInventoryNumber} · инв. <span class="tr-mono">{r.hostInventoryNumber}</span>{/if}</span>
```

(в файле разбито prettier'ом на строки). Это текст элемента, читаемый без наведения; `title` (функция `hostLabel`) - только дубль полного текста для длинных названий. Вывод интерполяцией Svelte, `{@html}` нет.

Стиль `.host` (SCSS): `display: block; margin-top: var(--tr-space-2xs); font-size: var(--tr-font-size-caption); color: var(--tr-text-secondary); white-space: normal; text-align: left; overflow-wrap: anywhere;`. Новых токенов, hex и custom properties нет. `white-space: normal` и `text-align: left` нужны, чтобы перебить nowrap/center, протекающие из `td.cell`.

## Имя есть, инв. номера нет

Выводится только имя, без « · инв.» и без пустого моноширинного span (блок `{#if r.hostInventoryNumber}`). В `title` то же самое (`hostLabel`).
Имени нет (`usb_host_name` null): `{#if r.hostName}` не срабатывает, строки подписи нет вообще; id хоста не выводится ни при каких условиях (колонка `device_id` в ячейке «Связь» запрещена правилом F4).

## Источник данных

`Row` получил `hostName` и `hostInventoryNumber`. В первом цикле: `const usbHost = p.origin === 'usb' ? p : null;` затем `hostName: usbHost?.usb_host_name ?? null`, `hostInventoryNumber: usbHost?.usb_host_inventory_number ?? null`. Во втором цикле (ссылки из формы) оба поля `null`. Строка выражения `const origin: RowOrigin = ...` и условие пропуска `origin === 'link'` не менялись.

## Гейт check-group-printer-origin.mjs

Правила: F1 (охрана источника, единственное чтение полей через `usbHost?.`, присваивания 2 раза: серверное и `null`), F2 (внутри usb-ветки и после `<Badge>USB</Badge>`), F3 (подпись - текст, не только title), F4 (нет `device_id` в ячейке «Связь», нет `{@html}`), F5 (`инв.` + tr-mono + `r.hostInventoryNumber`), F6 (под `{#if r.hostName}`), F7 (стиль `.host`: токены, нет hex/custom property, есть overflow-wrap). Вспомогательная `enclosingConds` разбирает стек `{#if}/{:else if}/{:else}` вокруг позиции. Правила A-E не менялись (B получило исключение для оператора `usbHost`). `ui/package.json` не менялся: `grep -o check-group-printer-origin ui/package.json | wc -l` = 2.
