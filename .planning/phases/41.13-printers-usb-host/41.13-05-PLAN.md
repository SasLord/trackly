<objective>
Показать происхождение каждой строки «Подключённых принтеров» и не сломать места, где UI фильтрует
принтеры по литералу 'usb'.

Purpose: PGR-01/PGR-02 на стороне интерфейса (находка карты образцов №1: GroupPropertiesForm и
GroupPrintersList).
Output: правки двух компонентов, структурный гейт с мутационным selftest, подключение к lint.
План не требует cargo: работает только с ui/ (pnpm). Зависит от 41.13-01 по смыслу (сервер отдаёт origin = member).

ИЗВЕСТНОЕ ОГРАНИЧЕНИЕ (решение плана, не переделывать): принтер-член, на которого явная ссылка стоит только во ВТОРОМ (не первичном) свойстве «Ссылки на устройства» пользовательского типа, получает от сервера origin = link, первый цикл rows строки link пропускает, а в linkedIds первичного свойства его нет — поэтому в списке первичного свойства он не показывается (виден в списке того свойства, где стоит ссылка, с пометкой «Ссылка»). У встроенных типов свойство-ссылка одно, ограничение их не затрагивает; для пользовательских типов с несколькими такими свойствами это пограничное нарушение PGR-01 («правило не зависит от типа группы»). Принято сознательно: различить «член и ссылка» и «только ссылка» в списке на клиенте нельзя без расширения DTO (origin теряет информацию о членстве), а список вторичных свойств по замыслу показывает только ссылки. Исполнитель ОБЯЗАН записать это ограничение в SUMMARY отдельным пунктом «Известное ограничение» и не пытаться обойти его в обход серверного DTO.
</objective>
