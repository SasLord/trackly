## Известное ограничение

Принтер-член, у которого явная ссылка стоит только во ВТОРОМ (не первичном) свойстве «Ссылки на устройства» пользовательского типа, получает от сервера `origin = link`; первый цикл `rows` строки `link` пропускает, а в `linkedIds` первичного свойства его нет — в списке первичного свойства он не показывается (виден в списке того свойства, где стоит ссылка, с пометкой «Ссылка»). У встроенных типов свойство-ссылка одно, их это не затрагивает; для пользовательских типов с несколькими такими свойствами это пограничное нарушение PGR-01 («правило не зависит от типа группы»). Принято планом сознательно: различить «член и ссылка» и «только ссылка» на клиенте нельзя без расширения DTO (origin теряет информацию о членстве), а список вторичных свойств по замыслу показывает только ссылки. Обход в обход серверного DTO не делался.

## Мутационная проверка гейта

Selftest: чистые реальные исходники проходят; 19 мутантов, каждый краснит именно ожидаемое правило, плюс зелёный контроль «запретные токены в комментарии не краснят». Якоря проверяются функцией `mutate()` на ровно одно вхождение (иначе selftest бросает ошибку).

Мутанты: (1) отбор строк сервера только по usb; (2) ПЕРЕСТАНОВКА `hasLink ? 'member' : 'link'`; (3) ПЕРЕСТАНОВКА ссылка выше USB; (4) запасной поиск снова по `!== 'usb'`; (5) текст «В составе» убран; (6) «В составе» в accent; (7) «USB» без accent; (8) «Ссылка» вне Badge; (9) вернулась фраза «появятся здесь сами»; (10) «ссылкой ниже» в варианте без поля; (11) Table без `{emptyBody}`; (12) меню по origin вместо r.link; (13) меню без условия по ссылке; (14) фильтр вторичных свойств `!== 'usb'`; (15) вернулась `usbPrinters`; (16) блок только для чтения по usb; (17) ловушка `/*` внутри `//` перед нарушением; (18) нет `<script>`; (19) файл отсутствует.

Сквозная мутация по реальному исходнику вне selftest:
- Якорь `card.printers.filter((x) => x.origin === 'link')` в `GroupPropertiesForm.svelte`: счёт вхождений до мутации = **1**. Мутант `x.origin !== 'usb'` -> гейт exit=1 (два нарушения C). Восстановление из копии, `cmp` — `IDENTICAL`.
- Якорь `hasLink ? 'link' : 'member'` в `GroupPrintersList.svelte`: счёт = **1**. Мутант-перестановка `hasLink ? 'member' : 'link'` -> exit=1 (нарушение B). Восстановление, `cmp` — `IDENTICAL`; чистый прогон после — exit=0; `git status` показал только ожидаемые файлы плана.

Замечание: гейт на порядок веток строгий (регулярное выражение по нормализованным пробелам), семантически равный, но иначе записанный рефакторинг выражения `origin` его покраснит — осознанная цена за ловлю перестановок.
