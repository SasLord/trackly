# Requirements: Trackly v1.2 — Редизайн UI и дизайн-система

**Milestone goal:** Перевести интерфейс на новую дизайн-систему (спроектирована в Claude Design) —
единый слой токенов, переработанные примитивы и все окна — не потеряв плотность рабочего инструмента.

**Источник дизайна:** `.planning/reference/design-system-v2/` — 11 файлов из Claude Design.
Формат `.dc.html` — **спецификация, а не переносимый код** (Design Canvas: `<x-dc>`, `sc-for`, `{{ }}`,
класс `DCLogic`, требует `support.js`). Значения CSS извлекаются из них; разметка переписывается на Svelte.

## Критичный контекст миграции

**Ловушка переименования шкал.** Новая система переиспользует имена с другими значениями.
Мигрировать нужно **по значению, а не по имени** — иначе 642 использования `--space-*` тихо
поедут без единой ошибки сборки. Карта соответствия:

| Сейчас | px | Новое имя с тем же значением |
|---|---|---|
| `--space-xs` | 4 | `--tr-space-2xs` |
| `--space-sm` | 8 | `--tr-space-xs` |
| `--space-md` | 16 | `--tr-space-md` ✓ |
| `--space-lg` | 24 | `--tr-space-xl` |
| `--space-xl` | 32 | `--tr-space-2xl` |
| `--space-2xl` | 48 | `--tr-space-4xl` |
| `--radius-sm` | 4 | `--tr-radius-xs` (кнопки/поля намеренно идут 4→6 = `--tr-radius-sm`) |
| `--radius-md` | 8 | `--tr-radius-md` ✓ |

**Замеры кодовой базы (2026-07-16):** 105 из 118 svelte-файлов ходят через токены —
смена значений разойдётся по UI сама. Использований: `--space-*` — 642, `--radius-*` — 132,
`--font-size-*` — ~344. Захардкоженных hex — около 40 (из них `#c0392b` — 22 раза).

**Покрытие дизайном:** готовые макеты есть только на 2 окна из ~12 (Дашборд, Список устройств).
Раскладку остальных придётся выводить из компонентной системы.

**Открытый вопрос для `/gsd-ui-phase`:** новый дизайн вводит `transition: background .12s,
box-shadow .12s` на кнопках. Это противоречит `transition: none` в `Button.svelte:46`
(комментарий ссылается на UI-SPEC §Motion). Важно: §Motion **не запрещает анимации вообще** —
там прописан `Modal enter: opacity 0→1 + scale 0.98→1.00 (150ms ease-out)`. Запрет касался
конкретно переключения темы, поэтому конфликт уже́, чем выглядит.

## Future Requirements

Отложено за пределы v1.2:

- **Анимации и микро-взаимодействия сверх текущих** — сначала статика новой системы, motion-язык отдельно
- **Плотный режим таблиц (compact density toggle)** — `--row-height-dense` существует в токенах, но UI-переключателя нет
- **Пересмотр иконографики** — дизайн-система иконки не покрывает

## Out of Scope

- **Изменение поведения/логики** — milestone чисто визуальный; функциональность, роли и API не трогаем
- **Новые экраны** — только переоформление существующих
- **Внешние шрифты / CDN** — портативность: только системный шрифт (ограничение проекта)
- **i18n** — UI остаётся только русским (см. PROJECT.md → Out of Scope)
- **Печатные HTML-шаблоны актов** — у них своя вёрстка под печать, дизайн-система на них не распространяется
