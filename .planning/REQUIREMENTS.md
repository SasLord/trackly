# Requirements — Milestone v1.3 «AD-SSO паритет + полировка превью печати»

**Milestone goal:** довести passwordless AD-SSO (Kerberos/SPNEGO) до полного паритета с
reference-проектом adwebapp и привести предпросмотр печати к «вордовскому» виду.

**Baseline:** AD-SSO спайк уже LIVE-VALIDATED на реальном AD (ветка `spike/ad-sso-kerberos`):
passwordless-вход, авто-регистрация, keytab-валидация offline (`sspi 0.21`), UI-тумблер +
статус, кнопка входа, live-обновление роли из БД. Эти требования достраивают SSO до паритета и
добавляют полировку печати. Приватность org-данных — жёсткое требование (в git только
плейсхолдеры; реальные значения — в gitignored `trackly.config.toml`).

---

## v1.3 Requirements

### SSO — AD Single Sign-On (паритет с adwebapp)

- [ ] **SSO-01**: Пользователь, вошедший через AD-SSO, отображается по реальному ФИО (AD
  `displayName`), а не по доменному логину. ФИО резолвится служебным bind'ом (service-account
  LDAP: bind фиксированной учёткой → поиск `sAMAccountName` → `displayName`, fallback `cn` →
  логин) с кэшем, чтобы не дёргать DC на каждый запрос. По образцу adwebapp `ldap.go`.
- [ ] **SSO-02**: Администратор может задать список доменных логинов, которые при первом
  SSO-входе сразу получают роль «Администратор» — без ручного подтверждения заявки (аналог
  `ADMIN_AD_LOGINS` в adwebapp). Решает проблему «первого администратора».
- [ ] **SSO-03**: Роли пользователей назначаются автоматически по членству в AD-группах
  (настраиваемый маппинг «AD-группа → роль», проверка через `memberOf` /
  `LDAP_MATCHING_RULE_IN_CHAIN`, fail-closed при недоступности каталога).

### PRV — Предпросмотр и печать документов

- [ ] **PRV-01**: Модалка предпросмотра печати (Акты, Приёмка/DocumentAcceptance, Отчёты)
  показывает документ как лист формата A4, лежащий над сероватой подложкой-фоном — визуально
  как предпросмотр печати в Word.
- [ ] **PRV-02**: Лист предпросмотра имеет внутренние поля (margins) сверху, снизу и по краям,
  соответствующие полям печати.
- [ ] **PRV-03**: Печать совпадает с предпросмотром (WYSIWYG) — то, что пользователь видит в
  модалке, то и выводится на бумагу (через `@media print`, единый источник стилей листа).

## Out of Scope (v1.3)

<!-- Явные границы, чтобы не расползалось. -->

- **NTLM-fallback для SSO** — только Kerberos (как в adwebapp; NTLM показывает нативный диалог).
- **LDAPS-вход логином/паролем через служебный bind** — служебный bind в SSO-01/03 используется
  только для чтения (displayName / членство в группе); пользовательский вход по паролю остаётся
  как есть (bind самим пользователем).
- **Полноформатная система шаблонов печати / редактор полей** — PRV только про визуальную
  подачу предпросмотра и WYSIWYG, не про новый редактор документов.
- **Множественные форматы бумаги (A5/Letter/…)** — только A4 (единственный используемый формат).
- **Загрузка keytab через UI** — keytab кладётся на диск рядом с exe (секрет), путь — в конфиге.
