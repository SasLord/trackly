# Trackly Link: руководство администратора

Trackly Link — отдельный клиент для сотрудников. Он живёт в трее, входит в Trackly
(автоматически по домену или логином и паролем) и подключается к серверу Trackly по
HTTPS с проверкой отпечатка ключа сервера. В документе используются только вымышленные
имена: `trackly.example.local`, `EXAMPLE`, `PC-EXAMPLE-01`.

## Как клиент находит сервер: файл `link.toml`

Link читает `link.toml` из двух мест. **Первый найденный файл решает всё целиком**:
машинный конфиг побеждает пользовательский, значения не смешиваются, а невалидный
машинный файл не заменяется молча пользовательским (клиент покажет ошибку настройки).

| ОС | Машинный конфиг (приоритет) | Пользовательский конфиг |
|----|-----------------------------|-------------------------|
| Windows | `%ProgramData%\Trackly Link\link.toml` | локальные данные пользователя (`app_local_data_dir`, НЕ Roaming) |
| macOS | `/Library/Application Support/Trackly Link/link.toml` | то же, каталог данных приложения пользователя |
| Linux | `/etc/trackly-link/link.toml` | то же |

Пользовательский файл создаётся самим Link после успешного ввода кода приглашения.
Машинный создаёт администратор (например, групповой политикой), чтобы сотрудникам
не нужно было вводить код.

```toml
server     = "trackly.example.local:8443"   # хост[:порт], порт по умолчанию 8443
pin_sha256 = "AA:BB:...:FF"                 # SPKI-отпечаток сервера, 32 байта в hex через двоеточие
spn        = "HTTP/trackly.example.local"   # необязательно: SPN для автовхода, если он отличается от имени сервера
```

## Где взять отпечаток (SPKI)

Откройте в Trackly **Настройки → Сеть** при запущенном сервере: строка
**«Отпечаток для Link (SPKI):»** с кнопкой «Копировать». Это отпечаток открытого ключа,
а не всего сертификата. Пока файл `server.key` рядом с БД сохраняется, SPKI не меняется
при перевыпуске сертификата (например, при смене адреса сервера). Если удалить
`server.key`, ключ станет новым, и все клиенты покажут экран «Сертификат сервера
изменился» (это защита от подмены; клиент не предлагает принять новый сертификат).

## Как подключить новый компьютер

1. Откройте раздел **«Link»** (боковое меню, виден только администратору).
2. Нажмите **«Выпустить код приглашения»**, выберите срок (1 час, 24 часа или 7 суток),
   скопируйте код. Код показывается **один раз** и в списке больше не виден.
3. Сотрудник запускает Link, на экране «Подключение к Trackly» вставляет код
   (пробелы и переносы строк допустимы).

Код **одноразовый**: после использования или по истечении срока он недействителен
(«Этот код уже использован…»). Неиспользованный код можно отозвать во вкладке
«Коды приглашения».

## Отзыв и запрет компьютера

- **Раздел «Link → Входы»**, кнопка **«Отозвать»**: клиент немедленно (на лету)
  показывает «Вход отозван администратором», а компьютер попадает в
  **«Запрещённые компьютеры»**: вход с него (в том числе автовход) невозможен.
- **«Запрещённые компьютеры» → «Разрешить»** снимает запрет; сотрудник входит снова без
  нового кода.
- **Настройки → Пользователи → карточка → «Отозвать входы Link»** отзывает все входы
  пользователя. Блокировка пользователя (снятие «Активен») отзывает его входы автоматически.

## Автозапуск

Автозапуск Link **всегда включён** и не настраивается: при входе в Windows Link стартует
свёрнутым в трей (запись в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` с путём
в кавычках, поэтому пути с пробелами работают). Если запись удалить (в том числе
отключить в Диспетчере задач), при следующем запуске Link она восстанавливается, так что
«выключить насовсем» из Диспетчера задач нельзя. Повторный запуск при работающем
экземпляре выводит окно первого. На терминальном сервере (RDS) у каждого пользователя
свой экземпляр.

## Где хранятся секреты

- **Секрет устройства** лежит в хранилище ОС (Диспетчер учётных данных Windows, связка
  ключей macOS, Secret Service на Linux).
- Если хранилища нет (например, Linux без Secret Service), секрет устройства сохраняется
  в файле `secrets` в каталоге пользовательских данных Link с правами `0600`.
- **Токен входа** никогда не пишется на диск: без хранилища ОС вход живёт только до
  закрытия Link (под кнопкой «Войти» показывается подпись об этом).
- Пароль сотрудника в Link нигде не сохраняется.

## Автовход по домену

См. раздел «Автовход Trackly Link» в [AD-SETUP.md](AD-SETUP.md): имя сервера, SPN,
почему не работает по IP-адресу.

## Трей на Linux

В Ubuntu GNOME без расширения AppIndicator значка в трее нет: окно остаётся на панели
задач, а закрытие окна его сворачивает; завершить клиент можно командой «Закрыть Link»
в меню учётной записи или на экранах входа. С расширением AppIndicator доступны значок и меню.
