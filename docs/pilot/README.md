# Пилот установки Trackly Link на доменных ПК (DST-06)

## Назначение

Проверить до вложений в дистрибуцию (Фаза 45), что вариант A (установка на пользователя без прав администратора) работает в доменной среде с AppLocker/SRP и на RDS. Пилот проводит оператор; результат записывается обезличенно (см. раздел «Что пересылать»).

Пилот не блокирует закрытие Фазы 42, но блокирует планирование Фазы 45 (D-07).

## Состав участников (D-02)

- 2-3 ПК с Windows, пользователи БЕЗ прав администратора.
- Один RDS-сервер (Windows Server) с несколькими сеансами.

## Откуда взять сборку

Артефакт dry-run workflow `release-link.yml`: NSIS-установщик `currentUser`. Подпись тестовой сборки - по [sign-notes.md](sign-notes.md). Скрипты: [install-silent.ps1](install-silent.ps1), [diag.ps1](diag.ps1).

Канонический путь установки (ADR 0005): `%LOCALAPPDATA%\Programs\Trackly Link\trackly-link.exe`. Штатный путь NSIS `currentUser` - `%LOCALAPPDATA%\Trackly Link`; скрипт передаёт `/D=` явно. Фактический путь, который создал установщик, записать в итог и сверить с каноническим.

## Чек-лист

Для каждого пункта заполнить: ожидаемо / фактически / событие (код события AppLocker/SRP, если есть).

| № | Действие | Ожидаемо | Фактически | Событие |
|---|----------|----------|------------|---------|
| 1 | `diag.ps1` ДО установки | JSON в `%TEMP%`; ОС x64, WebView2 есть/нет зафиксировано | | |
| 2 | Тихая установка без админа: `install-silent.ps1 -Installer <установщик>` | код 0, `trackly-link.exe` в `...\Programs\Trackly Link`, запись удаления в HKCU, ярлык; записать, потребовал ли WebView2 админа/интернета | | |
| 3 | Запуск `%LOCALAPPDATA%\Programs\Trackly Link\trackly-link.exe` под AppLocker/SRP (Enforce/Audit) | процесс запущен, события 8002/8003, нет 8004 | | |
| 4 | Окно каркаса | логотип «Link», вкладка «Чат», сайдбар, служебная строка (версия Link, WebView2, путь); нет белого экрана (CSP) | | |
| 5 | Тема | следует системной | | |
| 6 | Положение и размер окна | запоминаются между запусками | | |
| 7 | RDS: два пользователя одновременно | каждый запускает свой экземпляр, у каждого своя установка | | |
| 8 | Удаление: `install-silent.ps1 -Uninstall` | каталог, ярлык, запись реестра удалены | | |
| 9 | Итоговая карточка | заполнен [RESULT-TEMPLATE.md](RESULT-TEMPLATE.md) | | |

### Если запуск заблокирован (событие 8004 или блокировка SRP)

Решение D-04: НЕ переходить на вариант B. Добавить разрешающее правило AppLocker/SRP по издателю (предпочтительно, нужна подпись - см. sign-notes) или по пути `%LOCALAPPDATA%\Programs\Trackly Link\*`, повторить запуск и записать, какое правило сработало. Отдельно отметить возможную блокировку DLL NSIS-установщика, распаковываемых в `%TEMP%`.

## Что пересылать

Только заполненный RESULT-TEMPLATE и JSON из `diag.ps1`. Не пересылать и не записывать: имена ПК, пользователей, IP, домен, название организации, Subject и отпечатки сертификатов.

После пилота заменить заглушку [RESULT.md](RESULT.md) заполненным шаблоном.
