# ADR 0005. Путь установки и данные пользователя Link

## Статус
Accepted (provisional): фактический путь NSIS и режим установки WebView2 подтверждает пилот.

## Контекст
Link устанавливается на каждого пользователя без прав администратора. Нужны стабильные пути и идентификатор.

## Решение
- Системное имя «Trackly Link»; в окне применяется короткое «Link» с логотипом (D-08).
- Канонический каталог: `%LOCALAPPDATA%\Programs\Trackly Link\`, исполняемый файл `trackly-link.exe`.
- Штатный путь NSIS `currentUser` — `%LOCALAPPDATA%\Trackly Link`. Поэтому скрипт тихой установки передаёт `/D=%LOCALAPPDATA%\Programs\Trackly Link` (D-09). Фактический путь фиксирует пилот.
- Bundle identifier `org.trackly.link` стабилен навсегда: от него зависят AUMID уведомлений и пути данных.
- Данные `tauri-plugin-window-state` лежат в каталоге данных ОС текущего пользователя.
- Правило «portable, ничего в %APPDATA%» относится к серверу и десктопу Trackly. Link — устанавливаемый клиент на пользователя.

## Последствия
Смена идентификатора или каталога после выпуска потеряет данные окна и AUMID, поэтому они не меняются.

## Отвергнутые варианты
- Установка в `Program Files`: требует прав администратора.
- Portable-режим для Link: противоречит модели обновлений.
