# ADR 0004. Обновления, распространение и RDS

## Статус
Accepted (provisional): AppLocker/SRP и RDS подтверждает пилот.

## Контекст
Link ставится на ПК сотрудников Windows 10 x64 (D-01) без прав администратора.

## Решение
- Каналы обновлений существуют только на сервере. Канал компьютера приоритетнее канала пользователя.
- Откат версии = выпуск с большим номером; `version_comparator` запасной.
- Вариант A (D-04): установка на пользователя в `%LOCALAPPDATA%`, NSIS `currentUser`, запуск скриптом входа GPO.
- При запрете запуска из `%LOCALAPPDATA%` вводится разрешающее правило AppLocker/SRP по издателю. Переход на вариант B без нового решения пользователя не рассматривается.
- Целевые ПК: Windows 10 только x64.
- RDS: single-instance на пользователя сеанса, отдельный экземпляр в каждом сеансе.
- Пилот не блокирует закрытие Фазы 42, но блокирует планирование Фазы 45 (D-07).

## Последствия
Администратору домена нужно правило по издателю, если AppLocker запрещает каталог пользователя.

## Отвергнутые варианты
- Вариант B (установка на машину): требует прав и отдельного решения пользователя.
- Каналы обновлений на клиенте.
