# Trackly — Portable-режим (Windows)

Этот архив содержит portable-версию Trackly для Windows 10 x64.
Все данные хранятся рядом с исполняемым файлом — никаких записей в реестр
и системные папки.

## Быстрый старт

1. Распакуйте ZIP-архив в любую папку (например, `D:\trackly\`).
2. Запустите `trackly.exe`.
3. Данные (база `trackly.db` и логи) будут созданы в той же папке.

## Portable-маркер

Файл `portable.txt` (входит в архив) сигнализирует приложению о том, что
работает portable-режим. **Не удаляйте `portable.txt`** — без него приложение
может попытаться записывать данные в %APPDATA%.

## Изменение пути к базе данных

Если требуется хранить базу данных в другом месте:

1. Переименуйте `trackly.config.toml.example` в `trackly.config.toml`.
2. Откройте файл в текстовом редакторе.
3. Раскомментируйте строку `db_path` и укажите нужный путь.

## Вложения и резервные копии

Файлы вложений хранятся в папке `attachments` рядом с файлом базы данных
(не рядом с `trackly.exe`, если база перенесена). Чтобы хранить их в другом
месте, раскомментируйте в `trackly.config.toml` строку `attachments_path`,
например `attachments_path = 'D:\trackly-data\attachments'`. Для вложений
допустим сетевой (UNC) путь; сама база данных на сетевом пути хранить нельзя.

При переносе базы данных переносите вместе с ней и папку `attachments`
(или укажите её расположение через `attachments_path`).

Резервные копии копируют файлы вложений инкрементально в одну общую папку
`attachments/` рядом с копиями базы данных. Ротация старых копий эту папку
не очищает. Для восстановления скопируйте файл базы данных и объедините
(слейте) папку `attachments/` с рабочей папкой вложений.

## Требования

- Windows 10 x64 (64-разрядная)
- WebView2 Runtime (как правило, уже установлен на Windows 10;
  при необходимости скачайте с сайта Microsoft)

## Обход предупреждения SmartScreen

При первом запуске Windows может показать предупреждение SmartScreen.
Это ожидаемо, поскольку исполняемый файл не подписан сертификатом.
Нажмите «Подробнее» → «Выполнить в любом случае».
